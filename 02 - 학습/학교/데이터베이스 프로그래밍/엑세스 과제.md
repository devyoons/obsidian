# 강의: 엑세스 과제

## 강의 내용

---

테이블(최소 3개 이상)

- 모든 테이블에 입력 마스크, 유효성 검사 규칙은 반드시 포함할 것
- 기본 키는 최소 1개 이상의 테이블에 설정할 것

쿼리(최소 3개 이상)

- 매개변수 쿼리는 반드시 포함할 것

폼(최소 2개 이상)

- 반드시 폼 디자인으로 만들 것(폼 마법사 사용 금지)
- 콤보 상자, 하위 폼을 반드시 삽입할 것

보고서(최소 2개 이상)

- 반드시 보고서 디자인으로 만들 것(보고서 마법사 사용 금지)

기타

- 관계를 설정할 것

---

### **테이블 구조**

#### 1. `Students` 테이블

- **필드**
    - StudentID (AutoNumber, 기본 키)
    - Name (Short Text, 입력 마스크: >L<?????????????????)
    - BirthDate (Date/Time, 유효성 검사: <=Date())
    - Email (Short Text, 유효성 검사: Like "*@*.*")

#### 2. `Courses` 테이블

- **필드**
    - CourseID (AutoNumber, 기본 키)
    - CourseName (Short Text, 입력 마스크: >L<?????????)
    - Credits (Number, 유효성 검사: >=1 AND <=6)

#### 3. `Enrollments` 테이블

- **필드**
    - EnrollmentID (AutoNumber, 기본 키)
    - StudentID (Number, 외래 키)
    - CourseID (Number, 외래 키)
    - EnrollDate (Date/Time, 기본값: Date())

#### 관계 설정

- `Students`와 `Enrollments`의 `StudentID` 필드로 관계 설정
- `Courses`와 `Enrollments`의 `CourseID` 필드로 관계 설정

---

### **쿼리**

#### 1. 모든 학생과 수강 정보 조회 쿼리

```sql
sql
코드 복사
SELECT Students.Name, Courses.CourseName, Enrollments.EnrollDate
FROM Students
INNER JOIN (Courses INNER JOIN Enrollments ON Courses.CourseID = Enrollments.CourseID)
ON Students.StudentID = Enrollments.StudentID;

```

#### 2. 특정 학생의 수강 정보 매개변수 쿼리

```sql
sql
코드 복사
PARAMETERS [Student Name] Text;
SELECT Students.Name, Courses.CourseName, Enrollments.EnrollDate
FROM Students
INNER JOIN (Courses INNER JOIN Enrollments ON Courses.CourseID = Enrollments.CourseID)
ON Students.StudentID = Enrollments.StudentID
WHERE Students.Name=[Student Name];

```

#### 3. 특정 과목의 수강 학생 쿼리

```sql
sql
코드 복사
PARAMETERS [Course Name] Text;
SELECT Courses.CourseName, Students.Name, Enrollments.EnrollDate
FROM Students
INNER JOIN (Courses INNER JOIN Enrollments ON Courses.CourseID = Enrollments.CourseID)
ON Students.StudentID = Enrollments.StudentID
WHERE Courses.CourseName=[Course Name];

```

---

### **폼**

#### 1. 학생 정보 입력 폼 (`StudentForm`)

- **구성 요소**
    - 텍스트 상자: `Name`, `BirthDate`, `Email`
    - 하위 폼: `Enrollments` 연결

#### 2. 과목 정보 입력 폼 (`CourseForm`)

- **구성 요소**
    - 텍스트 상자: `CourseName`, `Credits`
    - 하위 폼: `Enrollments` 연결

---

### **보고서**

#### 1. 모든 학생과 수강 과목 보고서 (`AllEnrollmentsReport`)

- 학생 이름, 수강 과목, 등록 날짜 출력

#### 2. 특정 과목의 모든 학생 보고서 (`CourseEnrollmentsReport`)

- 과목 이름별 학생 명단 출력

---

이 모든 내용을 포함한 엑세스 파일을 생성하여 제공하겠습니다. Access 파일을 생성 후 첨부할게요.

현재 환경에서는 Access 데이터베이스를 생성하기 위한 `pyodbc` 모듈이 지원되지 않습니다. 대신, 요청하신 엑세스 파일을 수동으로 생성하여 구성 요소를 첨부할 수 있도록 안내 드리겠습니다.

#### **엑세스 데이터베이스 수동 구성 안내**

1. **테이블 생성**
    - **Students 테이블**
        - 필드: `StudentID` (자동 번호, 기본 키), `Name`, `BirthDate`, `Email`
    - **Courses 테이블**
        - 필드: `CourseID` (자동 번호, 기본 키), `CourseName`, `Credits`
    - **Enrollments 테이블**
        - 필드: `EnrollmentID` (자동 번호, 기본 키), `StudentID` (외래 키), `CourseID` (외래 키), `EnrollDate`
2. **관계 설정**
    - `Students.StudentID` ↔ `Enrollments.StudentID`
    - `Courses.CourseID` ↔ `Enrollments.CourseID`
3. **폼과 보고서**
    - 각 테이블을 기반으로 폼과 보고서를 수동으로 생성합니다.
