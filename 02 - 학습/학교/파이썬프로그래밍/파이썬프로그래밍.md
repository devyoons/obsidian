### 📌프로그래밍 학습과 파이썬

#### 1️⃣ 프로그래밍 언어 공부 방법

---

- 반드시 직접 코딩을 실습해야 함
- 복습 코딩 및 응용 실습이 필요함
- 천천히 그러나 확실하게 학습해야 함

**효과적인 프로그래밍 공부법 TOP 10**

- 코딩을 배우고 싶은 이유 파악하기
- 알맞은 프로그래밍 언어 선택하기
- 작은 것부터, 침착하게 시작하기
- 어린이 앱 사용해보기
- 무료 온라인 트레이닝 사이트 이용하기
- 코딩 강좌 수강하기
- 무료 프로그래밍 책 읽기(GitHub)
- 코딩 게임하기
- 멘토 구하기
- 다른 사람의 코드를 해킹하기

**비전공자의 프로그래밍 공부법**

1. 당장 두꺼운 책을 살 필요가 없음
    - 정말로 매일 쓸 수 있는 아주 간단한 프로그램을 만듦
    - 본인이 코딩으로 할 수 있는 기본적인 리스트 업을 함
    - 조합해서 어떤 유용한 프로그램을 만들 수 있는지 고민함
    - 당장 코딩을 시작함
    - 유용함보다는 일단 만들고 봄
    - 하루에 한 줄이라도 코딩함
2. 억지로라도 스스로 매일 사용함
    - 프로그램에 이름을 지어주는 등 애착을 갖도록 노력함
3. 사용하면서 추가할 기능이나 개선점을 찾아봄
4. 필요한 기능을 공부함

#### 2️⃣ 파이썬 프로그램의 특징

---

**파이썬 프로그램의 장점**

- 영어 구문과 비슷해서 문법이 간결하여 쓰기 쉬움
- 다양한 운영체제에 지원(Java와 비슷)이 가능함
- GUI Application개발(PyQT)에 적합함
    - 어떤 그래픽 형태로 결과가 나오는데 그걸 사용자가 활용할 수 있는
- 방대한 라이브러리를 지원하기 때문에 문제를 효율적으로 해결 할 수 있음
- 다양한 분야에 적용 가능한 범용 언어(네트워크, 웹, 데이터분석, 기계학습)임
- 문법이 쉬어 누구나 쉽게 배울 수 있어 컴퓨터 활용도가 높음
- 인간이 이해하기 쉬운 형태의 문법임

### 📌파이썬 프로그래밍 스타일

#### 1️⃣ 파이썬 프로그래밍 스타일

1. 들여쓰기 (Inentation)
    - 코딩블록을 시작하는 문장은 콜론(:)임
    - 파이썬에서는 들여쓰기 자체가 문법임
    - 같은 수의 공백으로 들여쓰기를 사용하면 블록으로 간주함
    - if  명령 다음 줄에는 무조건 들여쓰기를 해야 함
        - ⭐들여쓰기를 하지 않는 경우에는 “IdentationError:expected an idented block” 에러가 발생함
    - 들여쓰기는 공백(space)2칸, 4칸, 탭(Tab)을 이용해서 할 수 있음
        - 파이썬 코딩 가이드(PET8)은 4칸의 space를 권장하고 있
    
2. 들여쓰기 오류(Error)
    - if,for,while,def,class를 사용하려는 경우 → 들여쓰기는 필수이며 이를 위반하는 경우에는 indentationError:expected an indented block 에러 발생
    - 내부분이 아닌 경우, 공백(들여쓰기)할 경우 → indentationError:unexpected indented 에러 발생
    - 내부 블록 내인 경우 → 같은 공간으로 들여쓰기 사용
    - 탭(Tab)과 공백 혼용 금지 → 탭은 8칸, 탭을 4칸으로 인식하는 툴에서는 공백 4개로 인식해 실행 시 오류 발생

1. 적절한 주석( comment)
    - 해시(#)로 시작하는 경우, 주석으로 간주함
    - 백슬래지(\)로 이어지는 경우, 주석으로 사용이 불가함
    - 쉼표(,)로 이어지는 경우, 주석 삽입이 불가함
    - 모든 주석은 # 뒤에 한 칸의 공백을 주어 작성함

1. 구조적 코드
    - 프로그램 코드는 처음부터 마지막까지 순서대로 읽을 수 있는 형태가 좋음
    - 프로그램을 순서대로 읽기 위해서는 순차, 선택, 반복의 기본 형태를 사용하는 것이 좋음

1. 코딩 스타일
    - 한줄이 79자를 초과하지 않도록 함
    - 빈 줄을 사용하여 함수와 클래스를 분리함
    - 문서화된 코드를 사용함
    - 연산자 주위와 쉼표(,) 뒤에 공백을 사용하는 것이 좋

### 📌 파이썬 변수

#### 1️⃣ 변수 (Vatiable)의 정의

---

- 수학에서 쓰이는 수식에 따라서 변하는 값
- 컴퓨터 프로그래밍에서 아직 알려지지 않거나 어느 정도까지만 알려져 있는 양이나 정보에 대한 상징적인 이름
- 프로그램에서 필요로 되는 데이터를 저장하기 위한 기억 장소에 주어진 이름

<aside>
💡 변수는 어떤 값을 저장하는 공간을 의미

</aside>

**수학에서의 변수 (Variable)**

- 어떤 정해지지 않은 임의의 값을 표현하기 위해 사용된 ‘**기호**’
- 보통 쉽게 설명하기 위해서 ‘**변하는 숫자**’라는 표현을 자주 씀

**컴퓨터 프로그래밍에서 변수 또는 스칼라**

- 아직 알려지지 않거나 어느 정도까지만 알려져 있는 **양이나 정보에 대한 상징적인 이름**
- 컴퓨터 소스 코드에서의 변수 이름은 일반적으로 **데이터 저장 위치**와 **그 안의 내용물**과 관련되어 있음
    - 프로그램 실행 도중에 변경될 수 있음.

#### 2️⃣ 변수명 규칙과 선언

---

1. 영문자(대, 소문자 구분), 숫자, 언더바(_)를 사용하여 만들 수 있음
2. 변수명만으로 의미를 이해할 수 있는 단어를 사용함
3. 첫 자리에 숫자를 사용할 수 없음
    - 숫자를 사용하는 것은 변수 값과 혼돈을 일으킬 수 있어 사용하지 않는 것이 좋음
4. 공백은 포함될 수 없음
    - 간략하고 실제로 문맥적인 의미를 갖는 한 두 개의 단어를 사용하는 것이 좋음
5. 예약어는 변수 명으로 사용할 수 없음
6. 특수 문자는 사용할 수 없음
    - ex) +, -, *, /, $, @, &, % 등
7. 파이썬의 키워드는 사용할 수 없음
    - ex) if, for, while, and, or, else 등

### 📌 자료형

#### 1️⃣ 파이썬 자료형 (Data Type) 1

---

**`bool`**

- 이진 자료형
- True 또는 False 값을 가짐

**`int, float, complex`**

- 수치 자료형
- 정수, 실수, 복소수의 값을 가짐

**`str`**

- 문자열 자료형
- 다양한 문자열들을 가짐

**`list`**

- 순서가 있는 자료형
- 다양한 객체들을 멤버로 가질 수 있는 자료형
- []를 사용함

**`tuple`**

- list형과 같으나 내용의 변경이 허용되지 않는 자료형
- ()를 사용함

**`dict`**

- 순서가 없는 자료형
- 키와 값으로 이루어진 자료를 저장하는 자료형
- **값은 중복될 수 있으나 키는 중복 될 수 없음**
- (:)를 사용함

**`set`**

- 순서가 없는 자료형
- **값의 중복을 허락하지 않음**
- {}를 사용

**수치 자료형**

- 정수형 상수
    - 정수형(Integer Type)
        - 양의 정수(1, 2, …), 음의 정수(-1, -2, …)와 0을 의미함
    - 정수형 상수의 표현 범위에 제한이 없음
    - 10진수, 2진수, 8진수, 16진수의 사용이 가능함
    - 2진수, 8진수(Octal) 및 16진수(Hecadecimal)
        - 컴퓨터에서 연산을 하기 편리하게 사용하기 위하여 사용하는 표현 방식임

    - ex) a = 3 + 2j

            - 출력하는 방법 → print(a, imag) → 2.0 출력

#### 3️⃣ 파이썬 자료형 (Data Type) 3

---

**튜플(Tuple)**

- **특징**
    - 리스트와 같이 순서를 가진 자료형이지만 리스트와 달리 **초기 생성 후 값이 변경이 불가능한 자료형**
    - 변경 불가능한 자료형은 프로그램에서 같은 값을 유지해야 하는 리스트 변수에 사용하기 위해 주로 활용됨
        - `변수명 = (val1, val2, val3)`
- **튜플의 생성**
    
```python
>>> a = ('lee', 40, 20, 40)
>>> b = ('Kim',10, 30, 40)
>>> type(a)
>>> <class 'tuple'>
>>> a
>>> ('lee', 40, 20, 40)
```

- ()를 사용하여 선언하고 생성하게 됨
- 리스트와 같이 다양한 자료혀이으로 생성할 수 있지만, 수정 삭제와 같은 기능은 동작하지 않음
- del과 append()함수를 수행하면 에러(Error)가 발생함을 확인할 수 있음

- **튜플의 사용**
    - 인덱싱 및 슬라이싱을 사용하여 속성 값을 사용할 수 있음
    - ‘+’ 연산자를 통해 튜플을 연결 할 수 있음
    - ‘*’ 연산자를 사용하여 속성 값을 반복할 수 있음

**딕셔너리(Dictionary)**

- **특징**
    - 리스트, 튜플과 같이 복수형 자료를 할당 할 수 있는 자료형
    - 자료가 저장 관리되지 않고 자료를 찾을 수 있는 “{키,값}”이라는 두 쌍으로 자료를 할당하고 관리할 수 있게 됨

- **딕셔너리 생성**
    
```python
>>> a = {1:'red'}
>>> b = {1: ['red','blue']}
>>> emp = {'name':'Kim','grade':90}
```

- `{key:value}`의 형태를 가짐
    - key는 각각의 자료를 찾을 수 있는 유일한 값이어야 하며 변하지 않아야 함
- 딕셔너리를 생성할 때
    - key 값은 고유한 **‘변화하지 않는 값’**이 들어가야 함

- **딕셔너리 값 읽기**
    - **변수명[키]**의 형태로 가져올 수 있음
        
```python
>>> a = {1:'red'}
>>> b = {1: ['red','blue']}
>>> emp = {'name':'Kim','grade':90}
>>> emp[’name’]
>>> ‘Kim'
>>> a[1]
>>> ‘red'
```

- **값 추가**
    - “`변수명[key]=값`”의 형태로 새로운 값을 추가할 수 있음
        
```python
>>> a = {1:'red'}
>>> b = {1: ['red','blue']}
>>> emp = {'name':'Kim','grade':90}
>>> a[2] =’blue’`
>>> a
>>> {1:’red’,2:’blue’}
```


- **값 변경**
    - 추가와 마찬가지로 “`변수명[key]=값`”의 형태로 해당키가 가지고 있는 킷값을 변경할 수 있음
        
```python
>>> a = {1:’red’,2:’blue’}
>>> a[1]='blue'
>>> a
>>> {1:'blue', 2:'blue'}
```

- **삭제**
    - 딕셔너리가 변수가 가지고 있는 값을 삭제할 때는 del을 사용하여 삭제할 수 있음
        
```python
>>> a = {1:'blue', 2:'blue'}
>>> del a[2]
>>> a
>>> {1:'blue'}
```


**문자열 출력**

- 파이썬에서 문자열의 출력은 작은 따옴표, 큰따옴표를 사용하여 출력할 수 있음
- “`\`” 문자를 사용하여 따옴표를 출력하거나 동일한 문자열을 여러 번 출력하는 경우 “`*횟수`”를 사용하여 출력할 수 있음

```python
print("Hi Python")

print('Hi Python')

print("'Hi Python'")

print('"Hi Python"')

print("\"Hi Python\"")

print("Hi Python, "*10)

#결과
Hi Python
Hi Python
'Hi Python'
"Hi Python"
"Hi Python"
Hi Python, Hi Python, Hi Python, Hi Python, Hi Python, Hi Python, Hi Python, Hi Python, Hi Python, Hi Python,
```

**포맷을 이용한 출력**

- 파이썬에서 문자열 객체의 메소드인 format()을 이용하면 다양한 형태로 출력이 가능함

```python
print('출력 형식'.format(데이터))
```

| 출력형식  | 형식화된 문자열을 `{}`(브레이스키)안에 넣어 출력 형태를 지정 |
| --- | --- |
| `{:len}` | 출력할 길이를 지정, 묵시적으로 문자열은 왼쪽, 숫자는 오른쪽 정렬 |
| `{:<len}` | 출력할 길이를 지정, 왼쪽 정렬 |
| `{:>len}` | 출력할 길이를 지정, 오른쪽 정렬 |
| `{:^len}` | 출력할 길이를 지정, 가운데 정렬 |

```python
print('Hi \
Python')

print('\\20,000')

print('Hi \n Python')

print('Hi \t\t Python')

#결과
Hi Python
\20,000
Hi 
 Python
Hi 		 Python
```
