#### 자바스크립트와 자바는 다른 언어

라이브 스크립트

- 초기에 가장 대중화됐던 ‘넷스케이프’ 브라우저에서 웹 문서를 좀 더 동적으로 만들기 위해 개발된 언어
- 무려 10일 만에 개발

자바 스크립트

- 라이브스크립트가 선 마이크로시스템즈로 넘어가면서 새로 붙인 이름
- 당시에 ‘자바’가 인기 있는 언어였기 때문에 좀 더 친숙하게 보이도록 이름을 붙임

### 📌ES6에 대하여

- 1990년대 중반부터 자바스크립트가 많은 곳에서 사용되자 유럽컴퓨터제조협회(ECMA)는 자바스크립트를 ECMAScipt라는 이름으로 표준화
- 2000년대 중반부터 자바스크립트가 많은 곳에서 널리 사용되며, 자바스크립트의 문법이 급속도로 발전
- 1997년에 ECMAScript 초판이 채택된 후 ‘ES2’와 ‘ES3’처럼 ES 뒤에 판 번호를 붙여서 구별
    
    <aside>
    💡 이후 ‘ECMAScript 2015’처럼 연도를 붙인 것으로 공식적인 이름으로 결정
    
    </aside>
    
- 기본의 자바스크립트는 단순히 웹 브라우저의 동적인 효과를 위해 개발된 언어였고, 아주 단기간에 개발된 언어였기 때문에 활용 범위가 좁았음
- HTML5가 등장할 즈음 웹 개발에 새로운 변화가 찾아왔고, 모든 브라우저에서 지원하는 자바스크립트를 확장시킬 필요성이 대두됨
    
    <aside>
    💡 이 변화를 수용해서 나온 것이 ES6(ES 2015)
    
    </aside>
    
- ES6 이후로부터 일반적인 개발 언어처럼 복잡한 개념이 추가됨
    - 일반적인 개발 언어 : C#, JAVA, C++
    
    <aside>
    💡 기존 자바스크립트를 확장한 것이기 때문에 예전 개념들을 하나씩 버리면서 새로운 개념들로 교체해 나가는 중
    
    </aside>
    
- ECMAScript는 1년마다 업데이트되고 있음

### 📌자바스크립트에서 할 수 있는 일

#### 웹 클라이언트 애플리케이션 개발

- 웹 브라우저에서 실행되는 웹 클라이언트 애플리케이션 개발이 목적
- 웹 브라우저에서 실행할 수 있는 유일한 프로그래밍 언어

#### 웹 서버 개발

- 기존에 웹 개발은 두 가지 이상의 프로그래밍 언어가 필요했음
    - Node.js가 등장하면서 웹 서버도 자바스크립트로 개발 가능
- 웹 페이지를 출력하지 않아도 웹 프로토콜 활용하면 웹 서버로 칭함
    - ex) HTTP 또는 HTTPS 등
- 페이팔 결제 시스템에도 Node.js 를 활용
- Node.js는 웹 개발과 관련해서 간단한 모듈들만 제공해서 데이터 처리와 예외 처리 등이 복잡하나, 빠르다는 장점이 있음

#### 페이스북의 React Native

- 자바스크립트로 네이티브 애플리케이션을 개발
    - 내부적으로 프로그래밍 언어로 변환
    - 웹용 앱용 동시개발 가능

#### 데스크톱 애플리케이션 개발

- 일렉트론(Electron) 모듈
    - 자바 스크립트로 개발 전용 텍스트 에디터를 만들어 배포, 본격적으로 데스크톱 애플리케이션 개발
    - URL : [https://www.electronjs.org/](https://www.electronjs.org/)

#### 데이터베이스 관리

- 데이터베이스는 데이터를 저장할 때 사용하는 프로그램을 말함

<aside>
💡 NoSQL : 기존의 SQL은 복잡하고 무거워 사용하기 쉬운 데이터베이스 등장

</aside>

- 2016년 9월 기준 주사용 데이터베이스 엔진
    - Oracle, MySQL, MSSQL Server, PostgreSQL, MariaDB, MongoDB(JSON기반)
        - 관계형 데이터 베이스  : RDBMS
        - NoSQL은 기존의 관계형데이터베이스가 아닌 SQL을 이용하지 않는걸 NoSQL이라고함
    - JSON 프로토콜을 통해서 만들어진 DB
    - 골격은 JSON과 동일
    - firebase 에서 NoSQL을 무료로 제공해주고 있다.

## ✔ 웹 개발과 자바스크립트

### 📌클라이언트와 서버

- 사이트의 동작 원리는 서버 컴퓨터와 클라이언트 컴퓨터 간에 정보를 주고 받으면서 그 결과를 사용자에게 보여주는 것
    - ex ) 사용자가 쇼핑몰에서 상품의 정보를 보기 위해 거치는 단계
        1. 클라이언트 컴퓨터(사용자가 사용하는 컴퓨터)에서 서버 컴퓨터로 관련 정보 요청을 함
        2. 서버에서 해당 상품 정보를 찾아서 클라이언트 컴퓨터로 보내줌
        3. 사용자가 화면을 보고 서버에서 응답한 정보를 확인함

#### 프론트엔드 개발과 자바스크립트

프론트엔드(Front-end) : 앞에 있어서 사용자에게 보이는 부분을 가리킴

**프론트엔드 개발의 역할**

- 웹 사이트나 애플리케이션에서 내용을 작성하고 화면을 디자인하는 것부터 사용자의 동작에 반응해서 결과를 만드는 것이 모두 포함됨

**프론트엔드 개발의 중요성**

- 최근의 웹 사이트는 사용자와 실시간으로 정보를 주고 받으면서 애플리케이션처럼 동작하기 때문에 그만큼 프론트엔드 개발이 중요함

#### 기본세팅

**기본적인 세팅**

1. ctrl + p를 누르면 파일 Find 및 Command를 입력할 수 있는 창이 생김
2. 바로 Command를 입력하고 싶은 경우 F1을 누름

**언어 세팅**

1. VS Code 사이트에서 다운로드 받으면 디폴트로 본인 브라우저의 Local 정보를 이용하여 언어가 세팅됨
2. 해당 언어를 바꾸고 싶은 경우
    - F1 를 누른 후 Configure Language에서 원하는 언어로 변경

**Theme Setting**

1. F1 > Theme 입력 후 테마를 선택하여 변경함

**setting.json Setting**

1. ctrl+p 입력 후 setting.json 키워드를 입력
2. 그 다음 “기본 설정 : 사용자 설정 열기 “(Open User Setting) 항목을 입력하면 IDE의 세팅 설정을 변경할 수 있음

| 좌측 | 우측 |
| --- | --- |
| 변경 가능한 세팅 목록이 나옴 | 커스터마이징할 세팅을 json형태로 입력 |
- 좌측 패널의 기본 설정에 마우스 포인터 오버 시 연필 아이콘이 나타남

#### VS Code 삭제하기

1. User 자신의 사용자 이름 안에 .vscode라는 폴더를 삭제
2. AppData에서 Code라는 폴더 안의 모든 내용 삭제
    - C:\Users\[사용자]\Roaming\Code
3. VS Code 프로그램 삭제 후 재설치 진행하여 초기화 완료
