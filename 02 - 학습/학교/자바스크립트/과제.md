# 강의: 과제

## 강의 내용

**과제 제목 : 자바스크립트를 활용한 웹 비즈니스 아이디어 모델 작성**

**평가기준(준거)**

① 평가 등급은 완성도에 따라 A, B, C, D 로 평가합니다.② 과제는 본인이 할 수 있는 거 만큼 작성하시면 됩니다.③ 평가는 상대평가로 평가합니다.

과제 제목 : 자바스크립트를 활용한 웹 비즈니스 아이디어 모델 작성

(1) 웹 비즈니스 모델 기획 작성

① 비즈니스 모델 아이디어 경진대회라고 생각하고 작성하시면 됩니다.

② DB : MariaDB 활용

③ 프로그래밍 언어 : Javascript 활용

④ HTML, CSS 활용

⑤ 서버/프론트 엔드 개발 언어(Javascript 기반), 웹 서버 등을 소프트웨어 아키텍처에 포함하여 기획

⑥ 하나의 문서에 작성합니다. (pptx 혹은 ppt로 과제 작성하고 pdf 함께 제출 : 과제 제출 시 ppt 파일을 PDF로 만들어서 함께 압축 하여 함께 제출, ppt가 없는 경우 한컴 오피스로 작성 후 pdf와 함께 제출)

⑦ 파일은 이름_학번.zip 필수적으로 작성해 주세요.

(※ 예시 : 홍길동_202311112222.zip)

⑧ 필수적으로 자바스크립트 기반의 소프트웨어 아키텍처가 들어가 가야 합니다.

위 내용과 같고 날짜를 엄수 해주세요 ^^

그럼 어렵겠지만 과제를 신경 쓰시기 바랍니다.
