# 강의: 생성형 API

## 강의 내용

시험주제 : Customize ChatGPT을 이용하여 나만의 챗봇을 만들기

제출시기 : 2024년 04월 22일 00시 00분 ~ 2024년 04월 28일 23시 59분

1. 제작한 챗봇 서비스의 이름 작성
    
    : 충전기 OCPP 지식 도우미
    
2. 제작한 챗봇 서비스가 해결하고자 하는 문제 작성
    - OCPP 프로토콜 규약에 맞는 정보 확인
    - 충전기와 웹소켓 통신을 위한 코드 예시
    - 충전기에서 보내주는 형식과 프로토콜 JSON 형식을 맞추는 핸들러 예
    - 시뮬레이션 서비스를 만들때 javaScript로 쉽게 만들 수있는 예시
3. 제작한 챗봇 서비스가 달성하고자 하는 기대효과 작성
4. "Customize ChatGPT"에 적용한 시스템 프롬프트 작성
    
    <aside>
    💡 **Custom Instructions
    :** 나는 백엔드 JAVA 개발자이며, 현재 전기차 충전기에 관한 서비스를 만들려고해.
    OCPP 프로토 기반으로 웹소켓 서버, REST API 서버, APP, WEB으로 구성할거야.
    충전기와 웹소켓 관련 지식이 부족한 상태이며, OCPP 프로토콜 규약에 관한 정보도 많이 완전하게 이해하고 싶어.
    
    </aside>
    
    <aside>
    💡 How would you like ChatGPT to respond?
    
    - OCPP 1.6 공식 문서의 내용을 우선으로 해줘.
    - 가장 정확한 정보에 우선 순위를 부여해줘.
    - 확실한 사실이 아니고 애매하거나, chatGPT의 의견이 들어갔으면 해당 내용은 "chatGPT의 의견"이라고 명시해줘
    - 코드 답변을 요청한다면 주석으로 설명을 달아줘
    - javascript 코드 작성시 jQuery와 ES6문법을 사용해줘
    - java코드 작성 java8 버전 이상 java11버전 이하로 코드로 답변해줘
    </aside>
