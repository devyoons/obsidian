```c
#include <stdio.h> // stdio.h 파일 내용을 가져옴

									 // printf 함수의 호출을 위해 필요함

int main(void) {
	
	printf("hello world\n"); // printf함수를 호출함
												   // 인자는 문자열"hello world\n"
	
	return 0;  // 함수를 호출한 영역으로 값을 전달(반환)
						 // 현재 실행중인 함수의 종료
}
```

### 코드를 분석하기 위해 필요한 메모를 적는 ‘ 주석’ 사용수

**주석**

- 프로그램 내에 삽입된 메모
    - 컴파일의 대상에서 제외됨
    - 주석은 프로그램의 실행 결과에 영향을 미치지 않음

**주석의 필요성**

- 자신이 짠 코드도 분석하는 데 상당한 시간이 걸릴 수 있음
- 남이 작성한 코드는 더 오래 걸릴 수 있음

### printf 함수의 기본적인 이해

#### 1. 정수의 출력과 서식 문자 `%d`

```c
int main(void){
 printf("hello world!\n");
 printf("%f\n", 1234);
 printf("%d %d \n", 10, 20);
 return 0;
}
```

- `%d` : 문자열에 삽입된 %d를 가리켜 서식 문자라고 함
    - 서식 문자는 출력의 형태를 지정하는 용도로 사용됨
- 부호가 있는 10진수 정수 형태로 출력하라는 의미
- `%n` : ‘이스케이프 시퀀스(Escape Sequence)’라고 불리며 개행의 용도로 사용

### 변수 자료형

---

#### 덧셈 프로그램의 구현 : +연산자

```c
int main(void) {
	3 + 4; // 3과 4의 덧셈 명령
	return 0;
}
```

- 컴파일은 되는가?
    - C언어가 + 연산을 제공하고 있기 때문에 컴파일에 문제가 없음
    - C언어에서 사칙 연산은 기본적으로 제공함(+, -, *, /, %)
- 출력은 되는가?
    - 연산의 결과로 아무것도 출력되지 않음
    - + 연산은 이루어졌지만, 그 결과를 출력하기 위한 코드가 없기 때문임
- 결과를 확인할 수는 없을까?
    - printf 함수를 사용해서 출력해야만 결과를 확인할 수 있음
    - 연산 결과를 저장하려면 그 값의 저장을 위해서 **변수(Variable)**가 필요함

#### 변수의 정의 및 이름

#### 연산자의 우선 순위

- → : 왼쪽에서 오른쪽으로 진행됨

- 계승 (팩토리얼)
    
```c
#include <stdio.h>

int main(void) {
	
	int result = 1, num, i;
	
	printf("정수 입력: ");
	scanf("%d", &num);
	
	for(i = 1; i <= num; i++)
		result *= i; // result = result * i;
		
	printf("%d! = %d\n", num, result);
	return 0;
}
```
