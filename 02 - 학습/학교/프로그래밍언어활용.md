### 개발 환경 구축의 이해

#### 서버 프로그램 구현에 필요한 요소

- 개발에 필요한 환경을 구성하는 일
- 개발 환경 구성 시 구현될 요구사항의 명확한 이해가 필요함
- 개발 도구 및 서버의 선정이 이루어져야 함
- 개발에 사용되는 도구들의 사용 편의성과 성능, 라이선스 등에 대한 내용도 파악해야 함
    - IDE → 이클립스 , VS(C), 안드로이드 스튜디오(앱), 스위프트(IOS)
    - ADB , ORACLE, MySQL, MSQL

### 개발을 위해 사용되는 도구의 분류와 특성

![[02 - 학습/학교/첨부/2530a727_Untitled.png]]

- 구현 도구
    - IDE 개발툴 :  Eclipse(Java,C,C++,php,Js), 
                         Visual Studio code, IntelliJ, NetBeans 등
        1. 코드의 작성과 수정이 가능함
        2. 코드의 디버깅이 가능함
        3. 구현되는 소프트웨어의 언어 종류에 따라 선택이 가능함
        4. 프로그램을 개발할 때 가장 많이 사용되는 도구임

    - xUnit, Spring Test 등
- 형상관리 도구
    - CVS, Subversion, Git 등
- 빌드 도구
    - Ant, Maven, Gradle

#### 구현 도구

**이클립스(Eclipse)**

- 다양한 플랫폼에서 쓸 수 있으며, 자바를 비롯한 다양한 언어를 지원하는 프로그래밍 통합 개발 환경을 목적으로 시작한 구현 도구임
- 현재는 OSGi를 도입하여, 범용 응용 소프트웨어 플랫폼으로 진화함
- 자바로 작성되어 있으며, 자유 소프트웨어이지만 막강한 기능을 자랑함
- Windows, macOS, 리눅스 중 어디서든 자유롭게 이용 및 수정, 재배포가 가능함
- 개발자를 위한 플러그인 지원이 대단히 활발한 툴 중 하나임

**Visual Studio code**

- 마이크로소픝트가 마이크로소프트 윈도우, macOS, 리눅스용으로 개발한 소스 코드 편집기임
- 디버깅 지원과 Git제어, 구문 강조 기능 등이 포함되어 있음
- 종류 : 소스코드 편집기, 디버거
- 라이선스
    - 소스코드 → MIT 라이선스
    - 바이너리 → 프리웨어
- 개발 : 마이크로소프트

**IntelliJ**

- IntelliJ IDEA는 JetBrains사에서 제작한 사용 자바 통합 개발 환경임
- 줄여서 IntellJ혹은 IDEA로 불림
- 프로그래밍 언어 : 자바, 코틀린(안드로이드)

#### 빌드 도구(Build Tool)

- 작성한 소프트웨어 코드에 대한 빌드 및 배포 수행
- 각각의 구성 요소들과 모듈들에 대한 의존성 관리
    - 의존성(Dependency)이라는 개념으로 어떤 규칙에 의해 한 페이지에 작성해주면 Build툴이 온라인을 통해서 다운로드해준다.

**아파치 엔트(Aphache Ant)**

![[02 - 학습/학교/첨부/2a26e199_Untitled.png]]

- 자바 프로그래밍 언어에서 사용하는 자동화된 소프트웨어 빌드 도구
- 유닉스나 리눅스에서 사용되는 make와 비슷하나 자바 언어로 구현되어 있음
- 빌드를 위한 환경 구성을 xml 파일을 사용

**아파치 메이븐(Aphache Maven)**

![[02 - 학습/학교/첨부/2f2d4d21_Untitled.png]]

- 자바용 프로젝트 관리 도구
- 아파치 앤트의 대안으로 만들어짐
- 아파치 라이선스로 배포되며 오픈 소스 소프트웨어임

**Gradle**

![[02 - 학습/학교/첨부/011975c2_Untitled.png]]

- 그루비를 이용한 빌드 자동화 시스템
- Groovy와 유사한 도메인 언어를 채용함
- 현재 안드로이드 앱을 개발할 때 사용되는 안드로이드 스튜디오의 공식 빌드 시스템임
- Java, C++, Python등과 같은 여러 가지 언어를 지원

#### 테스트 도구 (Test Tool)

- 코드의 기능 검증을 시행함
- 소프트웨어의 전체 품직을 높이기 위해 사용됨
- 코드의 테스트, 테스트에 대한 계획, 수행 및 분석 등의 작업을 수행함

**xUnit**

- 다양한 코드 중심 테스트 프레임워크
- 소프트웨어의 함수나 클래스 같은 서로 다른 구성 원소(단위)를 테스트 할 수 있게 해줌
- 같은 테스트 코드를 여러 번 작성하지 않게 해줌

#### 형상관리 도구

- 소프트웨어 코드와 리소스에 대한 버전 관리 수행
- 프로젝트 수행 시 필수로 포함되는 도구임

**CVS**

- CVS(Concurrent Versions System, 동시 버전 시스템)는 버전 관리 시스템을 구현함
- 소프트웨어 프로젝트를 진행할 때 파일로 이뤄진 모든 작업과 모든 변화를 추적함
- 여러 개발자가 협력해서 작업을 할 수 있게 해줌
- CVS는 GNU 일반 공증 사용 허가서 하에서 배포됨
- CVS는 클라이언트 서버 구조로 되어 있음
- 서버는 프로젝트의 현재 버전과 변화를 저장함
- 클라이언트는 서버에 접속하여 프로젝트의 완전한 복사본을 얻을 수 있음
- 복사본으로 작업한 뒤에, 바뀐 내용을 체크인

#### 웹(Web)서버

- HTTP를 이용한 요청/응답(Request/Response)을 처리 하기 위한 미들웨어를 설치하는 서버
    - IIS, Aphache, Node.js express, EnginX, tomcat, ragin, weblogic
- 웹 브라우저 화면에서 요청하는 서비스
- HTML, CSS, 이미지 등을 제공하는 웹 서버 어플리케이션 처리를 담당함

![[02 - 학습/학교/첨부/8528f856_Untitled.png]]

#### 웹 어플리케이션(Application)서버

: 웹 서비스를 동적으로 제공하기 위해 WAS(Web Application Server)의 형태인 Resin, Tomcat등과 서비스에 관련된 애플리케이션이 설치된 서버

![[02 - 학습/학교/첨부/8c8ece89_Untitled.png]]

- 웹 브라우저가 클라이언트 프로그램임
- HTTP 요청을 받아들임
- 웹 페이지를 사용자가 사용할 수 있게 반환하여 사용자에게 전달함
- 웹 컨텐츠를 전달받고 전달하는 기능
- 현재 아파치 웹 서버가 1위 업체
