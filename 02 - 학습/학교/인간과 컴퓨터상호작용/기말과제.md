# 강의: 기말과제

## 강의 내용

비즈니스 모델 아이디어 제출

서버/프론트 개발 언어 : 선택 및 이유

개발 툴 : 선택 및 이유

물리적 서버 : 선택 및 이유

웹 서버 : 선택 및 이유

데이터베이스 : 선택 및 이유

프레임워크 : 선택 및 이유

비즈니스 모델 기획서(ppt로 작성)

비즈니스 모델의 프로세스(한 가지 이상)

기획하고자 하는 앱은 “배드민턴 대회목록과 출전선수를 관리하는 웹”을 대상으로 하려고한다.

기존 “스포넷”이라는 어플&웹이 있지만 사용함에 불편함이 있어 한번 기획해보고 싶어서 생각한것이다.

상품성으로 좋지는 않지만 많은 동호인이 생겨나고 대회에도 많이 출전하고 있기에 골랐다.

 서버/프론트 개발 언어 : Node.js

서버 프론트 개발 언어로는 node.js를 골랐다. 작고 빈번한 요청을 빠르게 처리가 가능한 장점이 있고, 비동기로 요청을 처리하기 때문에 처리가 끝나면 바로 응답하여 속도가 빠르고 비동기 처리 로직을 쉽게 짤수 있어서 골랐다. 해당 대회에 출전하는 선수의 대진표를 확인하는데 제일 많이 사용하므로 빨리 대진과 해당시간의 코트를 확인할 수 있어야하므로 빠른 처리가 필요하다.
