### 1. ERD

![[02 - 학습/학교/첨부/47aa00c2_Untitled.png]]

기본적으로 모든 테이블이 고유번호 PK를 SEQUENCE를 이용하여 자동으로 숫자가 증가하게 설정하도록 설계하였다.

#### 회원

![[02 - 학습/학교/첨부/f01064d4_Untitled.png]]

회원가입시 필요한 정보와 주문시 필요한 정보를 테이블로 나누어 설계하였습니다.

회원은 정지, 탈퇴시 삭제하지 않고 데이터를 가지고 있도록 Y,N을 사용하였습니다.

해당 회원이 주문,후기등 다양한 데이터에 영향을 주기 때문에 필드로 구분하도록 설계하였습니다. 

비밀번호는 암호화시 길이가 길기 때문에 넉넉하게 잡았고, 필요하지 않은 정보를 제외하고 전부 NOT NULL처리 하도록 하였습니다.

#### 주문

![[02 - 학습/학교/첨부/90cf6e54_Untitled.png]]

기본적으로 주문상세에 주문번호를 외래키로하여 하나의 주문에 여러개의 주문상세가 들어갈 수 있게 설계하였습니다.

주문상세에서 상품ID를 가져왔는데도 가격을 저장한 이유는 상품의 가격은 관리자가 수시로 바꿀 수 있지만, 이미 주문한 내역에는 예전 가격이 저장되어야하기 때문에 따로 저장하도록 하였습니다.

배송지에 대한 내용 또한 동일한 이유로 구성하였습니다.

#### 상품

![[02 - 학습/학교/첨부/51b9a0d0_Untitled.png]]

카테고리는 그룹기본과 기본으로 분류하였습니다.

그룹 기본에는 대분류 , 기본엔 소분류로 하기위함입니다.

카테고리 또한 삭제하지 않고 필드를 만들어서 관리하도록 하였습니다.

#### 장바구니

![[02 - 학습/학교/첨부/31a631b8_Untitled.png]]

이 테이블은 일시적으로 데이터를 저장하는 용도이므로 하나의 장바구니에 여러개의 상품을 담는것이 아니라, 여러개의 데이터를 생성하여 회원ID로 묶어서 사용하도록 설계하였습니다.

#### 문의 및 후기

![[02 - 학습/학교/첨부/c71dc24e_Untitled.png]]

문의, 후기 결국 둘 다 게시판 용도이며, 게시글 종류로 필드를 만들어 분류하도록하였습니다.

#### 파일

![[02 - 학습/학교/첨부/5bdb7bdf_Untitled.png]]

이미지를 관리하는 테이블입니다.

한 상품에 여러 이미지, 혹은 게시판 하나에 여러이미지를 관리하기위해 그룹으로 파일이미지를 관리하도록 설계하였습니다.

#### 관리자

![[02 - 학습/학교/첨부/bc5e90e3_Untitled.png]]

관리자는 탈퇴나 회원가입을 진행하는걸 고려하지 않고 만들었다.

개발자쪽에서 직접 처리하는 방식으로 간단하게 설계하였습니다.

### 3. 테이블 생성 및 PK,FK 조건 추가 (ORACLE)

```jsx
CREATE TABLE "ORDER" (
	"ORDER_ID"	INT		NOT NULL,
	"MEMBER_NO"	INT		NOT NULL,
	"PRICE"	INT		NOT NULL,
	"ORDER_DATE"	DATE	DEFAULT NOW()	NULL,
	"CARD"	VARCHAR(20)		NULL,
	"STATUS"	VARCHAR(20)	DEFAULT 'O'주문완료	NULL,
	"REASON"	VARCHAR(300)		NULL,
	"RECIPIENT_NAME"	VARCHAR(15)		NOT NULL,
	"ZIP_CODE"	VARCHAR(6)		NOT NULL,
	"RECIPIENT_ADDR"	VARCHAR(300)		NOT NULL,
	"ADDR_DETL"	VARCHAR(100)		NOT NULL,
	"RECIPIENT_PHONE"	VARCHAR(15)		NOT NULL,
	"REQ"	VARCHAR(100)	DEFAULT '조심히 안전하게 와주세요'	NULL,
	"ITEM_CNT"	INT		NULL
);

CREATE TABLE "MEMBER" (
	"MEMBER_NO"	INT		NOT NULL,
	"MEMBER_ID"	VARCHAR(15)		NOT NULL,
	"MEMBER_NAME"	VARCHAR(15)		NOT NULL,
	"MEMBER_PW"	VARCHAR(150)		NOT NULL,
	"PHONE"	VARCHAR(15)		NOT NULL,
	"JUMIN"	INT		NULL,
	"GENDER"	INT		NULL,
	"BANNED"	VARCHAR(1)	DEFAULT 'N'	NULL,
	"SINGOUT"	VARCHAR(1)	DEFAULT 'N'	NULL
);

COMMENT ON COLUMN "MEMBER"."MEMBER_NO" IS 'SEQUENCE 1~';

COMMENT ON COLUMN "MEMBER"."MEMBER_ID" IS 'UNIQUE KEY';

CREATE TABLE "ITEM" (
	"ITEM_ID"	INT		NOT NULL,
	"CATEGORY_GROUP_ID"	INT		NOT NULL,
	"FILE_GROUP_ID"	VARCHAR(100)		NOT NULL,
	"CONTENT"	VARCHAR(1000)		NULL,
	"PRICE"	INT		NOT NULL,
	"SALE"	INT		NOT NULL,
	"RGSR_DATE"	DATE		NULL,
	"CNT"	INT		NOT NULL,
	"DELETED"	VARCHAR(1)	DEFAULT 'N'	NULL
);

CREATE TABLE "CATEGORY_GROUP" (
	"CATEGORY_GROUP_ID"	INT		NOT NULL,
	"NAME"	VARCHAR(30)		NOT NULL
);

CREATE TABLE "ITEM_FILE_GROUP" (
	"FILE_GROUP_ID"	VARCHAR(30)		NOT NULL
);

CREATE TABLE "ITEM_FILE" (
	"FILE_ID"	VARCHAR(4)		NOT NULL,
	"FILE_GROUP_ID"	VARCHAR(100)		NOT NULL
);

CREATE TABLE "WISH" (
	"WISH_ID"	INT		NOT NULL,
	"ITEM_ID"	INT		NOT NULL,
	"ORDER_NO"	INT		NOT NULL,
	"PRICE"	INT		NULL,
	"CNT"	INT	DEFAULT 1	NULL
);

CREATE TABLE "CATEGORY" (
	"CATEGORY_ID"	INT		NOT NULL,
	"CATEGORY_GROUP_ID"	INT		NOT NULL,
	"DETL_NAME"	VARCHAR(30)		NOT NULL
);

CREATE TABLE "BOARD" (
	"BOARD_ID"	INT		NOT NULL,
	"MEMBER_NO"	INT		NOT NULL,
	"ITEM_ID"	INT		NOT NULL,
	"FILE_GROUP_ID"	VARCHAR(30)		NOT NULL,
	"TYPE"	VARCHAR(1)		NOT NULL,
	"TITLE"	VARCHAR(100)		NOT NULL,
	"RGSR_DATE"	DATETIME	DEFAULT NOW()	NULL,
	"CONTENT"	VARCHAR(300)		NOT NULL,
	"RATE"	INT	DEFAULT -1	NULL
);

COMMENT ON COLUMN "BOARD"."MEMBER_NO" IS 'SEQUENCE 1~';

CREATE TABLE "COMMENTS" (
	"COMMENT_ID"	INT		NOT NULL,
	"ADMIN_NO"	INT		NOT NULL,
	"BOARD_ID"	INT		NOT NULL,
	"CONTENT"	VARCHAR(300)		NOT NULL,
	"RGSR_DATE"	DATETIME	DEFAULT NOW()	NULL
);

CREATE TABLE "ADMIN" (
	"ADMIN_NO"	INT		NOT NULL,
	"ADMIN_ID"	VARCHAR(15)		NOT NULL,
	"ADMIN_PW"	VARCHAR(150)		NOT NULL,
	"ADMIN_NAME"	VARCHAR(15)		NOT NULL,
	"AUTH"	INT	DEFAULT 1	NULL
);

CREATE TABLE "CART" (
	"CART_ID"	INT		NOT NULL,
	"MEMBER_NO"	INT		NOT NULL,
	"ITEM_ID"	INT		NOT NULL,
	"CNT"	INT	DEFAULT 1	NULL,
	"RGSR_DATE"	DATE	DEFAULT NOW()	NULL
);

COMMENT ON COLUMN "CART"."MEMBER_NO" IS 'SEQUENCE 1~';

CREATE TABLE "NOTICE" (
	"Key"	VARCHAR(255)		NOT NULL,
	"ADMIN_NO"	INT		NOT NULL,
	"FILE_GROUP_ID"	VARCHAR(30)		NOT NULL,
	"TYPE"	VARCHAR(1)		NOT NULL,
	"TITLE"	VARCHAR(200)		NOT NULL,
	"WRITER"	VARCHAR(15)		NOT NULL,
	"CNT"	INT	DEFAULT 0	NULL,
	"RGSR_DATE"	DATE	DEFAULT NOW()	NULL
);

CREATE TABLE "ADDRESS" (
	"ADDR_ID"	INT		NOT NULL,
	"MEMBER_NO"	INT		NOT NULL,
	"RECIPIENT_NAME"	VARCHAR(15)		NOT NULL,
	"ZIP_CODE"	VARCHAR(6)		NOT NULL,
	"RECIPIENT_ADDR"	VARCHAR(300)		NOT NULL,
	"ADDR_DETL"	VARCHAR(100)		NOT NULL,
	"RECIPIENT_PHONE"	VARCHAR(15)		NOT NULL,
	"REQ"	VARCHAR(100)	DEFAULT '조심히 안전하게 와주세요'	NULL,
	"DEF"	VARCHAR(1)	DEFAULT 'N'	NULL
);

CREATE TABLE "ORDER_DETL" (
	"ORDER_DETL_ID"	INT		NOT NULL,
	"ORDER_ID"	INT		NOT NULL,
	"ITEM_ID"	INT		NOT NULL,
	"PRICE"	INT		NULL,
	"CNT"	INT	DEFAULT 1	NULL
);

ALTER TABLE "ORDER" ADD CONSTRAINT "PK_ORDER" PRIMARY KEY (
	"ORDER_ID"
);

ALTER TABLE "MEMBER" ADD CONSTRAINT "PK_MEMBER" PRIMARY KEY (
	"MEMBER_NO"
);

ALTER TABLE "ITEM" ADD CONSTRAINT "PK_ITEM" PRIMARY KEY (
	"ITEM_ID"
);

ALTER TABLE "CATEGORY_GROUP" ADD CONSTRAINT "PK_CATEGORY_GROUP" PRIMARY KEY (
	"CATEGORY_GROUP_ID"
);

ALTER TABLE "ITEM_FILE_GROUP" ADD CONSTRAINT "PK_ITEM_FILE_GROUP" PRIMARY KEY (
	"FILE_GROUP_ID"
);

ALTER TABLE "ITEM_FILE" ADD CONSTRAINT "PK_ITEM_FILE" PRIMARY KEY (
	"FILE_ID"
);

ALTER TABLE "WISH" ADD CONSTRAINT "PK_WISH" PRIMARY KEY (
	"WISH_ID"
);

ALTER TABLE "CATEGORY" ADD CONSTRAINT "PK_CATEGORY" PRIMARY KEY (
	"CATEGORY_ID"
);

ALTER TABLE "BOARD" ADD CONSTRAINT "PK_BOARD" PRIMARY KEY (
	"BOARD_ID"
);

ALTER TABLE "COMMENTS" ADD CONSTRAINT "PK_COMMENTS" PRIMARY KEY (
	"COMMENT_ID"
);

ALTER TABLE "ADMIN" ADD CONSTRAINT "PK_ADMIN" PRIMARY KEY (
	"ADMIN_NO"
);

ALTER TABLE "CART" ADD CONSTRAINT "PK_CART" PRIMARY KEY (
	"CART_ID"
);

ALTER TABLE "NOTICE" ADD CONSTRAINT "PK_NOTICE" PRIMARY KEY (
	"Key"
);

ALTER TABLE "ADDRESS" ADD CONSTRAINT "PK_ADDRESS" PRIMARY KEY (
	"ADDR_ID"
);

ALTER TABLE "ORDER_DETL" ADD CONSTRAINT "PK_ORDER_DETL" PRIMARY KEY (
	"ORDER_DETL_ID"
);
```
