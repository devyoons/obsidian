# 강의: 3주차 수업 기반 과제

## 강의 내용

**평가기준(준거)**

평가 기준은 요구사항의 주제 - 요구사항 - Usecase Diagram의 일관성이 중요합니다.요구사항은 최소 20개를 기준으로 평가 됩니다.

**과제설명**

안녕하세요전혜영 교수 입니다.

이번 학기 과제는 총 2회로 진행됩니다.

1차 과제 내용을 공지 하겠습니다.

과제는 3주차 내용을 기반으로 합니다.

1. 개별 소프트웨어를 개발할 수 있는 자유 주제 선정

(ex) 학생에게 서비스할 성적 확인 프로그램)

2. 주제를 기반으로 한 요구사항 정의 

(주어, 동사가 명확한 요구사항 정의)

3. Usecase Diagram 작성

(종이로 그려도 되고 툴을 사용해도 상관없음)

제출 형식은 상관 없으나 3장 이상의 문서 형태제출 문서는 학번_학과_이름.pdf로 제출제출 마감일을 꼭 지켜 주시기 바랍니다.
