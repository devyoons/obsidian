# 학습: 노션 단축키

## 세부 내용

### 기본

| **Win** | **Mac** | **기능** |
| --- | --- | --- |
| `Ctrl` + `N` | `Cmd` + `N` | 새 페이지 생성하기 |
| `Ctrl` + `Shift` + `P` | `Cmd` + `Shift` + `P` | 페이지 이동하기(옮기기) |
| `Ctrl` + `P` or `K` | `Cmd` + `P` or `K` | 빠른 검색 |
| `Ctrl` + `[` or `]` | `Cmd` + `[` or `]` | 뒤로가기 / 앞으로 가기 |
| `Ctrl` + `Shift` + `L` | `Cmd` + `Shift` + `L` | 다크모드 / 라이트모드 |
| `Ctrl` + `\` | `Cmd` + `\` | 사이드 바 보이기/닫기 |
| `Ctrl` + `Alt` + `T` | `Cmd` + `Option` + `T` | 모든 토글 닫기/열기 |
| `Ctrl` + `L` | `Cmd` + `L` | 현재 페이지 링크 복사 |
| `Ctrl` + `+` or `-` | `Cmd` + `+` or `-` | 페이지 확대/축소 |
| `Ctrl` + `0` | `Cmd` + `0` | 페이지 원본 비율 |

| `Ctrl` + `Shift` + `5` | `Cmd` + `Option`+ `5` | `-` + `Spacebar` | 글머리기호 목록 블록으로 변경 |

### 블록을 선택한 상태

| Win | Mac | 기능 |
| --- | --- | --- |
| `Ctrl` + `Enter` | `Cmd` + `Enter` | 전체 화면, 할 일 목록 체크 완료/해제, 토글 목록 열기/닫기 |
| `Ctrl` + `Shift` + ⬆️⬇️ | `Cmd` + `Shift` + ⬆️⬇️ | 블록 위치 위/아래 이동 |
| `Ctrl` + `Shift` + `Enter` | `Cmd` + `Shift` + `Enter` | (페이지 블록 선택 후) 새 탭에서 페이지 열기 |
| `Ctrl` + `Shift` + `R` | `Cmd` + `Shift` + `R` | (페이지 블록 선택 후) 페이지 블록 이름 변경 |
| ⬅️, ➡️, ⬇️, ⬆️ | ⬅️, ➡️, ⬇️, ⬆️ | 커서 이동 |
| `Ctrl` + `A` | `Cmd` + `A` | 페이지 내 모든 블록 선택 |
| `Shift` + 🖱 | `Shift` + 🖱 | 여러 블록 선택 |
| `Ctrl` + 🖱 | `Cmd` + 🖱 | 새 탭에서 페이지 열기 |
| `ESC` | `ESC` | 블록 선택 해제 |
| `Delete` | `Delete` | 선택한 블록 삭제 |
| `Ctrl` + `D` | `Cmd` + `D` | 선택한 블록 복제 |
| `Spacebar` | `Spacebar` | (이미지 블록 선택 후) 이미지 미리보기 |
