- 기본값 지정
    - 해당 인덱스에 값이 없는 경우에만 기본값을 사용한다.
    
    ![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/131494ab_Untitled.png]]
    
    해당하는 값이 없다면 undefined가 들어가는데 이럴때 기본값을 미리 세팅해두면 에러를 방지할 수 있다.
    
```jsx
const alpha = ['a', 'b','c'];
const [k, l, m = 'x', n = 'd'] = alpha;
console.log(k, l, m, n);

alpha[2]에는 'c'라는 값이 있기 때문에 기본값으로 지정한 'x'는 사용하지 않는다.
alpha[3]은 값이 없기 때문에 기본값으로 지정한 'd'가 사용된다.
```

- 나머지 파라미터 rest parameter
- 구조분해할당 마지막에만 사용가능
    - q배열에 담기!

```jsx
const [o, p, ...q] = [1, 2, 3, 4];
console.log(o, p, q); // 1, 2, [3, 4]

// 전개 연산자 spread operator(값)
// q의 요소를 뿌리기
const other = [...q];
console.log(q, other, q === other); 
// (2) [3, 4] 
// (2) [3, 4] false
console.log([...alpha, ...q]); //(5) ['a', 'b', 'c', 3, 4]
console.log(alpha.concat(q)); //(5) ['a', 'b', 'c', 3, 4]
```

#### @실습문제

- 리턴구문에서 구조분해 할당
- calc 호출결과 두 수의 합,차,곱,몫,나머지를 리턴하고 호출부 변수에 담아 출력.
- 

```jsx
const [...result] = calc(10, 3); // 나머지 파라미터를 사용
console.log(...result);

const [add, subtract, multiply, divide, remainder] = calc(10, 3); // 이렇게 해야함
console.log(add, subtract, multiply, divide, remainder);

};
const calc = (a, b) => {
    return [a + b, a - b, a * b, Math.floor(a/b), a % b];
};
//나머지 파라미터를 사용하면 결과값이 배열
13 7 30 3 1
```

#### 중첩객체를 구조분해할당하기

- name, sns 변수를 선언한게 아니라 접근하기 위한 것
    - 실제로 console.log(name); 하면 window객체 name이 출력된다.

```jsx
const test4 = () => {
   const user = {
       id : 'honggd',
       name : {
           firstName : '길동',
           familyName : '홍'
          },
          age : 33,
          sns : ['facebook', 'twitter', 'instagram']
  }

  const {id, name : {firstName}, sns : [,mainSns]} = user; 
  // name이 객체이기때문에 다시한번 그 안에서 구조분해할당
	// 배열에 대한 구조분해할당
  console.log(id, firstName, mainSns); //honggd 길동 twitter
};
```

#### 리턴값 처리

- 화살표 함수에서 객체를 리턴하는 경우
- ({}) 형태로 처리

```jsx
const {} = getKHInfo();
const getKHInfo = () => ({a:1, b:2});
```

- 교육원명, url, 대표전화1개, 종로 지원의 주소

```jsx
const getKHInfo = () => ({
     name : 'KH정보교육원',
     url : 'https://iei.or.kr',
     tel : ['070-1234-1234','070-2345-2345'],
     addr : {
         '강남 지원' : '서울시 강남구',
         '종로 지원' : '서울시 종로구',
         '당산 지원' : '서울시 영등포구'
     }
});

// 교육원명, url, 대표전화1개, 종로 지원의 주소
// tel은 중복된게 아님
// addr 키값을 동일하게 작성해야함.
const {name, url, tel : [tel], addr : {'종로 지원': jongro}} = getKHInfo();
console.log(name, url,tel, jongro); 
// KH정보교육원 https://iei.or.kr 070-1234-1234 서울시 종로구
```
