### 자바스크립트 엔진

---

- 자바스크립트는 싱글스레드로 처리된다.
    - 동기 synchronous
    - 비동기 asynchronous
- 비동기처리함수(Timer API, DOM처리, Event처리, Ajax(XMLHttpRequest))를 만날때만 백그라운드(Web APIs)로 처리를 위임.
- 콜스택의 동기적작업이 완료되면 콜백함수를 실행하는 구조
    - heap
    - call stack
    - Web APIs
    - Callback Queue : EventLoop에 의해서 call stack이 비워질때 순차적(FIFO)을 실행

프로미스는 자바스크립트 비동기 처리에 사용되는 객체이다.

자바스크립트의 비동기 처리란?

- ‘ **특정 코드의 실행이 완료될 때까지 기다리지 않고 다음 코드를 먼저 수행하는 자바스크립트의 특성**’을 의미
- **비동기적인것을 수행할 때 콜백함수 대신에 사용하는것.**
    - callback hell을 제거, 아래로 코드를 연이어 작성할 수 있다.(가독성, 유지보수좋음)
- **`Primise`**는 **producer와 consumer코드를 연결해주는 객체**
    - **producer(생산자) code** 비동기 : 제작 코드 : 정보를 제공하는
    - **consumer(소비자) code** 콜백 : 소비 코드 : 정보를 소비하는
- then 프라미스를 리턴하므로 이후 실행코드는 다시 then절 작성가능하다.

#### 1. Promise 만들기

- **새로운 Promise 를 만드는 순간 전달한 콜백함수가 바로 실행된다.**
    - 네트워크를 통신하는 코드를 작성했다면 Promise가 만들어지는 순간 바로 네트워크 통신을 수행하게 된다 .
    - 만약 네트워크 요청을 사용자가 요구했을 때만 네트워크 요청을 해야한다면 이렇게 작성하면 바로 실행된다는 점 유의하기

#### promise 문법

```jsx
const promise = new Promise((resolve, reject) => {
	console.log('Producing.....');
}
```

```jsx
const promise = new Promise(function(resolve, reject) {
  // executor (제작 코드, '가수')
});
```

`new Promise`에 전달되는 함수는 *executor(실행자, 실행 함수)* 라고 부릅니다. 

executor는 `new Promise`가 만들어질 때 자동으로 실행되는데, 결과를 최종적으로 만들어내는 제작 코드를 포함합니다. 위 비유에서 '가수’가 바로 executor입니다.

- `resolve(value)` : 일이 성공적으로 끝난 경우 그 결과를 나타내는 `value`와 함께 호출
    - resolve 코드예시
        
        ```jsx
        const promise = new Promise(function(resolve, reject) {
          // 프라미스가 만들어지면 executor 함수는 자동으로 실행됩니다.
        
          // 1초 뒤에 일이 성공적으로 끝났다는 신호가 전달되면서 result는 '완료'가 됩니다.
          setTimeout(() => resolve("완료"), 1000);
        });
        ```
        
        ![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/8bc9c099_Untitled.png]]
        
- `reject(error)` : 에러 발생 시 에러 객체를 나타내는 `error`와 함께 호출
    - reject 코드예시
        
        ```jsx
        const promise = new Promise(function(resolve, reject) {
          // 1초 뒤에 에러와 함께 실행이 종료되었다는 신호를 보냅니다.
          setTimeout(() => reject(new Error("에러 발생!")), 1000);
        });
        
        // 1초 후 reject(...)가 호출되면 promise의 상태가 "rejected"로 변합니다.
        ```
        
        ![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/af053eee_Untitled.png]]
        

#### 2. promise의 3가지 상태(states)

- `new promise()` 로 promise를 생성하고 종료될 때까지 3가지 상태를 갖는다.
    - Pending : 비동기 처리 로직이 아직 완료되지 않은 상태
    - Fulfilled : 비동기 처리가 완료되어 프로미스가 결과 값을 반환해준 상태
    - Rejected : 비동기 처리가 실패하거나 오류가 발생한 상태
    
    ![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/aba9290b_Untitled.png]]
    
    | status | pending(대기) | 정상처리 fullfilled (이행) |
    | --- | --- | --- |
    |  |  | 오류 rejected(실패) |
    | result | undefined | 정상처리시 value |
    |  |  | 오류 예외객체 |

### 소비자 : then, catch, finally

- 프라미스 객체는 executor와 결과나 에러를 받을 소비 함수를 이어주는 역할을 함.
- 소비함수는 `.then` `.catch` `.finally` 메서드를 사용해 등록된다.

#### Promise Chain

- Promise#then는 promise객체를 리턴한다.
- promise#then안에서 명시적으로 Promise객체를 리턴할 수 있다.
- Promise#then에서 값을 리턴하면 암묵적 Promise객체의 result값이 된다.
