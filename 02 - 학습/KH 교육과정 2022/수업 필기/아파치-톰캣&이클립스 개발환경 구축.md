## ✔개발환경 구축 순서

---

1. [https://tomcat.apache.org/download-80.cgi](https://tomcat.apache.org/download-80.cgi) 아파치 톰캣 사이트 접속
2. Download - Tomcat 버전 선택 후 해당zip 다운로드
3. D 드라이브의 dev 폴더에 압축 풀기
4. 이클립스에 설치한 톰캣의 경로로 서버런타임 등록
5. 테스트 서버 생성 후 실행
6. 정상 start up 확인

### 📍톰캣 다운로드 + 이클립스

---

#### Directory

| bin | 톰캣을 실행하고 종료시키는 스크립트 파일(bat, sh)이 위치 |
| --- | --- |
| conf | server.xml, web.xml 등 설정파일이 위치 |
| lib | 톰켓을 실행하는데 필요한 라이브러리파일(.jar)위치 |
| logs | 톰캣 로그파일이 위치 |
| temp | 톰켓이 실행되는 동안 임시파일이 위치 |
| webapps | 웹 어플리케이션 위치, 웹 어플리케이션이 저장되는 위치 |
| work | 톰캣이 실행되는 동안 사용되는 작업파일이 위치 |

#### 환경설정

| web.xml | 웹 어플리케이션에 대한 설정파일 (배포서술자 DD:Deployment Descriptor |
| --- | --- |
| server.xml | 메인 환경설정파일, Service, connector, Host 등 설정 |
| catalina.policy | 보안정책설정파일, JVM에 의해서 웹어플리케이션에 강제적으로 보안정책 권한을 설정 |
| catalina.properties | 서버를 시작할때 검색하는 서버 설정 공유로더 , jar등의 공유 정보 |
| tomcat-users.xml | 사용자 권한과 인증번호를 설정, 톰캣 관리자를 사용할 때 활용되는 정보로서 기본적으로 주석처리 |
| logging.properties | 톰켓인스턴스의 로깅설정 파일, 기본적으로 4가지 로그 파일 설정 |
| context.xml | 세션, 쿠키 저장 경로를 지정하는 설정파일 |

### 📍웹 프로젝트 서버에 등록하기

---

1. **Java EE 모드 →** **package Explorer → new → Dynamic Web Project 생성**

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/57266b50_Untitled.png]]

1. **프로젝트 이름 설정 → Target runtime을 이전에 생성한 서버로 설정 후 next**
    - Dynamic web module version : servlet spec (현재 9.대 버전을 사용해서 4.0으로 설정)

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/c74fcf86_Untitled.png]]

1. **확인 후 next**
    - .java파일들이 src\main\java디렉토리에서 관리되며
    - .java파일이 컴파일되면 build\classes경로에 저장됨.

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/4f6401e9_Untitled.png]]

1. **브라우저에서 접속할 이름 :** Context root의 이름을 웹 서버를 호출할 별칭으로 변경
    - context-path
    - context-root
    - application name
    - aplication alias
    
2. **Content Directory 를 web으로 변경**
    - 체크박스를 체크하여 웹 프로젝트 기본 설정 파일인 web.xml 생성 → finish

1. **Web 프로젝트가 생성된 것을 확인하고, 서버 우클릭하여 해당 프로젝트 추가**
    - 지역서버와 연결되서 서버 하위에 생성된 것을 확인할 수 있다.

### 💥서버 등록하면서 ! 오류날시 (참조하고있는환경문제)

1. 프로젝트 우클릭 Properties(속성)
    1. Java Bulid Path → Libraries JRE 버전확인 
        1. 버전이 잘못되어있으면 삭제한다. Remove
    2. 잘못된 버전 삭제 후 Modulepath 에서 Add Library...
    3. JRE System Library → next
    4. Workspace 기본값으로 설정되어있는 JRE를 사용한다는 항목에 체크 후 finish → Apply
2. 프로젝트 우클릭 Properties(속성)
    1. Project Facets → Dynamic Web Module 버전 확인( 위 설정으로는 4.0이어야함)
    2. Project Facets → Java 버전 11로 변경
3. web.xml 오류나면 코드중 <web-app ....>이 부분 alt + 위아래로 움직이고 저장해보기
    1. http → https
