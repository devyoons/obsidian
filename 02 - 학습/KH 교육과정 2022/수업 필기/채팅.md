### ✔웹소켓 나오기전에 썼던 방식

#### polling

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/ebac015b_Untitled.png]]

- 클라이언트가 서버로 비동기통신을 계속 보내서 서버에 변경사항을 알 수 있는 방법을 사용했었음.
- 서버쪽에 부하가 엄청 많이 걸리는 방법임
- 더 골치아픈건 클라이언트가 하나가 아님

#### long-polling

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/9e4b92a7_Untitled.png]]

- 원하고자 하는 데이터가 존재할 때까지 무한반복을 돌리는 방법
- 요청수는 줄어들지만 서버 쪽 부하는 동일함

#### streaming

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/b9f2a859_Untitled.png]]

- 응답을 쪼개서 계속 보냄

### 웹소켓 http방식

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/449506ae_Untitled.png]]

- http를 **프로토콜을 승격시킴 ( http:// —→ ws://)**
- 서로간의 **소켓이 연결을 유지**하고 있음.

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/4fb942c6_Untitled.png]]

- 내 메세지를 보내면 채팅방 사람들에게 뿌려짐.
- 하나의 클라이언트에게 받은 메세지를 서버가 여러 클라이언트에게 뿌려줌.

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/98ae1d27_Untitled.png]]

- 웹소켓통신이 맺어졌다고 했을 때
- 각각의 이벤트 기반으로 처리
    1. 처음 웹소켓이 맺어지면 open 이벤트 발생
    2. 상대한테 메세지를 받게되면 message 이벤트 발생
        1. 서버는 클라이언트에게 메세지를 받게되면 message이벤트 발생
    3. error 이벤트
    4. 웹소켓이 끊기면 close 이벤트 발생
- 클라이언트는 js를 통해 이벤트 발생
    - ws.onopen
    - ws.onmessage
    - ws.onerror
    - ws.onclose
- 서버는 @ServerEndPoint 어노테이션
    - @OnOpen
    - @OnMessage
    - @OnError
    - @OnClose

### chat/ws/HelloWebSocketConfigurator클래스

---

- Configurator클래스는 @ServerEndpoint 클래스 설정정보를 작성하는 클래스
- modifyHandshake메소드를 override해서 httpSession객체에 접근할 수 있다.

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/88cc47e5_Untitled.png]]

- 아래 코드 
userProps 에 로그인멤버 정보가 들어오고 HelloWebSocket에 있는 OpOpen 이벤트로 넘어감.

```java
package chat.ws;

import java.util.Collections;
import java.util.HashMap;
import java.util.Map;

import javax.websocket.EndpointConfig;
import javax.websocket.OnClose;
import javax.websocket.OnError;
import javax.websocket.OnMessage;
import javax.websocket.OnOpen;
import javax.websocket.Session;
import javax.websocket.server.ServerEndpoint;

@ServerEndpoint(
		value = "/chat/ws", 
		configurator = HelloWebSocketConfigurator.class // 웹소켓 설정정보 관리
		)
public class HelloWebSocket {
	
	// client map객체를 동기화처리(멀티스레딩 환경에서 안전하게 사용할 수 있도록 함.)
	public static Map<String, Session> clients = Collections.synchronizedMap(new HashMap<>());
	
	@OnOpen
	public void onOpen(EndpointConfig config, Session session) {
		System.out.println("[Open]");	
		
		// 1. 사용자정보 복사 EndpointConfig -> Session
		Map<String, Object> ConfigUserProps = config.getUserProperties();
		String memberId = (String) ConfigUserProps.get("memberId");
		Map<String, Object> sessionUserProps = session.getUserProperties();
		sessionUserProps.put("memberId", memberId);
		
		// 2. clients에 추가
		clients.put(memberId, session);
		
	}
	@OnMessage
	public void OnMessage(String payload, Session session) {
		System.out.println("[Message]");	
	}
	@OnError
	public void OnError(Throwable e) {
		e.printStackTrace();
	}
	@OnClose
	public void onClose(Session session) {
		System.out.println("[Close]");	
		
		// 1. 사용자정보 가져오기
		Map<String, Object> sessionUserProps = session.getUserProperties();
		String memberId = (String) sessionUserProps.get("memberId");
		
		// 2. clients에서 제거
		clients.remove(memberId);
	}

}
```

```java
package chat.ws;

import java.io.IOException;
import java.util.Collection;
import java.util.Collections;
import java.util.HashMap;
import java.util.Map;

import javax.websocket.EndpointConfig;
import javax.websocket.OnClose;
import javax.websocket.OnError;
import javax.websocket.OnMessage;
import javax.websocket.OnOpen;
import javax.websocket.RemoteEndpoint.Basic;
import javax.websocket.Session;
import javax.websocket.server.ServerEndpoint;

import com.google.gson.Gson;

@ServerEndpoint(
		value = "/chat/ws", 
		configurator = HelloWebSocketConfigurator.class // 웹소켓 설정정보 관리
		)
public class HelloWebSocket {
	
	// client map객체를 동기화처리(멀티스레딩 환경에서 안전하게 사용할 수 있도록 함.)
	public static Map<String, Session> clients = Collections.synchronizedMap(new HashMap<>());
	
	@OnOpen
	public void onOpen(EndpointConfig config, Session session) {
		System.out.println("[Open]");	
		
		// 1. 사용자정보 복사 EndpointConfig -> Session
		Map<String, Object> ConfigUserProps = config.getUserProperties();
		String memberId = (String) ConfigUserProps.get("memberId");
		Map<String, Object> sessionUserProps = session.getUserProperties();
		sessionUserProps.put("memberId", memberId);
		
		// 2. clients에 추가
		clients.put(memberId, session);
		
		// 3. 사용자 입장 메세지 출력
		String payload = convertJsonPayload("welcome", memberId, "님이 입장했습니다.");
		onMessage(payload, session);
	}
	
	/**
	 * Map -> json 변환
	 * @param string
	 * @param memberId
	 * @param string2
	 * @return
	 */
	private String convertJsonPayload(String type, String sender, String msg) {
		Map<String, Object> map = new HashMap<>();
		map.put("type", type);
		map.put("sender", sender);
		map.put("msg", msg);
		map.put("time", System.currentTimeMillis());
		return new Gson().toJson(map);
	}
	@OnMessage
	public void onMessage(String payload, Session sess) {
		System.out.println("[Message]");	
		
		Collection<Session> sessions = clients.values();
		for(Session session : sessions) {
			Basic basic = session.getBasicRemote();
			try {
				basic.sendText(payload);
			} catch (IOException e) {
				e.printStackTrace();
			}
			
		};
	}
	@OnError
	public void OnError(Throwable e) {
		e.printStackTrace();
	}
	@OnClose
	public void onClose(Session session) {
		System.out.println("[Close]");	
		
		// 1. 사용자정보 가져오기
		Map<String, Object> sessionUserProps = session.getUserProperties();
		String memberId = (String) sessionUserProps.get("memberId");
		
		// 2. clients에서 제거
		clients.remove(memberId);
	}

}
```
