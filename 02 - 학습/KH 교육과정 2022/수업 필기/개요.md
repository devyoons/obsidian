## 클라이언트 주요언어

- **`HTML`** : 하이퍼텍스트를 구현하기 위한 뼈대가 되는 핵심적인 기술인 마크 업 언어
- **`CSS`** : HTML은 뼈대이고, 자바스크립트가 기능이라면, CSS는 꾸미기 위한 옷의 기능
- **`자바스크립트(JavaScript)`** : 로컬의 브라우저에서 실행되는 인터프리터 방식의 프로그래밍 언어
- **`jQuery`** : 자바스크립트의 코드가 길어지면 사용하기 복잡해지는 단점을 파격적으로 개선한 존 레식(John Resig)이 창안한 자바스크립트 기반의 **라이브러리** 중 하나(jquery는 주요언어는 아니고 자주 사용하는 자바스크립트인 외부 라이브러리임)

## 서버 주요 언어

- **`JSP` :** 운영체제의 구애를 받지 않으며 실행된다. 톰캣(Tomcat) 컨테이너 위에서 자바 기반의 언어를 사용한다.
- **`ASP` :** 윈도우 기반의 IIS 서버에서만 동작한다. MS-SQL DBMS와 연동된다.
- **`PHP`** : 리눅스 기반에 아파치(Apache) 서버에서 동작한다. 기존에 제로보드나 그누보드와 같은 사이트 빌더에서 기본적으로 사용되는 언어
- **`node.js` :** 흔히 “노드제이에스” 또는 “노드”라고 하는 자바스크립트 라이브러리로서, 소켓을 이용하여 쉽게 실시간 서버를 구축 가능하도록 한다.

## 개요

#### Javascipt란

- 자바스크립트는 웹 브라우저에서 많이 사용하는 **인터프리터 방식의 객체지향 프로그래밍 언어**이다.
    - compile : source(ex.java) → object (ex.class)
    - interpreter : source가 곧 목적 코드(실행하면서 한 줄 한줄 기계어로 변환되므로 별도의 기계어코드가 없음)
        - 웹 브라우저에 내장되어 있는 자바스크립트 파서가 소스 코드를 한 줄씩 읽고 해석한다는 점에서 인터프린터 방식으로 소스를 해석하기 때문에 전체를 해석해 놓은 컴파일 언어와는 차이가 있다. **자바스크립트 실행은 작성된 html문서를 브라우저에서 읽어 들이면 바로 실행을 확인할 수 있다는 것**
    - prototype 방식의 객체지향언어
- 자바스크립트는 ECMA스크립트 표준을 따르는 대표적인 웹 기술이다.(에크마스크립트)
    - ECMA (European Computer Manufacturers Association) : 표준화기구
    - ES6 , ECMA2015 ⇒ 자바스크립트를 가르키는 말

#### 스크립트 언어란

- 다른 언어를 제어하는 언어
- 매우 빠르게 배우고 작성하기 위해 고안되었고 짧은 소스코드파일이나 REPL(Read Eval Print Loop)로 상호작용 (주고 받으면서 하는 프로그램)
- 기본 프로그램의 동작을 사용자의 요구에 맞게 수행되도록 해주는 용도로 주로 사용

#### 클라이언트 사이드 스크립트

- 클라이언트, 즉 사용자 컴퓨터에서 처리되는 스크립트
- 종류 : Javascript, VBscript, Jscript

#### 서버 사이드 스크립트

- 정보를 제공하는 서버쪽 컴퓨터에서 처리되는 스크립트
- 종류 : ASP, PHP, JSP, Perl, 파이썬, Node.js 등

## 작성 및 실행

#### 브라우저 개발자 도구

- 브라우저별 개발자 도구 (Develop Tools)가 있음
- 크롬/IE 브라우저 F12키 눌러서 실행
- 브라우저 창에서 원하는 코드를 확인하고 싶으면 원하는 위치에서 우 클릭 후 해당메뉴선택
(크롬 : 검사 / IE : 요소검사)
- 자바스크립트 소스코드 중 console.log()는 브라우저에 출력하는 것이 아니라 개발자 도구의 console패널에서 출력
- 스크립트 구문을 디버깅할 때 자주 사용

## 작성 및 실행

#### 자바스크립트 선언

```jsx
<script type=“text/javascript”>
자바스크립트내용
</script>
```

- **`<script></script>`** 태그 사이에 자바스크립트 코드 문장을 작성하면 된다.
- HTML에서 제공하는 **`<script></script>`** 태그를 사용하여, 자바 스크립트 작성영역을 설정
- type속성 브라우저 호환성을 위해 사용되나 default값으로 생략 가능
- language속성과 charset속성이 있었지만 language속성은 폐기되고 charset속성은 meta 태그가적용되기 때문에 사용할 필요가 없음.

#### 자바스크립트 위치

```jsx
	<script>자바스크립트 내용</script>
<html>
	<head><script>자바스크립트 내용</script></head>
	<body><script>자바스크립트 내용</script></body>
</html>
	<script>자바스크립트 내용</script>
```

- **`<script></script>`** 는 <head>,<body>안 어느 영역에나 작성 가능
- HTML태그 영역 밖에 작성 가능, 하지만 웹 표준과 웹 접근성을 고려해서 <head>나 <body>에 작성

#### 브라우저에서 Javascript를 사용하는 3가지 방법

1. external 방식 : 외부 파일로 script 작성하고 가져와 사용
    1. **`<script scr = “경로”>`** 태그를 이용하여 내용을 삽입 후 사용 → 위치는 <head>태그안에 주로 사용하고 코드는 위에서 아래로 실행하기 때문에 불러오는 위치가 중요함
2. internal 방식 : HTML파일 내 자바스크립트소스를 작성 
    1. 위치는 <head>,<body>태그 안에 작성
    2. **`<script>실행할 소스코드 작성</script>`**
3. inline 방식 : 태그에 이벤트 핸들러 속성을 이용하여 직접 실행 코드 작성(html 이벤트 속성)
    1. **`<태그명 on이벤트 = “함수명();”>`**
- 자바스크립트가 지원되지 않는 브라우저를 대비 지원하지 않는 경우 <noscript>에 작성된 내용이 출력
    - **`<noscript>지원하지 않을 경우 출력문구</noscript>`**

## 데이터 출력

- **`document.write(내용);`**  : 브라우저 화면상의 페이지에 값을 출력한다.
- **`window.alert(내용);` :** 내용을 메세지창에 출력한다. → window객체는 모두 적용되는 것으로 생략가능 ****
- **`innerHTML = 내용;` :** 태그 앨리먼트의 내용을 변경하여 출력한다.
- **`console.log(내용);`** : 개발자도구 화면의 콘솔에 출력한다. (개발자용)

## 데이터 입력

### 데이터 입력방법

- 자바스크립트 내장객체인 window 객체가 제공하는 confirm(), prompt() 메소드를 사용하여 입력 받는 방법
- HTML 태그에 접근하여 대상의 값을 읽는 방법
- HTML form 태그의 input 입력양식을 통해 값을 입력 받는 방법

#### **`window.confirm()`** : 확인 받음

- 어떤 질문에 대해 **“예/아니오”의 결과**를 얻을 때 사용
- 대화창에 메세지와 **확인, 취소버튼 표시**
- 리턴 값 : 확인(true), 취소(false)
- **`var 변수 = [window.]confirm(”질문내용”);`**

#### **`window.prompt()`** : 입력 받음

- 사용자로부터 한 줄짜리 입력값을 받는 메소드
- 텍스트필드, 확인/취소버튼을 제어
- 리턴값 : 확인시 입력값 (string)이 리턴, 취소시 null이 리턴
- **`var 변수 = [window.]prompt(”메세지”, “입력받을 default값 (생략가능)”)`**;

### 메소드

- **`getElementById(”아이디명”)`** : **태그의 id 속성 값**을 이용해서 태그 **HTML요소(element) 객체 정보**를 가져온다.
    - 리턴 값 : 단일 값(id는 중복 허용 안됨)
    - 변수는 객체를 의미하는 레퍼런스 변수(객체.항목.속성)
    - 성능상 가장 우수
- **`getElementsByName(”이름”)`** : **태그의 name 속성 값**을 이용해서 태그 **HTML요소(element)의 객체 정보를 배열(가짜)**에 담아서 가져온다. (같은 이름의 태그가 여러 개 존재할 수 있기 때문에 배열로 리턴)
    - 리턴 값 : 배열(name은 중복가능)
    - 변수는 배열이 됨
    - input/select 태그를 배열로 반환(이렇게 자주사용)
    - 매칭되는 태그가 없을 때 빈 배열로 반환(null반환하는게 아님)
- **`getElementsByTagName(”태그명”)`** : **태그명**을 이용해서 해당 태그들의 **객체 정보를 배열(가짜)**에 담아서 가져온다.
    - 리턴 값 : 배열(태그 중복가능)
    - 변수는 배열이 됨

```jsx
document.getElementsByTagName('태그명')
// 해당 태그명을 가진 모든 태그들을 반환하기 때문에 그 중 일부를 가져오는 방법이 필요하다.
<!DOCTYPE html>
<html>
<body>
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
<script>
    var ul = document.getElementsByTagName('ul')[0];
    var lis = ul.getElementsByTagName('li');
    for(var i=0; lis.length; i++){
        lis[i].style.color='red';   
    }
</script>
</body>
</html>
//위의 태그를 통해 ul안에 있는 li만 가져온다.
```

- **`getElementsClassName(”클래스명”)`** : **class명**을 이용해서 HTML요소(element)의 **객체 정보를 배열(가짜)**에 담아서 가져온다.
- **`querySelector()`** : CSS 선택자를 이용해서 **선택자와 일치하는 하나의 요소 반환** (복수개에 해당하는 선택자여도 제일 첫 요소만 반환)

```jsx
const a = document.querySelector('.class');
const b = document.querySelector('#idName');
const c = document.querySelector('div');
const c = document.querySelector('[name=찾으려는name]');
```

- **`querySelectorAll()`** : CSS 선택자를 이용해서 **선택자와 일치하는 모든 요소를 유사배열에 반환**
