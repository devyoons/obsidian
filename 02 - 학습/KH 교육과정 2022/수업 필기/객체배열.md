## 객체배열

- // 반복문처리 ??가 짖습니다. 야옹!

```jsx
const test1 = () => {
    const pets = [];
    pets.push({
        name: '먼지',
        breed: '코리안숏헤어',
        weight: 4,
        age: 5,
        color : ["white"],
        bark(){
            console.log(this.weight < 5 ? '야옹' : '앩옹');
        }
    });
    pets.push({
        name: '탄이',
        breed: '뱅갈',
        weight: 5,
        age: 5,
        color : ["brown"],
        bark(){
            console.log(this.weight < 3 ? '야옹' : '앩옹');
        }
    });
    pets.push({
        name: '단지',
        breed: '아메리칸숏헤어',
        weight: 3,
        age: 1,
        color : ["white", "gray"],
        bark(){
            console.log(this.weight < 5 ? '야옹' : '앩옹');
        }
    });
    console.log(pets);

    // 반복문처리 ??가 짖습니다. 야옹!
    pets.forEach((pet, i) => {
        const {name} = pet;
        console.log(`${name}가 짖습니다.`);
        pet.bark();
    });
    
};
```

- 생성자 함수를 통한 객체 생성
- 생성자함수는 관례상 대문자로 시작하는 이름을 갖는다.
- this용법5. 생성자함수에서 this는 현재 객체를 가리킨다.
- 자바와 비슷해보이지만 자바와 구조가 다르다.

```jsx
const test2 = () => {
    const pets = [];
    pets.push(new Pet('먼지','코리안숏헤어', 4, 5, ['white']));
    pets.push(new Pet('탄이','뱅갈', 5, 5, ['brown']));
    pets.push(new Pet('단지','아메리칸숏헤어', 3, 1, ['gray']));

    console.log(pets);

    pets.forEach((pet, index) => {
        const info = `반려동물정보
---------------------------------
이름 : ${pet.name}
묘종 : ${pet.breed}
몸무게 : ${pet.weight}
나이 : ${pet.age}
색깔 : ${pet.color}
짖는 소리 : ${pet.bark()}    
---------------------------------`;
        alert(info);
    });
};

/**
 * 생성자함수는 관례상 대문자로 시작하는 이름을 갖는다.
 * this용법5. 생성자함수에서 this는 현재 객체를 가리킨다.
 */
function Pet(name, breed, weight, age, color){
    this.name = name;
    this.breed = breed;
    this.weight = weight;
    this.age = age;
    this.color = color;
    this.bark = function(){
        return this.weight < 5 ? '야옹' : '앩옹';
    };
};
```

#### 변수 → 객체

```jsx
// 변수 -> 객체
 const x = 10;
 const y = '안녕';
 const z = {x, y}; // 변수를 z에 객체로 변경
 console.log(x); // 10
 console.log(y); // 안녕
 console.log(z); // {x: 10, y: '안녕'}

```

## 생성자함수 - prototype - 객체

**자바스크립트 프로토타입 기반 상속모델을 가진 객체지향언어**

- 생성된 객체는 prototype과 연결된 프로토타입체인을 가진다.
- 자바에서는 자식객체에서 부모객체의 참조할 부분을 내부에 가지고 있는데 프로토타입은 따로 관리되서 성능상 프로토타입이 구조상 더 좋다.
- Object.prototype이 프로토타입 최상위에 위치한다.
- **`생성자 함수 Duck`**
- **`prototype 객체`**(부모객체처럼 생각해도 좋음)
- **`생성 객체 new Duck`**()

#### 프로토타입 체인(prototype chain)

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/bb90c1a9_Untitled.png]]

- pet 예습코드로 공통메소드 prototype객체에 작성해보기
- 공통메소드를 prototype객체(부모)에 작성하고, 자식객체들이 공유하도록

```jsx
        const info = `반려동물정보

몸무게 : ${pet.weight}
나이 : ${pet.age}
색깔 : ${pet.color}
짖는 소리 : ${pet.bark()}    
---------------------------------`;
        alert(info);
    });
};

function Pet(name, breed, weight, age, color){
    this.name = name;
    this.breed = breed;
    this.weight = weight;
    this.age = age;
    this.color = color;
    // this.bark = function(){
    //     return this.weight < 5 ? '야옹' : '앩옹';

// 공통메소드를 prototype객체(부모)에 작성하고, 자식객체들이 공유하도록
Pet.prototype.bark = this.weight < 5 ? '야옹' : '앩옹';
```
