#### 환경설정

1. 인코딩 환경 다시 설정
    1. 도구 → 환경 → 인코딩 → UTF-8 로 설정 
    
2. 주석 색상 변경, 글꼴 변경, 행여백여부
    1. 도구 → 코드 편집기 → PL/SQL 구문색상 → 기본 주석 → 주석색상변경
    2. 도구 → 코드 편집기 →  글꼴 → 글씨 크기, 글꼴 변경
    3. 도구 → 코드 편집기 → 행 여백 → 행번호표시 체크
    
3. 접속정보 
    1. 새접속 → oracle 기본 계정 (sys, system) 
    2. name : system → 컬러지정 → 비밀번호 지정(비밀번호저장)
    → 로컬호스트(내컴퓨터) → SID : ex(db이름) 

<aside>
💡 **sys계정은 super admin 이라 사용할 때 조심해야함**. 보통 수업 때는 system으로 진행할 예정

</aside>
