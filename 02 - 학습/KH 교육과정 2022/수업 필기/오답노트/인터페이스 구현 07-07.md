```java
<select id="electSearchList" resultMap="boardResultSet">
	select 
		board_no, board_title, user_id, count, create_date
	from
		board b
			join member on(board_writer=user_no)
	<choose>
		<when test="user_id != null">

		</when>
		<when test="board_title != null">
			AND board_title like '%' || #{title} || '%'
		</when>
		<when test="board_content != null">
			AND board_content like '%' || #{content} || '%'
		</when>
		<otherwise>
			<![CDATA[

				order by board_no desc
			]]
		</otherwise>
	</choose>
</select>
```

- 4.Mybaits 에서 SQL을 동적으로 제어할 수 있는 구문 종류 4가지를 작성하시오. (12점)

---

- 내 답안

1. if

: 특정 조건을 만족할 경우 if안의 구문을 쿼리에 포함

`<if test="조건식"></if>`

2. choose(when, otherwise)

: 주어진 구문 중 한가지만 수행하고자 할 때 사용한다. when은 if문과 흡사하고, otherwise는 else와 흡사함.

3. trim

:쿼리 구분의 특정 부분을 없앨 때 사용

:태그 안의 내용이 완성될 때 처음 시작할 단어와 시작 시 제거해야할 단어를 명시해야함.

`<trim prefix="where" prefixOverrides="AND| OR"/>`

4. foreach

: 동적 쿼리를 구현할 때 collection에 대한 반복 처리를 제공함.

item, index, collection, close, open,separator

- 모범답안

if

choose (when, otherwise)

trim (where, set)

foreach

- 5.resultType과 resultMap의 차이점에 대해 설명하시오. (12점)

---

- 내 답안

resultType은 클래스명 전체 또는 Alias를 입력해야한다.

VO, DTO등의 객체를 담을 수 있는 클래스의 경로를 명시하여 사용하면 된다. 자동 매핑

DML인 경우 작성하지 않는다.

resultMap의 경우 xml과 같은 문서 안에서 새롭게 정의된 형식이다.

매핑된 컬럼명을 변경함. column 대소문자를 구분하지 않음.

resultMap을 정의하는 이윤 기존 클래스(dto)에서 column의 이름이 다를 경우 쿼리와 맞춰주기 위해 column name의 치환

- 모범답안

resultType : resultset 결과를 매핑해서 반환되는 타입의 전체 클래스명이나 별명

resultMap : resultset 결과를 매핑할 resultMap 참조 아이디명
