# 강의: 0314

## 강의 내용

- **1.상속에 대해 서술하시오. (8점)**
    
    상속을 받음으로써 새 클래스가 자신의 멤버처럼 사용할 수 있는 기능
    
    클래스의 재사용, 연관된 일련의 클래스들에 대한 공통적인 규약 정의할 때 사용된다.
    

- **2.오버로딩과 오버라이딩의 차이점에 대해 서술하시오. (12점)**
    
    오버로딩은 한 클래스내에 동일한 메소드명으로 기술하는 것으로 매개변수의 자료형, 갯수, 순서가 달랐을 경우 허용됨.
    
    오버라이딩은 부모 클래스에 정의되어있는 메소드를 자식 클래스에서 재정의 하는걸로 부모클래스의 메소드명, 매개변수의 자료형, 개수, 순서가 같아야됨.
    

- **3.아래에는 String 클래스들의 주요 메소드들이다.**
    1. charAt(int index) :
    2. length() :
    3. substring(int beginIndex, int endIndex)
    4. toUpperCase() :
    5. toLowerCase() :
    
    ---
    
    1. 해당 문자열에서 전달받은 index위치의 문자만을 추출해서 반환해주는 메소드
    2. 해당 문자열의 글자수를 반환해주는 메소드
    3. 해당 문자열의 전달받은 beginIndex부터 endIndex-1위치까지의 문자열을 추출해서 반환해주는 메소드
    4. 해당 문자열을 다 대문자로 변환해서 반환해주는 메소드
    5. 해당 문자열을 다 소문자로 변환해서 반환해주는 메소드

- **4.인터페이스와 추상클래스의 차이점에 대해 5가지 기술하시오. (20점)**
    1. 추상클래스는 단일 상속만 가능하지만 인터페이스는 다중 상속이 가능하다.
    2. 추상클래스 구현시에는 extends 키워드를 사용하지만, 인터페이스 구현시에는 implements 키워드를 사용한다.
    3. 추상클래스는 abstract메소드가 0개 이상 존재하지만, 인터페이스는 모든 메소드가 abstract이다.
    4. 추상클래스는 명시적으로 abstract를 사용해야 하지만, 인터페이스는 묵시적으로 abstract이다.
    5. 추상클래스는 일반 필드를 가질 수 있지만, 인터페이스는 상수필드만 가질 수 있다.

- **5.Wrapper클래스 8가지를 기술하시오. (8점)**
    
    Boolean, Character, Byte, Short, Integer, Long, Float, Double
    

- **6.배열의 크기로 음수를 제시했을 때 발생될 수 있는 예외클래스에 대해 기술하시오. (8점)**
    
    NegativeArraySizeException
    
    배열 사이즈를 음수로 줬을 때 나는 에러이다.
    
    해결방법 -> 배열 크기를 음수에서 양수로 바꿔주면 된다.
    

- **7.아래에는 List 계열의 컬렉션 클래스들의 주요 메소드들이다. 각 메소드에 대한 설명을 기술하시오. (12점)**
    
    1. add(E e) :
    
    2. set(int index, E e) :
    
    3. size() :
    
    4. remove(int index) :
    
    5. get(int index) :
    

- **8.자바에서의 배열과 컬렉션의 차이점을 기술하시오. (20점)**
    
    배열은 크기를 지정해야만 하고 한번된 지정된 크기를 변경할 수 없지만 컬렉션은 크기에 제약이 없다.
    
    배열은 중간에 값을 추가해준다거나 삭제 또는 정렬을 하고자 할 때 개발자가 직접 코드로써 로직을 짜야만 하지만 컬렉션에서는 이미 자료구조적인 알고리즘이 메소드로 정의되어 있기 때문에 메소드 호출만으로 방대한 데이터를 효율적으로, 구조적으로 관리할 수 있다.
    
    배열은 한가지 타입의 여러 개의 데이터를 보관할 수 있다면 컬렉션은 별도의 제네릭 설정을 하지 않을 경우 여러가지 타입의 여러 개의 데이터를 보관할 수 있다.
