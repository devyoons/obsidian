- 서술형(신)
    1. **의존성 주입이란 무엇인지 서술하시오. (20점)**
        - 답안
            
            하나의 객체가 다른 객체의 의존성을 제공하는 테크닉이다.
            
    2. **WAS(Web Application Server)에 대해 간단하게 서술 하시오. (12점)**
        - 답안
            
            사용자의 요청을 받아 프로그래밍 처리 등을 수반한 동적인 작업을 수행하는 서버로, WAS 구성 및 운용을 위한 국제 표준 규격을 정하고 있으며, 제품마다 배포 방식과 설정이 일부 다르다. 웹 애플리케이션의 경우 UI 배포 영역(JSP, Servlet 등)과 Biz. 배포 영역(EJB,POJO 서비스 등)으로 구분되어 있다.
            
    3. **버전(형상) 관리 시스템의 사용 이점에 대해서 서술하시오. (12점)**
        - 답안
            
            버전 관리된 정보를 이용하여 언제라도 과거의 릴리즈에 접근 변경 및 수정 작업을 반복할 수 있게 된다.
            
    4. **JSP 내장객체에서 컨텍스트정보를 저장하는 영역(Scope)의 종류와 해당 영역이 사용되는 상황에 대해 설명하시오. (8점)**
        - 답안
            
            page - 하나의 jsp 페이지를 처리할 때 사용되는 영역
            
            request - 하나의 요청-응답을 처리할 때 사용되는 영역
            
            session - 하나의 브라우저가 연결되어있는 동안 사용되는 영역
            
            application - 하나의 웹 어플리케이션이 실행되는 동안 사용되는 영역.
            
    5. **세션을 관리하는 클래스인 HttpSession을 이용하여 세션 정보를 지울 때 사용하는 메소드를 작성하시오. (8점)**
    
    **( HttpSession session = request.getSession(); 코드가 이미 수행된 상황 )**
    
    - 답안
        
        session.invalidate();
        
    1. **형상관리 시스템 Git에서 로컬 저장소(Local Repository)와 원격 저장소(Remote Repository)의 차이점에 대해 서술하시오. (8점)**
        - 답안
            
            로컬 저장소(Local Repository)에는 내PC에 파일이 저장되는 개인전용 저장소이고 원격 저장소(Remote Repository)는 원격 저장소 전용으로 여러 사람이 함께 공유하기위한 저장소
            
    2. **웹 어플리케이션 배포를 한 후에 아래와 같은 404 에러가 발생하였습니다. 404 에러에 대해서 서술하시오. (20점)**
        - 답안
            
            클라이언트에서 서버로 요청한 페이지(Resource)나 기능을 찾을 수 없다. 서버에 존재하지 않는 페이지나 기능에 대한 요청이 있을 경우 서버는 이 에러 코드를 응답한다.
            
    3. **Git의 명령 중 Pull에 대해서 기술하시오. (12점)**
        - 답안
            
            Pull이란 원격 저장소에서 로컬 저장소로 추가, 변경, 제거된 파일을 다운로드하는 것을 말한다.
