### Framework이란?

:개발자가 소프트웨어를 개발함에 있어 코드를 구현하는 개발 시간을 줄이고, 코드의 재사용성을 증가시키기 위해 일련의 클래스 묶음이나 뼈대, 틀을 제공하는 라이브러리를 구현해 놓은 것을 말한다.

- 노란색 : 스프링 프레임워크 여러가지 기능을 가져다가 사용할 수 있는 틀이다.
    - mybatis : 영속성(데이터가 계속 보관될수 있는 프로그램)..?
        - persistence framework : 데이터가 계속 보관될수 있는 프로그램
        - jdbc : db 관련 —→ mybatis (디비랑 소통할 수 있는)
    - maven :
- 빨간색 : 프로젝트 관리도구 (maven | gradle)
    - 이 위에서 스프링이 돌아감
    - 프로젝트의 생성주기를 관리함
        - generate
        - dependency
        - compile
        - package
        - deploy
        - 중간확인 test
        - 저장소에 저장하는 install 기능
