## 스프링 빈

### 스프링 빈이란?

---

: 스프링 빈은 스프링 컨테이너에 의해 관리되는 자바 객체(POJO)를 의미함.

![[02 - 학습/KH 교육과정 2022/수업 필기/스프링 컨테이너 & 빈(의존성 주입)/첨부/16050fec_Untitled.png]]

<aside>
📖 우리가 new 연산자로 어떤 객체를 생성했을 때 그 객체는 빈이 아니다.
**ApplicationContext.getBean()으로 얻어질 수 있는 객체는 빈이다.**

</aside>

Spring에서의 빈은 ApplicationContext가 알고 있는 객체, 즉 ApplicationContext가 만들어서 그 안에 담고있는 객체를 의미한다.

### 스프링 컨테이너

---

: 스프링 컨테이너는 스프링 빈의 생명주기를 관리하며, 생성된 스프링 빈들에게 추가적인 기능을 제공하는 역할을 한다. IoC와 DI의 원리가 스프링 컨테이너에 적용된다.

- **IoC(Inversion of Control, 제어의 역전)은 의존성주입 (Dependency Injection)이라고도 하며 의존성있는 객체를 직접 만드는 것이 아닌, 주입 받아 사용하는 방법이다.**
- BeanFactory 는 스프링 IoC 컨테이너의 가장 최상위 인터페이스이다.

: 개발자는 new연산자, 인터페이스 호출, 팩토리 호출 방식으로 **객체를 생성**하고 소멸하지만, 스프링 컨테이너를 사용하면 **해당 역할을 대신해 준다.** 즉, **제어 흐름을 외부에서 관리**하게 되고 **객체들 간의 의존 관계를 스프링 컨테이너가 런타임 과정에서 알아서 만들어준다.**

✏️ Bean은 spring container가 관리하는 자바 객체이다. 

✏️ context도 객체이며 spring container 에 있다.

✏️ context 단위 아래에서 관리된다.

**빈 장점**

1. 의존성 관리가 용이하다.
2. 빈으로 등록된 객체는 기본적으로 스코프가 '싱글톤'으로 정해진다.
    - 싱글톤 : 객체가 하나만 만들어짐. 재사용하여 메모리를 절약하며, 런타임시 성능 최적화에 유리하다. 특히 데이터베이스와 관련된 객체들은 필드가 많기 때문에 만드는 비용이 많이 들기 때문에 싱글톤이 효율적이다.
    - 프로토타입 : 매번 다른 객체가 만들어짐.
3.  라이프사이클 인터페이스를 지원해준다. 이를 활용할 수 있다.

**ApplicationContext**

- BeanFactory 를 포함한 다른 컨테이너를 상속받음.
    
    메시지 소스 처리 기능도 있고, 이벤트 발행 기능, 리소스 로딩 기능 등이 있다.
    
- 자주 사용하게 될 Beanfactory 이다.

    ```java
    import org.springframework.context.ApplicationContext;
    import org.springframework.context.support.ClassPathXmlApplicationContext;
    
    public class TvMain {
    
    	public static void main(String[] args) {
    		// bean을 관리하는 객체 생성
    		String configLocation = "application-context.xml";
    		ApplicationContext applicationContext = new ClassPathXmlApplicationContext(configLocation);
    		System.out.println("=========== Spring Container 초기화 완료 ===========");
    		
    		Tv lgTv1 = (Tv) applicationContext.getBean("lgTv");
    		System.out.println(lgTv1);

    		Tv lgTv2 = applicationContext.getBean(LgTv.class);
    		System.out.println(lgTv2);
    		System.out.println(lgTv1 == lgTv2); // true
    		
    		// 빈id와 클래스타입을 합쳐서도 사용할 수 있다.
    		Tv lgTv3 = applicationContext.getBean("lgTv", LgTv.class);
    		System.out.println(lgTv3);
    	}
    }
    ```

#### 1 - 2. java @Configuration annotation (빈설정 클래스)

---

1. 자바 설정 파일은 `@Configuration`어노테이션을 클래스 위에 붙여줘야 설정파일로서 활용가능
2. 빈으로 등록하기 위해서는 메서드 위에 `@Bean`어노테이션을 객체를 생성해서 return해준다
    - UserConfig.java
        
        ```java
        package com.kh.spring.user;
        
        import org.springframework.context.annotation.Bean;
        import org.springframework.context.annotation.Configuration;
        import org.springframework.context.annotation.Lazy;
        import org.springframework.context.annotation.Scope;
        
        /**
         * 
         * @Configuration 빈설정이 가능한 클래스
         * @Bean 메소드. 리턴값이 Spring Container가 관리할 bean 객체
         *
         */
        @Configuration
        public class UserConfig {
        	/**
        	 * 메소드명이 bean의 id
        	 * @return
        	 */
        	@Bean
        	@Scope
        	@Lazy
        	public UserController userController() {
        		return new UserController(userService());
        	}
        
        	@Bean
        	public UserService userService() { // 여기서 만들어진 빈이 위에서 사용한다는 뜻
        		return new UserService();
        	}
        }
        ```
        
3. 해당 빈에 의존성을 주입해주기 위해서는 **setter**나 **생성자**를 이용해서 필요한 빈을 객체로 주입해줄 수 있다.
    - UserController.java
        
        ```java
        package com.kh.spring.user;
        
        public class UserController {
        	private UserService userService;
        	
        	public UserController(UserService userService) {
        		System.out.println("UserController 객체 생성 & 의존 주입 : " + userService);
        		this.userService = userService;
        	}
        }
        ```
        
    - UserService.java
        
        ```java
        package com.kh.spring.user;
        
        public class UserService {
        
        	public UserService() {
        		System.out.println("UserService객체 생성!");
        	}
        }
        ```
        
4. 설정파일을 읽어와서 빈으로 등록하기 
    - ApplicationContext의 구현체 **AnnotationConfigApplicationContext을 생성할 때 설정파일의 클래스를 넣어주면된다.**
    - UserMain.java
        
        ```java
        // UserMain.java
        package com.kh.spring.user;
        
        import org.springframework.context.ApplicationContext;
        import org.springframework.context.annotation.AnnotationConfigApplicationContext;
        
        public class UserMain {
        
        	public static void main(String[] args) {
        		ApplicationContext context = new AnnotationConfigApplicationContext(UserConfig.class);
        		System.out.println("=============== Spring Container 초기화 완료 ===============");
        	}
        
        }
        ```

    ```java
    package com.kh.spring.pet;
    
    import org.springframework.beans.factory.annotation.Autowired;
    import org.springframework.beans.factory.annotation.Qualifier;
    import org.springframework.context.annotation.Scope;
    import org.springframework.stereotype.Component;
    
    @Component // 빈으로 등록
    @Scope("prototype")
    public class Person {
    	
    	/**
    	 * Pet타입의 빈을 찾아서 의존주입
    	 * @Autowired 필드 생성자 세터에 붙을 수 있음
    	 * - 필드에 주입
    	 */
    	@Autowired
    	@Qualifier("dooooooooooooog")
    	private Pet pet;
    	
    	public Person() {
    		System.out.println("Person 객체 생성!");
    	}
    	
    //	@Autowired
    //	@Qualifier("dooooooooooooog") The annotation @Qualifier is disallowed for this location
    	public Person(Pet pet) {
    		System.out.println("Person 객체 생성 & 의존 주입 : " + pet);
    		this.pet = pet;
    	}
    	
    	public Pet getPet() {
    		return pet;
    	}
    	
    //	@Autowired
    //	@Qualifier("dooooooooooooog") // Qualifier는 필드랑 세터에서만 사용가능 생성자에서는 사용불가.
    	public void setPet(Pet pet) {
    		System.out.println("Pet 의존 주입 : " + pet);
    		this.pet = pet;
    	}
    
    	@Override
    	public String toString() {
    		return "Person [pet=" + pet + "]";
    	}
    	
    	
    }
    ```

### 2. 의존성 주입(Dependency Injection) 3가지 방법

---

1. 생성자 주입
2. setter주입 (수정자 주입)
3. 어노테이션 사용 오토아이어링 (필드 주입)

```java
난 차가 필요하다. 차 공장(configuration.xml)에 차를 하나 달라고 요청한다. 
공장에서 모든걸 만들어서 줄거다.

차를 만들기 위해 필요한 모든 의존성(엔진, 타이어, 시트 등)을 공장에서 주입해준다.
```

```
A가 "나는 B가 필요해"라고 의존성 주입 신호만 보내면 ApplicationContext라는 스프링 컨테이너가 필요한 B객체를 생성하고 주입해준다. 
여기서 스프링 컨테이너가 관리하는 객체를 **Bean** 이라고 말하며 빈과 빈의 의존관계는 xml 또는 어노테이션으로 설정한다. sts 레거시 프로젝트는 기본적으로 xml 사용해서 객체를 관리한다.
```

#### 2 - 1. 생성사 주입 방법

```java
Tv samsungTv1 = new SamsungTv(RemoteControl.channelTo(3));? 랑 비슷
```

1. 의존성 클래스 정의
    - DaisoRemocon.java (RemoteControl이 인터페이스라 구현클래스가 필요)
        
        ```java

        ```
        
2. 주입을 위해 생성자 만들기
    - 멤버 변수를 생성자 인자에 그대로 갖고 오기
    - SamsungTv.java
        
        : 아래 코드를 이용한 의존주입을 해달라는 걸 작성해야함. 
        
        → application-context.xml 로 이동
        
        ```java
        package com.kh.spring.tv;
        
        public class SamsungTv implements Tv {
        	private RemoteControl remoteControl;
        
        	public SamsungTv () {
        		System.out.println("SamsungTv 객체 생성!");
        	}
        	public SamsungTv (RemoteControl remoteControl) {
        		System.out.println("SamsungTv 객체 생성 & 의존 주입 : " + remoteControl);
        		this.remoteControl = remoteControl;
        	}
        	@Override
        	public void powerOn() {
        		System.out.println("SamsungTv를 켭니다.");
        	}
        	@Override
        	public void channelTo(int no) {
        		remoteControl.channelTo(no);
        	}
        }
        ```
        
3. application-context.xml 파일에 의존성 주입 설정하기
    - application-context.xml
        
        `<constructor-arg>` 
        
        - 사용방법
            
            ```java
            <bean id | name=”명칭” class=“클래스명” [기타 옵션] >
            <constructor-arg value | ref =“값” | “bean id명”/>
            <constructor-arg value | ref =“값” | “bean id명”/>
            /////////////// index로 설정가능 ////////////
            <constructor-arg index=“숫자” value | ref =“값” | “bean id명”/>
            <constructor-arg index=“숫자” value | ref =“값” | “bean id명”/>
            </bean>
            ```
            
        - 생성자를 통해 빈을 주입받는 경우에 사용하는 태그
            - 생성자 호출할 때 전달할 인자가 있습니까?
        - 생성자의 파라미터를 이용하기 때문에 한번에 여러 개의 객체를 주입할 수 있다.
            - index를 통해 처리할 수 있다.
        
        ```java
        <?xml version="1.0" encoding="UTF-8"?>
        <beans 
        	xmlns="http://www.springframework.org/schema/beans"
        	xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        	xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
        	
        	<bean id="daisoRemocon" class="com.kh.spring.tv.DaisoRemocon"/>
        	<bean id="samsungTv" class="com.kh.spring.tv.SamsungTv" lazy-init="true">
        		<constructor-arg ref="daisoRemocon" index="0"/>
        	</bean>
        
        </beans>
        ```
