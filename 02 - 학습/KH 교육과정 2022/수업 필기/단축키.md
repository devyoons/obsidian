#### 이클립스 Main Method 자동생성 주석제거

`// TODO Auto-generated method stub`

- 이클립스의 Window -> Preferences 메뉴를 클릭한다.
- Java -> Code Style -> Code Templates 를 선택한다.
- Code -> Method body 를 선택한다.
- Edit 버튼을 클릭한 후, "// ${todo}" 로 시작하는 라인을 제거한다.
