#### **SOP [ Same Origin Policy ]**

- 동일근원정책
- 웹브라우저에서 비동기요청을 보낼 때 (ajax) 반드시 같은 origin으로만 요청을 보낼 수 있다.
- http://localhost:9090 -> http://localhost:10000 요청을 보낼 수 없다.
    - 한글자라도 다르면 보낼 수 없다.
    - localhost ≠127.0.01

#### **Origin [ protocol + host + port ]**

- `protocol` : http:// https://
- `host` : domain, ip
- `port` : 8080,9090 …

### **CORS [ Cross Origin Resource Sharing Policy ]**

- 타 오리진 타 근원자원정책
- sop를 넘어서는 ajax요청을 위한 정책
- Access-Control-Allow-Origin 헤더에 해당 orgin이 명시되어 있어야 한다.

오리진을 넘나들면서 자원을 공급받을 수 있다. ACAO가 있어야만!

```java
@CrossOrigin(origins="*") //메소드레벨, 클래스레벨 가능

위 아래 동일 코드

response.addHeader("Access-Control-Allow-Origin", "*");
```

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/1df0485f_Untitled.png]]

```java
@RestController
@Slf4j
@RequestMapping("/menu")
@CrossOrigin
public class MenuController {

	@Autowired
	MenuService menuService;
	
//	@CrossOrigin(origins="*")
	@GetMapping
	public List<Menu> selectAll(HttpServletResponse response){
		// CORS정책 - Access-Control-Allow-Origin 헤더값추가
		response.addHeader("Access-Control-Allow-Origin", "*");
		return menuService.selectAll();
	}
```

#### **CORS 처리방법**

1. Access-Control-Allow-Origin 헤더에 origin 명시
    - 서버단 코드를 내가 수정할 수 있을 때 가능한 방법
2. jsonp
3. proxy server
