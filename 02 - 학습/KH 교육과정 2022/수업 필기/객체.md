### 객체란?

- (속성명 : 속성값)을 하나의 요소로 관리
    - 속성명은 중복될 수 없다.
    - 동일한 속성명으로 값을 대입하면, 이전 속성값은 대체된다.
- 속성명 : 모든 타입이 가능하나, 키워드, 문자열 사용추천
- 속성값 : 모든 타입이 가능하다.

### 객체생성

#### literal

```jsx
let obj = {키:값};
					Key Value : 속성(Property)
new Object()
```

#### 속성접근방식

- `dot-notation` ⇒ .속성명
- `bracket-notation` ⇒ [속성명]
- 없는 속성을 참조해도 오류가나지 않고, undefined리턴

```jsx
const test1 = () => {
  const obj = {

      id : 'honggd',
      'name' : '홍길동',
      married : true,
      hobby : ['축구', '농구', '배구'],
      pet : {
          name : '구리구리',
          breed : '푸들'
      },
      123 : 456, //추천하지않음
      'a-b' : 'ㅋㅋㅋㅋ' // 연산자는 문자열로 묶으면 사용가능
  
```

1. `dot-notation` ⇒ .속성명

```jsx
console.log(obj.id);
console.log(obj.name);
console.log(obj.married);
console.log(obj.hobby);
console.log(obj.pet);
// console.log(obj.123); // Uncaught SyntaxError: missing ) after argument list
// console.log(obj.a-b); // - 연산자로 사용되서 b가 정의되지 않았다고 오류남
```

1. `bracket-notation` ⇒ [속성명]
    - 속성명을 문자열로 준다. `obj[’string’]`

```jsx
console.log(obj['id']);
console.log(obj['name']);
console.log(obj['married']);
console.log(obj['hobby']);
console.log(obj['pet']);
console.log(obj[123]);
console.log(obj['a-b']);
```

1. 없는 속성을 참조해도 오류가나지 않고, undefined리턴

```jsx
console.log(obj.abcdef); // undefined

// 뒤늦게 추가해도 가능
obj.abcdef = 'ABCDEF'; // 속성 추가가능
console.log(obj.abcdef);
//ABCDEF
```

#### 객체생성 - 생성자함수

- 속성추가 , 값만 제거, 속성 제거

```jsx
const test2 = () => {
    const obj = new Object();

    // 속성 추가
    obj.name = '망고';
    obj.weight = '0.3';
    obj.price = 3000;
    obj['origin'] = '필리핀';

    // 값만 제거 
    obj.price = undefined;

    // 속성 제거
    delete obj.origin;

    console.log(obj);
};

//결과

{name: '망고', weight: '0.3', price: undefined}
name: "망고"
price: undefined
weight: "0.3"
[[Prototype]]: Object
```

## 메소드

- **객체의 속성으로 등록된 함수를** 메소드라고 한다.
- 메소드로 사용할 함수는 **익명함수로 사용**한다.
- **메소드작성시 화살표 함수가 아닌 일반함수로 작성한다.**
    - this가 가르키는게 window가됨
        - dog객체가 부모환경이 아니라 window임
    
```jsx
const test3 = () => {
    const dog = {
        name : '복실이',
        run : function(){ // 익명함수로 사용
            // this용법4. 메소드 안의 this는 현재 객체를 가르킨다.
            // 메소드
            console.log(this.name + '가 달린다.');
        },
        jump : function(){ // 메소드작성시 화살표함수사용X(this가 가르키는게 window가됨)
            console.log(this.name + '가 점프한다.');
        }
    };
		//dot - notation
    console.log(typeof dog.run, dog.run);
    dog.run(); 
    dog.jump(); // 복실이가 점프한다.

		// bracket-notation
    dog['run']();
    dog['jump']();
    dog['eat']('갈비');
};
```


#### 메소드 문법 (외부에서는 사용불가)

```jsx
jump(){ 
    // 메소드 문법
    console.log(this.name + '가 점프한다.');
}

dog.jump(); // 복실이가 점프한다.
```

#### 메소드 단축 문법

```jsx
eat(food){
    console.log(`${this.name}가 ${food}를 먹는다.`);
}

dog.eat('갈비'); // 복실이가 갈비를 먹는다.
```
