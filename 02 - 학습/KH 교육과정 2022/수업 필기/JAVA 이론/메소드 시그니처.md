#### 매개변수

- 메서드로 전달된 값을 받는 변수를 말한다.
- 메서드를 호출할 때 소괄호 안에 값을 콤마(,)로 구분하여 값을 전달한다
- 전달된 값은 메서드의 매개변수로 순서대로 넘어간다.
- 값의 개수는 매개변수 개수와 일치해야하고 타입또한 서로 일치해야함

#### 매개변수 사용법

```java
public void test1() {
	//데이터 할당부
	String name = "홍길동";
	int age = 33;

	//데이터 출력부
	printPerson(name,age); //printPerson메소드에 값대입해준다. name,age안에 있는 값이 전달
												 //매개인자

	return;
}

public void test2() {
	//데이터 할당부 
	String name = "신사임당";
	int age = 48;

	//데이터 출력부
	printPerson(name,age); //printPerson메소드에 값대입해준다. name,age안에 있는 값이 전달
												 //매개인자

	return;
}

public void printPerson(String name, int age) { //괄호 안에 있는건 매개변수
	System.out.printf("안녕하세요, 저는 %s 입니다. 나이는 %d살이예요.%n", name , age);
}
```

- 변수의 사용절차 : 선언 → 값대입 → 사용
- 매개변수(메소드 선언부) parameter
→ 메소드 호출시에 값(매개인자 argument)이 대입된다.

#### 2개의 정수를 입력받아 더해주는 프로그램

```java
public void test(){
	Scanner sc = new Scanner (System.in);
	System.out.print("정수입력 : ");
	int n1 = sc.nextInt();
	System.out.print("정수입력 : ");
	int n2 = sc.nextInt();
	System.out.print("정수입력 : ");
	int n3 = sc.nextInt();

	System.out.printf("%d + %d + %d = %d%n", n1, n2, n3 ,n1 + n2 + n3);
}
```

→ 개선 코드

```java
public void test(){
	int n1 = getUserInput(1);
	int n2 = getUserInput(2);
	int n3 = getUserInput(3);

	System.out.printf("%d + %d + %d = %d%n", n1, n2, n3, n1 + n2 + n3 );
}

public int getUserInput(int nth){
	Scanner sc = new Scanner(System.in);
	System.out.printf("정수 %d입력 : ",nth);
	int n = sc.nextInt();
	return n;
}
```
