## 🧐print

#### System.out.print(); - 내용출력 (개행처리 없음)

```java
System.out.print("안녕");
System.out.print("잘가");
//결과
안녕잘가
```

#### System.out.print(); 개행처리 방법

```java
System.out.print("안녕\n");
System.out.print("잘가\n");
//결과
안녕
잘가
| <-커서는 이 위치에서 출력을 마친다.
```

## 🧐println

#### System.out.println(); - 내용출력 후 개행처리

```java
System.out.println("안녕");

|<-커서는 여기에서 출력을 마친다.
```

## 🧐printf - (”문자열 %d%n”,변수)

#### printf → f는 포멧(format)

|  | 지시자 | 설명 |
| --- | --- | --- |
| 논리형 | %b | boolean 형식으로 출력 |
| 정수형 | %d | 정수 형식으로 출력 |
|  | %o | 8진수 정수형식으로 출력 |
|  | %x 또는 %X | 16진수 정수형식으로 출력 |
|  | Integer.toBinaryString(i) | 2진수는 포멧지원하지 않음. |
| 실수형 | %f | 소수점 형식으로 출력/소수점아래6자리(기본값) 더 줄이거나 늘릴 수 있음 |
|  | %e 또는 %E | 지수 표현식의 형식으로 출력 |
| 문자형 | %c | 문자 형식으로 출력 |
|  | %s | 문자열 형식으로 출력 |
| 개행문자 | %n | 줄바꿈 기능 |
| 너비 및 정렬방법 | %[ flag ][ width ] | flag 생략시 우측정렬 : + 작성하면 안됨. |
|  |  | flag = -(음수) 좌측정렬 |
|  | %.2f | 소수점 둘째자리까지 표현 |

```java
<사용법>
System.out.printf("%c,%c,%c,%c,%s", c, ga, na, da, ra, str)
//%c,%c,%c,%c,%s -> format String
//formet 개수와 맞게 입력하면 변수값이 대입된다.
```

```java
<너비 및 정렬방법>
System.out.printf("%10d, %-10d.", i, i); //결과      12345,12345     .
System.out.printf("%.3f",123.456878789); //결과 123.457

```

## 🧐escaping 문자

#### (\ + 문자) → 인쇄되지 않고, 키보드로 표현불가한 문자

- \ + n 개행문자
- \ + t 탭
- \ + \  역슬래시 문자 출력
- \ + “  쌍따옴표 출력
- \ + u 유니코드 → 유니코드를 \\u(escaping) + ac00 ( ‘가’ )으로 표현함

```java
System.out.print("\t잘가\n");
System.out.print("배고프니\n");
System.out.println("\\");
System.out.println("철수가 내게 \"안녕\"이라고 말했음");

//결과
	잘가
배고프니
\
철수가 내게 "안녕" 이라고 말했음
```
