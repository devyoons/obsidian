## 🧐접근제한자

객체 지향에서 정보은닉이란 사용자가 굳이 알 필요가 없는 정보는 사용자로부터 숨겨야 한다는 개념이다. 그렇게 함으로써 사용자는 언제나 최소한의 정보만으로 프로그램을 손쉽게 사용할 수 있다.

접근 제어자를 사용하면 클래스 외부에서의 직접적인 접근을 허용하지 않는 멤버를 설정하여 정보 은닉을 구체화 할 수 있다.

#### 자바에서 제공하는 접근 제한자

- **public:** 모든 위치에서의 접근을 허용합니다. 접근 제어자 중에서 범위가 가장 넓습니다.
- **protected:** 동일 패키지나 다른 패키지에 있는 자식 클래스에서만 접근할 수 있습니다.
- **default:** 접근 제어자를 붙이지 않으면 자동으로 붙는 접근 제어자입니다. 동일 패키지에서만 접근할 수 있습니다.
- **private:** 외부에서 접근이 불가능합니다. 즉, 선언된 클래스 내에서만 접근이 가능합니다.

이를 표로 나타내면 다음과 같습니다.

---

#### 접근제한자 입력 위치

```java
[접근제한자][예약어] class 클래스명{
	<속성,필드>
	[접근제한자]자료형 변수명;
	[접근제한자]자료형 변수명;   
	
	<기능,메소드>
	[접근제한자]생성자명(){}
	[접근제한자][예약어]리턴형 메소드명(){
		//기능정의
	}
}
```

## 🧐class level 접근제한자

- **public** : 모든 패키지에서 접근 가능
- **default** : 같은 패키지에서만 접근 가능 → 가능하다는것만 알고 쓰지말자
→ 객체지향프로그래밍에서는 클래스 재사용이 필수적인데, 타패키지에서 접근할 수 없어 쓸모가 없다.

```java
pubilc class 클래스이름 {}

class 클래스이름 {}
```

```java
<default>
public class Sample {

}

class Gample {
	
}
------------------------------
<다른 패키지>
import kh.java.oop.access.modifier.cls.Sample;
import kh.java.oop.access.modifier.cls.Gample; //에러

public class SampleMain2 {

	public static void main(String[] args) {
		Sample sample = new Sample();
		// default class는 다른패키지에서 접근할 수 없다.
		Gample gample = new Gample(); //에러
	}

}
```

#### public > protected > default > private 가 있다 (제한이 작은 순서)

![[02 - 학습/KH 교육과정 2022/수업 필기/JAVA 이론/첨부/e000235d_Untitled.png]]

```java
public class Foo {

	public int a;
	protected int b;
	int c; //default키워드 작성안함.
	private int d;
}
```

```java
package kh.java.oop.access.modifier.member;

public class FooMain1 {

	public static void main(String[] args) {
		Foo foo = new Foo();
		foo.a = 100;
		foo.b = 200;
		foo.c = 300;
		foo.d = 400; // private 필드는 다른 클래스에서 접근불가
	}
}
```

```java
package kh.java.oop.access.modifier.member.main;

import kh.java.oop.access.modifier.member.Foo;

public class FooMain2 {

	public static void main(String[] args) {
		Foo foo = new Foo();
		foo.a = 100;
//	foo.b = 200; protected 필드는 다른 패키지에서 접근불가하다.
//	foo.c = 300; default 필드는 다른 패키지에서 접근불가하다.
//	foo.d = 400; private 필드는 다른 클래스에서 접근불가하다.
	}

}
```

## 캡슐화

- 필드의 접근제한자를 private처리
- 필드를 제어하는 메소드를 public로 지정
- 필드와 메소드를 묶어서 클래스로 지정
- 멤버 변수나 메서드를 외부에서 사용하지 못하도록 하여 오류를 줄일 수 있다.
- 변수에 대해서는 필요한 경우 get(), set() 메서드를 제공

#### setter : 숨겨진 필드를 변경하는 메소드,값설정

```java
public class Account {
	
	private String name;
	private long balance; // 잔액
	
	//setter
	//변수명이 같은 경우 가까운 유효범위에 선언된 변수를 사용한다.
	public void setName(String _name) {
		name = _name; // this.name = name; -> 변수이름과 필드변수 이름이 동일하면 
									//											구분을 못하기 때문에 this.사용 
	}
	public void setBalance(long _balance) {
		balance = _balance;
	}
```

#### getter : 숨겨진 필드를 읽어오기

```java
public class Account {
	
	private String name;
	private long balance; // 잔액

//getter
	public String getName() {
		return name;
	}
	public long getBalance() {
		return balance;
	}
```

#### getter , setter 메서드 사용

```java
package hiding;

public class MyDateTest {

	public static void main(String[] args) {

		MyDate day = new MyDate();
		day.setMonth(2);
		day.setDay(31);
		day.setYear(2022);
		
	}
}

class MyDate {
	
	private int day;
	private int month;
	private int year;
	
	//getter, setter
	public int getDay() {
		return day;
	}
	public void setDay(int day) {
		if(month == 2) {
			if (day < 1 || day > 28) {
				System.out.println("날짜 오류입니다.");
			}
		}
		else {
			this.day = day;
		}
	}
	public int getMonth() {
		return month;
	}
	public void setMonth(int month) {
		this.month = month;
	}
	public int getYear() {
		return year;
	}
	public void setYear(int year) {
		this.year = year;
	}
}
```

<aside>
💡 값을 얻는 get() 메서드를 getter, 값을 지정하는 set()메서드를 setter

</aside>

<aside>
💡 get(),set() 자동으로 만들기 (alt + shift + s + r)

멤버 변수를 선언한 클래스 내부에서 오른쪽 마우스를 클릭
[Source → Generate Getters and Setters...→]  메뉴를 클릭한다.
메서드를 추가하고 싶은 멤버 변수를 선택하고 [OK]를 누르면 get(),set()메서드가 생성됨

</aside>
