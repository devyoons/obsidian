- 다차원 배열이란 2차원 이상의 배열을 의미

## 🧐2차원배열

#### 테이블 형태의 데이터를 저장하기 위한 배열

- 1차원 배열 안에 다른 배열을 넣은 것, 바둑판이나 아파트 같은 저장공간이 생긴다고 생각하면 됨. 
→ 배열은 저장된 값마다 인덱스 번호 두 개로 설정되고 앞 번호는 행, 뒷 번호는 열이다 ([0][0])

#### 2차원 배열의 선언과 할당

```java
<표현식>
자료형[][] 변수이름;
자료형 변수이름[][];
자료형[][] 변수이름 = new 자료형[행크기][열크기];

ex) int arr[행][열];
		int[][] arr = new int[2][3];
```

```java
요소타입[][] 참조변수명 = new 요소타입[][] {{값00, 값01, 값02...},{값10, 값11, 값12...}};
```

```java
1. int[][] arr = new int[][]{{1, 2, 3},{4, 5, 6}};

★3. int[][] arr = {
```

```java
<알파벳 배열 char[2][26] / 0행 대문자 1행 소문자출력>
->중복 for문을 이용

public void test2() {
		char[][] alphabet = new char[2][26];
		
		System.out.println(alphabet.length); //바깥 outer
		System.out.println(alphabet[0].length); //안쪽 inner
		
		for(int i = 0; i < alphabet.length; i ++) {
			for(int j = 0; j < alphabet[0].length; j++) {
				alphabet[i][j] = (char)('A' + j);
				if(i == 1)
					alphabet[i][j] = (char)('a' + j);
				
			}
		}
		for(int i = 0; i < alphabet.length; i++) {
			for(int j = 0; j < alphabet[0].length; j++) {
				System.out.print(alphabet[i][j] + " ");
			}
			System.out.println();
		}
	}
```

#### 2차원 배열 for문을 이용한 초기화

- 2개의 for문을 돌린다.
- 겉의 for문은 행, 안의 for문은 열을 본다
- 겉에 `i < arr.length`가 있는데 0번째 배열의 또 다른 크기를 구하려면 `arr[i].length`를 사용해서 구함

## 🧐가변배열

- 2차원배열(참조의 참조)의 길이가 다른 2차원배열

```java
<표현식>

자료형[][] 변수이름 = new 자료형[행크기][];

ex) int[][] arr = new int[3][]; //1차원배열(참조)까지 생성
		arr[0] = new int[2];
		arr[1] = new int[2];
		arr[2] = new int[3];
```

## 가변인자

- 매개변수 선언부에서 동일한 타입에 개수제한 없는 매개변수
- 매개변수가 여러개일 때 마지막에 한번만 사용가능
- 가변인자를 처리할 때 매개변수는 배열로 사용이 가능함.
