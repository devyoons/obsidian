#### 자료를 순차적으로 관리하는 구조, 배열

- 배열은 동일한 자료형의 변수를 한꺼번에 순차적으로 관리할 수 있다.

**동일 자료형의 묶음을 의미한다.**

- 동일한 물품을 보관하는 서랍장
- 아파트, 오피스텔, 기차
- 배열의 크기는 변경이 불가하다.
- 배열(객체)은 주소값을 null로 변경해서 삭제한다. → Garbage Collector

#### 배열은 왜 써야 할까?

- 정수 20개를 이용한 프로그램을 할 때 20개의 정수 타입의 변수를 선언해야한다.
    - int num1, num2, num3, ...
- 위 상황이 비효율적이고 변수 관리도 힘들다

→ 배열은 동일한 자료형의 변수를 한꺼번에 순차적으로 관리할 수 있다.

#### 배열 선언과 초기화 ( 생성 → 선언 → 할당 →초기화 → 사용)

- 배열을 구성하는 각각의 값을 배열 요소 (element)라고 한다.
- 배열에서의 위치를 가리키는 숫자를 인덱스(index)라고 한다.
- 자바에서 인덱스는 언제나 0부터 시작하며, 0을 포함한 양의 정수만을 가질 수 있다.

#### 메소드 호출시 call by reference

- 메소드 호출시 참조형 매개변수는 얕은복사로 처리된다.
- 호출된 메소드에서 배열에 값변경이 일어나면 리턴후에도 여전히 유효하다.

```java
<얕은복사 예시> 
public void test6() {
		int[] arr = {1, 2, 3};
		print(arr);
		System.out.println(arr[1]);
		
	}
	
	public void print(int[] arr) {
		arr[1] *=100;
		for(int i = 0; i < arr.length; i++) {
			System.out.print(arr[i] + " ");
		}
		System.out.println();
	}
```

```java
int[] a = {1, 2, 3};
```
