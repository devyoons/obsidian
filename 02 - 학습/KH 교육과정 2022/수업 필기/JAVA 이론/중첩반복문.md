# 강의: 중첩반복문

## 강의 내용

#### Nested(둥지) Loop

- 바깥반복문 1번에 안쪽반복문 n번이 처리되는 구조
- 행(가로)열(세로)표현에 적합 → 바깥반복문 - 행row, 안쪽반복문 - 열column

```java
<표현식>

for(초기값; 조건식; 증감식){
	1.실행코드
		for(초기값2; 조건식2; 증감식){
			2.실행코드
		}
	3.실행코드
}
```

```java

		for(int i = 0; i < 3; i++) {
```

## break

```java
<표현식>
for(초기값; 조건식; 증감식){
	1.실행코드
		for(초기값2; 조건식2; 증감식){
			2.실행코드 break;
		}
	3.실행코드 break;
}
```

### 라벨이 있는 반복문

```java
표현식 : break 지정이름;
 -> 라벨이 지정된 반복문을 빠져나가 다음 코드를 실행.

표현식 : continue 지정이름;
 -> 라벨이 지정된 반복문의 증감식으로 이동, 다음코드를 실행.
 -> comtinue가 기술된 반복문의 아랫부분은 실행하지 않는다.
```

```java
<dan * n의 결과가 50미만까지만 출력하기>
public void test8() {
		outer:
		for(int dan = 2; dan < 9; dan++) {
			System.out.println("====" + dan + "단====");
			for(int n = 1; n < 9; n++) {
				if(dan * n > 50)
					break outer;
				System.out.printf("%d * %d = %d%n", dan, n, dan * n);
			}
			System.out.println();
		}
	}
```

## continue

```java
<표현식>
for(초기값; 조건식; 1증감식){
	1.실행코드 continue;
		for(초기값2; 조건식2; 2증감식){
			2.실행코드 continue;
		}
	3.실행코드
}
```

```java
<각 단에서 dan과 n이 같을 때 까지만 출력>
public void test9() {
		abc:
		for(int dan = 2; dan < 9; dan++) {
			System.out.println("====" + dan + "단====");
			for(int n = 1; n < 9; n++) {
				System.out.printf("%d * %d = %d%n", dan, n, dan * n);
				if(dan == n) {
					System.out.println();
					continue abc;
				}
			}
		}
	}
```
