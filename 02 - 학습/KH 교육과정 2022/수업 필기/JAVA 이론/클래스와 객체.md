## 🧐클래스란?

- 객체를 정의하는 틀 또는 설계도와 같은 의미로 사용
- 이러한 설계도인 클래스를 가지고, 여러 객체를 생성하여 사용함
- 객체지향프로그래밍의 추상화(abstraction)라는 개념을 직접 구현한 것

#### 클래스의 구성 3가지

![[02 - 학습/KH 교육과정 2022/수업 필기/JAVA 이론/첨부/c98cf519_Untitled.png]]

1. **필드(Field)** : 객체의 데이터가 저장되는 곳이다. (클래스에 포함된 변수)
→ 필드는 생성자와 메소드 전체에 사용되고 객체가 소멸되지 않는 이상 객체와 함께 존재한다.
    - 클래스 변수 (static 변수)
    - 인스턴스 변수 (instance 변수)
    - 지역 변수 (lacal 변수)
    
2. **생성자(Constructor)** : 객체를 생성할 때 초기화를 해준다
→ new 연산자로 호출되는 중괄호 { } 블록이다. 객체 생성시 초기화를 담당한다.
    클래스 이름으로 되어있고 리턴 타입은 없다.

1. **메소드(Method)** : 객체의 동작에 해당하는 실행 블록이다. (명령문의 집합)
→ 객체의 동작에 해당하는 중괄호 {} 블록이다. 메소드를 호출하면 블록에 있는 코드들이 일괄적으로 실행된다.
→ 객체간 데이터를 전달하는 수단이라고 생각하면 된다.
→ 중복되는 코드의 반복적인 프로그래밍을 피할 수 있다.
→ 모듈화로 인해 전체적인 코드의 가독성이 좋아진다.
→ 손쉽게 유지 보수할 수 있다.

```java
접근제어자 class 클래스이름 {
```

- 객체 = 속성(필드, 멤버 변수) + 기능(메서드)

```java
class Tv{
<필드=변수(속성)>
	String color; //색깔
	boolean power; //전원상태
	int channel; //채널

<메서드(기능)>
	void power() {power = !power;}
	void channelUp() {channel++;}
	void channelDown() {channel--;}
}
```

- 학생 클래스의 예
속성 : 학번, 이름, 학년, 사는 곳   등등..
기능 : 수강신청, 수업듣기, 시험보기 등등..

```java
<학생 클래스 속성(필드),기능(메소드) 만들기>
```

## 🧐객체란?

- 객체의 사전적 의미: 실재하는 모든 사물. 살아있지 아니할 것.
- object → 절차지향 대비 객체지향
- instance → memory 객체
- 객체의 속성 → 객체의 특성(property), 속성 (attribute), 멤버의 변수 (member vatiable).
- 객체의 기능 → 객체가 하는 기능들을 메서드로 구현 method, member function

**객체 지향 언어에서의 객체**

- **new연산자를 통해 클래스의 설계대로 데이터를 메모리에 할당한 결과물(instance)이다.**
    
    ![[02 - 학습/KH 교육과정 2022/수업 필기/JAVA 이론/첨부/99032b28_Untitled.png]]
    
    속성(필드) → 정적인 상태 , 기능(메소드) → 동적인 행동
    

#### 객체 생성

```java
클래스명 참조변수명 = new 클래스명();
```

![[02 - 학습/KH 교육과정 2022/수업 필기/JAVA 이론/첨부/b222ae7c_Untitled.png]]

- 참조형 변수는 기본형 변수 ( 데이터 값 저장) 와 달리 데이터가 저장된 곳의 주소가 저장됨

```java
<객체 만들기>

public class StudentMain {

	public static void main(String[] args) {
		// 학생객체 1
		Student s1 = new Student();
		// 상태(속성) 값대입
		s1.name = "홍길동"; 
		s1.gender = '남';
		s1.age = 16;
		// 행동(기능) 실행
		s1.introduce();
		
		//학생객체2
		Student s2 = new Student();
		s2.name = "신사임당";
		s2.gender = '여';
		s2.age = 16;
		s2.introduce();
	}
}
```
