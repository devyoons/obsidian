# 강의: 배열 값 교환, 정렬

## 강의 내용

- 변수 두 값 교환하는 개념과 동일하다

```java
int[] arr = {1, 3, 2};

temp = arr[1];
arr[1] = arr[2];
arr[2] = temp;

for(int n : arr){
	System.out.print(n + " ");
}
//결과
1, 2, 3
```

#### swap (값 교환하는 메소드 따로 만들기)

```java
public void swap(){
	int temp = arr[i];
	arr[i] = arr[i];
	arr[j] = temp;
}
public void test(){
	int[] arr = {1, 3, 2};
	
	swap(arr, 1, 2); //swap 메소드 호출
	
	for(int n : arr){
		System.out.print(n + " ");
	}

```

#### 배열정렬 알고리즘

- 알고리즘 → 문제를 해결하는데 있어 시간적(처리시간)/공간적(메모리사용량) 효율이 좋은 방법

#### 종류

1. 순차정렬 - 각 회차에 해당하는 인덱스 알맞는 수를 찾음.(오름,내림차순)
2. 선택정렬
3. 버블정렬
4. 삽입정렬
5. 퀵정렬
6. 합병정렬 등등..

#### 순차정렬

```java
public void test(){
	int[] arr = {5, 4, 1, 3, 2};
	
// i = 0, 1, 2, 3
	for(int i = 0; i < arr.length - 1; i++);{
	
		for(int j = 0; j < arr.length; j++){
		if(arr[i] > arr[j])
			swap(arr, i, j);
		}
	}

}
```

#### 선택정렬 (Selection Sort)

- 각 회차에 최소값을 가진 인덱스를 찾고, 마지막에 한번만 값 교환하는 정렬

```java
public void test3() {
		int[] arr  = {5, 4, 1, 3, 2};
		
		for(int i = 0; i < arr.length - 1; i++) {
			int min = i; //최소값을 i번지수라고 가정
			for(int j = i + 1 ; j < arr.length; j++) {
				if(arr[min] > arr[j])
					min = j;
				print( i, min, arr);
			}
			swap(arr, min, i);
		}
		System.out.println("결과 : "+ Arrays.toString(arr));
	}
```

### Arrays.sort () 메소드

#### 기본타입 배열 오름차순 정렬

```java
public clsdd Sort{
	public static void main(String[] args) {
		int arr[] = {4, 23, 33, 15, 17, 19};
		Arrays.sort(arr);

		for(int i : arr) {
			System.out.print("[" + i + "]");
		}
	}
}
//결과 
[4][15][17][19][23][33]
```
