## 추상메소드

- abstract 키워드를 사용한다.
- 메소드 몸통이 없다 → 자식클래스의 재작성메소드에서 구현예정
- 자식클래스간의 표준화된 규격을 제공하고 이를 활용할 수 있게 된다.
- 추상클래스 안에서만 정의될 수 있다.

## 추상클래스

- 미완성클래스. 객체생성할 수 없다. ->new Animal() 불가
- 필드/메소드를 가질 수 있는 일반 클래스
- 0개이상 추상메소드를 가질수 있다. (가질수도있고, 안가질수도 있다.)
→단, 추상메소드는 반드시 추상클래스 안에 있어야한다.
- 규격제공. 자식클래스는 반드시 추상메소드를 재작성해야한다.
- 추상클래스는 부모의 추상메소드를 구현하지 않아도 된다.

## 인터페이스

- 인터페이스도 하나의 클래스
- 컴파일된 결과는 동일하게 .class 이다.
- 일반필드/메소드를 가질 수 없다. 객체를 생성할 수 없다.→ new Runnable()x
- 상수/추상메소드만 가질 수 있다. → 오로지 규격제공용 클래스라고 볼 수 있다.
    - 상수 → public static final 생략가능
    - 추상메소드 → public abstract 생략가능
- JDK8부터 default/static 메소드를 사용할 수 있다.
    - default메소드 : 일반메소드처럼 사용가능. 자식객체에서 호출가능
    - static메소드
- 자식클래스(구현클래스)에서는 implements 키워드를 사용한다.
- 다중구현을 지원한다.(다중상속을해서 개수 제한없이 사용할 수 있다.)
- 추상클래스에 implements 한다면 구현해야하는 규격을 안해도된다.

```java
<컴파일된 결과는 동일하게 .class 이다.>
package kh.java.polymorphism.animal;

public interface Runnable {

}
```

```java
<상수/추상메소드만 가질 수 있다.→ 오로지 규격제공용 클래스라고 볼 수 있다.>

public interface Runnable {
	
	//상수 (public static final 생략가능)
//	public static final 
	int LEG_NUM = 4;
	
	
	//추상메소드(public abstract 생략가능)
//	public abstract 
	void run();
```

```java
<곰 클래스>
package kh.java.polymorphism.animal;

public class Bear extends Animal implements Runnable{

	/**
	 * 메소드재작성
	 * Method Overriding
	 * Method Implementation
	 */
	@Override
	public void say() {
		System.out.println("안녕하세요. 곰입니다.");
	}
	
	public void punch() {
		System.out.println("곰이 펀치를 날렸습니다.");
	}
	
	@Override
	public void attack() {
		punch();
	}
	
	@Override
	public void run() {
		System.out.println("곰이" + Runnable.LEG_NUM + "발로 달립니다.");
	}

	
}
```

```java
public void test8() {
		Bear bear = new Bear();
		Runnable run = bear; //다향성 적용
		
	    bear.attack();
	    bear.say();
	    bear.run(); 
	    
	    //Runnable 관련 기능만 사용가능
	    run.run();
	    System.out.println(Runnable.LEG_NUM);
	}
```

```java
<Washable interface>
package kh.java.polymorphism.animal;

}
```

```java
<Tiger class>
package kh.java.polymorphism.animal;

public class Tiger extends Animal implements Runnable, Washable{

	public void punch() {
		System.out.println("호랑이 펀치를 날렸습니다.");
	}
	
	@Override
	public void attack() {
		punch();
	}
	
	@Override
	public void say() {
		System.out.println("안녕하세요. 타이거입니다.");
	}

	@Override
	public void run() {
		System.out.println("타이거가 " + Runnable.LEG_NUM + "발로 달립니다.");
	}

	@Override

	}

}
```

## 추상클래스는 부모의 추상메소드를 구현하지 않아도 된다. → 해당 추상메소느는 자식클래스가 반드시 구현해야한다.

```java
추상클래스Animal는 부모의 추상메소드Soundable#getSound를 구현하지 않아도 된다.
 → 해당 추상메소느는 자식클래스Lion Bear Tiger Eagle가 반드시 구현해야한다.
```

```java
<인터페이스>

package kh.java.polymorphism.animal;

public interface Soundable {
	
	String getSound();
}
```

```java
<추상클래스>
package kh.java.polymorphism.animal;

public abstract class Animal implements Soundable{

	public abstract void say();
	
	public abstract void attack();
}
```

```java
<자식클래스>
-------------------곰--------------------
package kh.java.polymorphism.animal;

public class Bear extends Animal implements Runnable{

@Override
	public String getSound() {
		return "우르~ ";
	}
-------------------사자--------------------
package kh.java.polymorphism.animal;

public class Lion extends Animal implements Runnable {

@Override
	public String getSound() {
		return "크앙~";
	}
}
-------------------호랑이-------------------
package kh.java.polymorphism.animal;

public class Tiger extends Animal implements Runnable, Washable{

@Override
	public String getSound() {
		return "어흥";
	}

}
-------------------독수리-------------------
package kh.java.polymorphism.animal;

public class Eagle extends Animal implements Flyable{

@Override
	public String getSound() {
		return "꺄야악";
	}
}
```

```java
<Main클래스>
public void test12() {
		Animal[] animals = new Animal[4];
		animals[0] = new Tiger(); 
		animals[1] = new Lion(); 
		animals[2] = new Bear(); 
		animals[3] = new Eagle(); 
		
		for(Animal animal : animals) {
			System.out.println(animal.getSound());
		}
	}
```
