## 🧐필드의 초기화

- 자바에서 필드는 초기화하지 않아도 변수의 타입에 맞는 초기값으로 자동 초기화해줌
- 그래도 초기화한 후에 사용하는 것이 좋음

1. 명시적 초기화
2. 생성자를 이용한 초기화
3. 초기화 블록을 이용한 초기화

#### 명시적 초기화 (=)

```java
class InitTest{
    int x;	// 인스턴스 변수
    int y = x;	//인스턴스 변수
    
    void method1(){
	    	int i;		// 지역변수
        int j = i;	// Error!! 지역변수를 초기화하지 않고 사용
    }
}
```

<aside>
💡 참조형 변수가 가질 수 있는 값은
→ null(기본값 : 초기화된게 아님), 객체주소값

</aside>

## 🧐초기화블럭

- 초기화 블록이란 클래스 필드의 초기화만을 담당하는 `중괄호{ }로 둘러싸인 블록`을 의미.
- 초기화 블록은 생성자보다 먼저 호출되며, static 키워드의 유무에 따라 다음과 같이 구분함

#### 1. 인스턴스(멤버변수) 초기화 : { }

- 클래스 내에 블럭 {}을 만들고 그 안에 코드를 작성한다.
→ 생성자와 같이 인스턴스를 생성할 때 마다 수행된다.
- 생성자와 인스턴스 초기화 블록의 차이는 거의 없으므로 인스턴스 초기화 블록은 사용 잘안함
- 여러개의 생성자가 있으면 모든 생성자에서 공통으로 수행되어야 할 코드를 인스턴스 초기화 블록에 포함하여 코드의 중복을 막을 수 있음

```java
class Car {

   private String modelName;
	 private int modelYear;
	 private String color;
	 private int maxSpeed;
	 private int currentSpeed;

    { // 인스턴스 초기화 블록
        this.currentSpeed = 0; // 모든 생성자에서 공통으로 수행되는 코드
    }
    Car() {}

    Car(String modelName, int modelYear, String color, int maxSpeed) {

        this.modelName = modelName;
				this.modelYear = modelYear;
				this.color = color;
				this.maxSpeed = maxSpeed;
    }
public int getSpeed() {
        return currentSpeed;
    }
}
public class Member03 {
    public static void main(String[] args) {
        Car myCar = new Car();                // 인스턴스 생성
        System.out.println(myCar.getSpeed()); // 인스턴스 메소드의 호출
    }
}
//결과
0
```

#### 2. 클래스 초기화 블럭 : static { }

- 인스턴스 초기화 앞에 static을 붙이면 된다. 
→ 클래스가 메모리에 처음 로딩될 때 한번만 수행
- 생성자나 인스턴스 초기화 블록으로는 수행할 수 없는 클래스 변수의 초기화를 수행할 때 사용

```java
class test{
		static{  /*클래스 초기화 블럭*/}

		{ /*인스턴스 초기화 블럭*/}
		//....
}
```

```java
class InitBlock {
    static int classVar; // 클래스 변수
		int instanceVar;     // 인스턴스 변수

		static { // 클래스 초기화 블록을 이용한 초기화
			classVar = 10;
		}
}
public class Member04 {
    public static void main(String[] args) {
        System.out.println(InitBlock.classVar); // 클래스 변수에 접근
    }
}
//결과 
10
```

## 🧐필드(멤버변수)의 초기화 시기와 순서

### 인스턴스변수, 클래스변수 초기화

1. 자동 초기화 (기본값 대부분 0)

2. 간단 초기화 (=)

3. 복잡 초기화 : 클래스변수인 경우 static { }, 인스턴스변수의 경우 생성자

![[02 - 학습/KH 교육과정 2022/수업 필기/JAVA 이론/첨부/1db6f27a_Untitled.png]]

**1. 클래스 변수 (static)**

- 기본값 → 명시적 초기화 → 클래스 초기화 블록

<aside>
❓ static은 생성자를 호출하지 않아도 되기 때문에 생성자 초기화는 없다.

</aside>

**2.인스턴스 변수 (non-static)**

- 기본값 → 명시적 초기화 → 인스턴스 초기화 블록 → 생성자

### 멤버변수의 초기화

- 클래스 변수 초기화 시점 : 클래스가 처음 로딩될 때 단 한번(메모리에 올라갈때)
- 인스턴스 변수 초기화 시점 : 인스턴스가 생성될 때 마다(객체가 만들어질 때 마다)

```java
class InitTest{
		InitTest it = new InitTest();
    static int cv = 1;	// 명시적 초기화
    int iv = 1;		// 명시적 초기화
    
    static { cv = 2; }	// 클래스 초기화 블럭
    { iv = 2; }		// 인스턴스 초기화 블럭
    
    InitTest() {	// 생성자
    	iv = 3;
    }
}
```

1. 명시적 초기화(=) : 간단 초기화

```java
class Car{
   int door = 4;		// 기본형(primitive type) 변수의 초기화
   Engine e = new Engine();	// 참조형(reference type) 변수의 초기화
}
```

<aside>
💡 참조형 변수가 가질 수 있는 값은
→ null(기본값 : 초기화된게 아님), 객체주소값

</aside>

1. 초기화 블럭 : 복잡 초기화
- 인스턴스 초기화 블럭 : { 여러 문장 넣을 수 있음 }
- 클래스 초기화 블럭 : static { }
1. 생성자 : 복잡 초기화

```java
car(String colot, String gearType, int door) { //매개변수있는생성자
	this.color = color;
	this.gearType = gearType;
	this.door = door;
}
```

#### cv 복잡 초기화 static { } 예시

```java
class StaticBlockTest{
    static int[] arr = new int[10];	// 명시적 초기화
    static {	// 클래스 초기화 블럭 - 배열 arr을 난수로 채운다.
    	for(int i = 0; i < arr.length; i++){
            arr[i] = (int)(Math.random()*10) + 1;
        }
    }
}
//static 명시적 초기화로는 난수만드는걸 못하기 때문에 
//static{}초기화를 활용한다.
```
