# 강의: Java Prigraming

## 강의 내용

### 프로그램밍이란?

- 프로그램 (Program) - 일정한 기능을 수행하는 컴퓨터가 인식할 수 있는 명령어들의 집합
- 프로그래밍 (Programming) - 프로그램을 작성하는 과정
- 프로그래머 (Programmer) - 프로그램을 작성하는 사람

### 프로그래밍 언어란?

- 프로그램을 작성할 때 사람과 컴퓨터 사이에 대화를 가능하게 해주는 컴퓨터가 이해할 수 있는 언어

### 자바 언어의 특징

- 객체 지향 언어
- 운영체제에 독립적이다.
- 능률적이고 명확한 코드를 작성하게 해 준다.
- 사용하기 쉬운 언어이다.
- 자동으로 메모리 관리를 한다. (Garbage Collection)
- 동적로딩을 지원한다.
- 멀티쓰레드를 지원한다.

- JVM이란? 
Platform(운영체제)에 독립적이며 bytecode(class파일)을 해석하고, 실행한다. Java 프로그램과 운영체제를 연결해주는 기능을 수행

<기본 기능 2가지>

1. 자바 프로그램이 어느 기기, 또는 어느 운영체제 상에서도 실행될 수 있게 하는 것(”한 번 작성해, 어디에서나 실행한다”)
2. 프로그램메모리를 관리하고 최적화하는 것이다.
