### com.kh.java.HelloWorld 클래스의 원래 이름

- [com.kh.java](http://com.kh.java) 패키지
1. 소문자, 단어단위로 잘라서 작성 (ex. hello.world)
2. 패키지는 3레벨 이상 작성
3. 패키지를 고유하게 관리하기 위해 url을 뒤집어서 주로 사용.
(ex)  com.naver/ com.facebook)
4. java로 시작하지 말 것. jdk가 사용하고 있는 패키지이기 때문에 사용불가

- HelloWorld 클래스명
1. 반드시 첫글자는 대문자로 시작할 것.
2. 연결되는 단어의 시작은 대문자로 쓸 것. (가독성을 높이기 위해)
