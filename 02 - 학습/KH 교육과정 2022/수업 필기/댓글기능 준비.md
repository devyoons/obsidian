- memberId는 로그인하지 않아도 게시물 상세보기가 가능하기 때문에 loginMemberId()를 넘기면 안된다. 로그인 하지 않은 상태로 댓글을 등록하려고할 때 null값이 들어가면서 NullPointException이 일어날 수 있다.
    - 방법1. 로그인 후에만 사용할 수 있게 필터처리
    - 방법2. null 처리
        - `<%= loginMember != null ? loginMember.getMemberId() : "" %>`
- form input 태그 전부 hidden 타입 : 노출시킬 필요 없어서

```java
<script>
// 댓글창에 focus하면 로그인 메세지 전송
document.querySelector("textarea[name=content]").onfocus = (e) => {
	if(<%= loginMember == null %>)
		loginAlert();
}
// 등록버튼 클릭시 폼제출 방지
document.boardCommentFrm.onsubmit = (e) => {
	if(<%= loginMember == null %>){
		loginAlert();
		return false;		
	}
	const contentVal = e.target.content.value.trim();
	// 정규식을 만족하지 못할 때 (아무글자 혹은 개행문자포함 한글자이상인지)
	if(!/^(.|\n)+$/.test(contentVal)){
		alert("댓글 내용을 작성해주세요.");
		e.target.content.focus();
		return false;
	}
	
};
const loginAlert = () => {
	alert("로그인후 이용할 수 있습니다.");
	document.querySelector("#memberId").focus();
}
</script>
```
