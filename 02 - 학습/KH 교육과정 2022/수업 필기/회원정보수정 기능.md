    - 필터 배우기전
    
```java
	protected void doGet(
											HttpServletRequest request, 
											HttpServletResponse response) 
											throws ServletException, IOException {
		HttpSession session = request.getSession();
		Member loginMember = (Member) session.getAttribute("loginMember");

		if(loginMember == null)
			response.sendRedirect(request.getContextPath() + "/");
		else {
			RequestDispatcher reqDispatcher = request.getRequestDispatcher("/WEB-INF/views/member/memberView.jsp");
			reqDispatcher.forward(request, response);
		}
	}
```


```java
package member.controller;

import java.io.IOException;

import javax.servlet.RequestDispatcher;
import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;

import member.model.dto.Member;

/**
* Servlet implementation class MemberDetailSurvlet
*/
@WebServlet("/member/memberView")
public class MemberViewServlet extends HttpServlet {
private static final long serialVersionUID = 1L;
   
/**
 * @see HttpServlet#doGet(HttpServletRequest request, HttpServletResponse response)
 */
protected void doGet(
										HttpServletRequest request, 
										HttpServletResponse response) 
										throws ServletException, IOException {
	
	RequestDispatcher reqDispatcher = 
					request.getRequestDispatcher("/WEB-INF/views/member/memberView.jsp");
	reqDispatcher.forward(request, response);
	
}

/**
 * @see HttpServlet#doPost(HttpServletRequest request, HttpServletResponse response)
 */
protected void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
	doGet(request, response);
}

}
```

**DD의 이점**

- 이미 테스트된 소스코드에 대한 수정을 최소화한다.
- 소스코드가 없더라도, 애플리케이션을 목적에 맞게 수정할 수 있다.
- 코드변경이나 컴파일을 다시 하지 않아도 서버자원(Database 접속정보 따위) 을 바꿀 수 있다.
- 접근제어목록, 보안역할과 같은 보안에 관련된 업무도 쉽게 관리할 수 있다.
- 프로그래머가 아닌 웹 애플리케이션을 배포하고 설정을 수정할 수 있다.

생명주기 `ServletContext` > `HttpSession` > `HttpServletRequest`

- **`Servlet Context events`**
    - tomcat start → tomcat end 톰캣이 끝날 때까지 유지되는 객체(어플리케이션객체)
    - `Lifecycle` : servlet 객체 생성 이벤트
    - `Changes to attribute` : 속성 변경 이벤트
    
- **`HTTP session events`**
    - `Lifecycle` : session객체 생성 이벤트
    - `Changes to attribute` : 속성 변경사항 이벤트
    - Session migration : 세션을 합쳐서 관리하거나 추가할 때
    - Object binding : session속성에 특정 객체를 세팅 이벤트
    - `Changes to id` : id 변경시 이벤트
    
- **`Servlet request events`** : doGet , doPost에 전달되는 request객체
    - `Lifecycle` : request객체 생성 이벤트
    - `Changes to attributes` : request.setAttribute() 호출했을 때 발생되는 이벤트
    - `Async events` : 비동기처리관련 이벤트
    
1. **SessionCounterListener.java** 
    - Session이 새로 발행될 때 마다 카운터해주는 이벤트 클래스
        
```java
package common.listener;

import javax.servlet.annotation.WebListener;
import javax.servlet.http.HttpSessionEvent;
import javax.servlet.http.HttpSessionListener;

//@WebListener -> 어노테이션 작성시 web.xml에 작성하지 않아도 됨
public class SessionCounterListener implements HttpSessionListener {

	// 접속하고 있는 사용자 수
	private static int activeSessions;

    public SessionCounterListener() {
    }

	/**
   * @see HttpSessionListener#sessionCreated(HttpSessionEvent)
   */
  public void sessionCreated(HttpSessionEvent se)  { 
  	activeSessions++;
  	System.out.println("> 세션 생성! 접속 사용자 수 : " + activeSessions);
  }

	/**
   * 개발할 때는 브라우저를 껐다 켜도 세션을 계속 유지시켜주면서 계산이 틀어짐
	 * 세션 카운트가 마이너스 안되게 0보다 클때만 1씩 감소하도록함.
   */
  public void sessionDestroyed(HttpSessionEvent se)  { 
  	if(activeSessions > 0) activeSessions--;
  	System.out.println("> 세션 폐기! 접속 사용자 수 : " + activeSessions);
  }
}
```

```java
package common.listener;

import javax.servlet.annotation.WebListener;
import javax.servlet.http.HttpSession;
import javax.servlet.http.HttpSessionAttributeListener;
import javax.servlet.http.HttpSessionBindingEvent;

@WebListener
public class SessionAttributeManager implements HttpSessionAttributeListener {

  /**
   * Default constructor. 
   */
  public SessionAttributeManager() {
  	
  }

  public void attributeAdded(HttpSessionBindingEvent se)  { 
  	String name = se.getName(); // 현재 추가된 속성
  	Object value = se.getValue(); // value 값
  	System.out.println("> 세션 속성 추가! " + name + "=" + value);
  	
  	// 로그인한 사용자에 대한 별도처리
  	if("loginMember".equals(name)) {
  		// 사용자 로그인 내역 관리 db -> insert
  	}
  }
	// 로그아웃시 session.invalidate() 호출되면서 내부적으로 removed 이벤트발생
  public void attributeRemoved(HttpSessionBindingEvent se)  { 
  	String name = se.getName();
  	Object value = se.getValue();
  	System.out.println("> 세션 속성 제거! " + name + "=" + value);
  	
  	// 로그아웃한 사용자에 대한 별도처리
  	if("loginMember".equals(name)) {
	  		ex> 몇시에 로그아웃 하셨습니다.
  	}
  }
	// 기존에 생성한 속성명으로 또 실행해서 value 새로 세팅시 이벤트발생
  public void attributeReplaced(HttpSessionBindingEvent se)  { 
  	String name = se.getName();
  	Object value = se.getValue();
  	System.out.println("> 세션 속성 대체! " + name + "=" + value);
  }
}
```
