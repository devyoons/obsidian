### 자유변수

- free variable
- 함수내에서 지역변수로 정의되지 않는 변수

### Closure (변수를 보호하기 위해 사용)

- 참조하는 환경을 가진 함수
- 자유변수를 가지고 외부로부터 닫힌 함수
- cctv(closed corckit) -> 폐쇄회로TV : 외부에 공개되지않는 영상

#### 전역변수 카운터 (다른사람이 접근해서 변경하기 쉬움,보안취약)

#### 클로져 카운터

- 내부 cnt변수에 접근할수 있는 방법이 없음.(버튼만 가능)

#### @실습문제

- 사용자 입력값을 누적해서 덧셈처리해주는 클로저 함수를 작성
- 누적합 해당변수를 외부로부터 보호할 것.
- #test5 호출시마다 누적합이 콘솔에 출력되고, #num은 초기화처리

```jsx
const closureAdderMaker = () => {
    let sum = 0;
    return () => {
        sum += Number(num.value);
        console.log('누적합 : ', sum);
        num.value = "";
    };
};
const test5 = closureAdderMaker();
```

#### @눈코딩

```jsx
<button onclick="aoo()();">aoo</button><!-- 100 -->
<button onclick="boo()();">boo1</button><!-- undefined -->
<button onclick="boo()(999);">boo2</button><!-- 999 -->
<button onclick="coo(3)(5);">coo1</button><!-- 15 -->
<button onclick="coo()(5);">coo2</button><!-- NaN -->

<script>
const a = 1;
const aoo = () => {
    const a = 100; // 자유변수 
    return () => console.log(a); //100
}

const b = 9;
const boo = () => {
    const b = 99;
    return (b) => console.log(b); // 자유변수없음 ,b 매개변수 없음 , 999
}

const coo = (c) => { // c가 자유변수 (3)
    return (n) => {
    console.log(c * n); // 15, undefined*5 = NaN
    }
}
</script>
```

#### 함수를 배열에 담아 호출

```jsx
const arr = [
  () => console.log('a'),
  () => console.log('b'),  
  () => console.log('c'),
];

arr[0](); // a
arr[1](); // b
arr[2](); // c

arr.forEach((f) => f());
// a
// b
// c
```
