# 강의: 계정만들기

## 강의 내용

**`oracle 설치시 자동으로 sys, system계정이 생성된다.`**

1. sys 슈퍼관리자
    - db생성/삭제권한 있음. 그 외 모든 db관련 처리가능.
    - 로그인시 sysdba롤로 접속해야함
2. system 일반관리자
    - db생성/삭제권한 없음. 그 외 모든 db관련 처리가능
    - 일반 관리자 만들 때 이관리자로만 가능함
3. 새로 생성한 user가 스키마다.

#### 계정만들기

- sql문은 대소문자를 구분하지 않는다.
- 데이터와 사용자의 비번, 별칭은 대소문자를 구분한다
- ORA-65096: 공통 사용자 또는 롤 이름이 부적합합니다.
- 12c버젼부터 일반사용자는 c##, C## 접두사를 사용해야 한다.

```sql
-- 우회방법
-- 12c버젼부터 일반사용자는 c##, C## 접두사를 사용해야 한다.
alter session set "_oracle_script" = true; 
// 원래 false로 되어있는 값을 바꿔줌

-- 일반사용자 kh추가
CREATE USER kh -- 아이디
IDENTIFIED BY kh -- 비밀번호
DEFAULT TABLESPACE USERS; -- 실제 데이터 저장공간

-- 접속권한(create session), 테이블생성권한 부여
-- connect롤안에 접속권한 포함
grant connect, resource to kh;

-- tablespace users에 사용용량 무제한 설정
alter user kh quota unlimited on users;
```

- 위 코드를 보면 세미콜론이 끝나기 전 모든 문장을 한번에 실행함
- 코드 하나하나 실행해줘야함

#### 계정만들기 2

- (관리자계정) qwerty 생성 -> 접속(실패) create session권한 부재
- create session | connect 을 qwerty에게 부여 -> 접속 시도(성공)

```sql
-- c뭐시기 접두사 대신해서 이걸로 하고 밑에 코드 실
alter session set "_oracle_script" = true; 
-- 우측상단 system계정으로 변환
create user qwerty identified by qwerty default tablespace users; 
--1.권한부여방법
grant create session to qwerty;
--2.권한부여방법
grant connect to qwerty;
-- 용량 무한으로 주는 것.
alter user qwerty quota unlimited on users;
--------------------------------------------------------------
```

#### 현재 접속한 사용자 알아보기

```sql
show user;

-- 결과
user이(가) "system"입니다.
```
