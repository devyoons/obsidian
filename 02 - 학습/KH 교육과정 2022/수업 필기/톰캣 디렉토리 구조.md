# 강의: 톰캣 디렉토리 구조

## 강의 내용

#### 톰캣 디렉토리 구조 설명

---

- 톰캣의 다른 이름 **web appliction server** or **web container**

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/4b22065f_Untitled.png]]

| 디렉토리 이름 | 설명 |
| --- | --- |
| bin | 톰캣을 실행하고, 종료시키는 스크립트(.bat, .sh등)파일이 들어있다. |
| conf | 서버 전체 설정파일 폴더 (server.xml등) |
| lib | 톰캣구동하는데 필요한 라이브러리(jar(자바클래스))가 들어있다. |
| logs | 예외 발생 사항 등의 로그 저장 |
| temp | 임시 저장용 폴더 |
| webapps | 웹 어플리케이션 폴더 |
| work | jsp 파일을 서블릿 형태로 변환한 java파일과 class파일이 저장 |

#### 톰캣 주요 파일들

---

| context.xml | 세션, 쿠키 저장 경로 등을 지정하는 설정 파일이다. |
| --- | --- |
| server.xml | Tomcat의 설정 파일로 접근/접속에 관한 설정이 주를 이룬다. |
| web.xml | Tomcat의 환경설정 파일이며 서블릿, 필터, 인코딩 등을 설정할 수 있다. 가잘 먼저 읽는 파일 DefaultServlet 지정 및 Servlet-mapping |

#### web.xml 설정 항목

- 디렉토리 목록 - url 접근시 디렉토리 목록의 사용여부 결정
- 웰컴 페이지 설정 - url접근시 사용할 첫 페이지 설정
- 자동 서블릿 로드 - 서블릿이 재컴파일 되었을 때 자동으로 리로드할지 여부를 설정
- 특정 Webapp에 대한 디렉토리 목록 사용 설정
- 웹 컨텍스트 루트 디렉토리 및 요청 URL 설정
- 기본 webapp 디렉토리 변경
