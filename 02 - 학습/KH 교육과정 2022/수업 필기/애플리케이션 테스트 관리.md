### SDLC STLC V-Model

![](https://4.bp.blogspot.com/-5lgMh-8EckI/V2dPvG2agQI/AAAAAAAADyY/39Ia4gJE06o8z9NC907OYoIoGPlavhdFwCK4B/s1600/V%2BModel.png)

![[02 - 학습/KH 교육과정 2022/수업 필기/첨부/11782b21_Untitled.png]]

- **`SDLC`** Software/System Development Life Cycle
- **`STLC`** Software Test Life Cycle
- **`Unit Test`** 보통 메소드 레벨로 가장 작은 단위의 테스트
- **`Intergration` Test** 각 컴포넌트간의 상호작용에 대한 테스트
- **`System Test`** 실제 실행환경에서 요구사항의 완벽 수행여부(성능, 처리량, 처리시간)에 대한 테스트
- **`Acceptance Test`** 사용자(고객)이 직접 요구사항의 일치여부등을을 확인하는 테스트

## Terms

- `BTS` Bug Tracking System

## Test Case 작성하기 (실제 QA에서 작성하는 것)

### 구성

- 테스트케이스 아이디 : 요구사항 정의서 & 단위업무 정의서에 관련된 아이디
- 제목
- 설명/목적
- 시나리오
- 사전조건
    - 테스트 데이터 : 테스트를 하기 위한 샘플데이터에 대한 DDL, DML문
- 시작조건 : 테스트 시기등을 명시
- 종료조건 : 테스트 완료 조건을 명시
- 테스트절차
- 예상결과
- 실제결과
- 결과
    - `P` Pass : 통과
    - `B` Blocked : 보류
    - `F` Failed : 실패
