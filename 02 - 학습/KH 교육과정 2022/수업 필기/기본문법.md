## 변수

### 변수선언

- 변수 종류 : 멤버변수와 지역변수
- 멤버변수 : 전역변수라고도 하고 기본적으로 window객체의 멤버변수
- 변수에 대한 자료형을 선언하지 않음(자료형은 있음)

| **`변수명 = 값;`** | **`window.변수명`** 또는 **`this.변수명`**과 같은 의미이다. 변수 선언시 변수명 앞에 var를 붙이지 않으면 **전역변수**로 간주한다. |
| --- | --- |
| **`var 변수명 = 값;`** | 변수 선언시 변수명 앞에 var를 붙이면 **지역변수**다.
변수명 중복가능 |
| **`const 변수명 = 값;`** | 절대로 바뀌지 않는 상수 (수정X) , 대문자로 사용함   |
| **`let 변수명 = 값;` 
ES6에서 추가됨** | 이미 선언된 **변수명을 중복사용시 오류**가 발생
변수의 값을 바꿔 사용해야함 (scope 블럭안) |

<aside>
📖 변하지 않는 값은 **`const`**
변할 수 있는 값은 **`let`**으로 선언

</aside>

#### 숫자(number)

- Math static api
- 정수형 숫자와 부동소수점 숫자로 구분
- 내장객체로 Math객체 제공, 기본 메소드 존재

| Math.abs() | 절대값 리턴 |
| --- | --- |
| Math.random() | 0.0 이상 1.0미만의 난수 생성 |
| Math.round() | 반올림처리 후 리턴 |
| Math.floor() | 부동소수점 숫자를 정수로 리턴(소수점 자리버림) |
| Math.ceil() | 소수점 자리에서 무조건 올림 |
- **`NaN(Not a Number)`** : 숫자가 아닌 데이터를 숫자처럼 사용할 때 출력
- **`Math.random()` 1 ~10 사이의 정수형 난수**
    - 1 ~ 10 사이의 정수형 난수 : 버림(난수 * 경우의 수) + 최소값
    - rnd = Math.random();
    console.log(rnd);
    console.log(Math.floor(rnd * 10) + 1);

#### 기타자료형

- 논리값 (Boolean) : true, false 두가지 값을 가짐
- 객체 (Object) : new로 선언된 사용자 객체와 자바스크립트 내장객체
- undefined : 변수명이나 함수명으로 선언되지 않은 식별자일때 지정
- 함수(function): 함수(메소드)를 가지는 자료형

#### typeof()

- 값의 자료형을 확인하는 연산자
- 선언시 자료형을 지정하지 않아 변수명을 보고 데이터를 확인불가, 자료형 확인시 자주 사용
- **`typeof(“문자열값”)`** 또는**`typeof(‘문자열값‘)`** => string
- **`typeof(숫자) => number`**
- **`typeof(참/거짓) => Boolean`**
- **`typeof(객체) => object`**
- **`typeof(초기값이없는변수)`** => undefined
- **`typeof(function)`**=>**function**

## 데이터 형병환

#### 숫자 → 문자열

- 숫자와 문자를 +연산하게 되면 문자가 우선되어 숫자를 문자로 변환
- 강제 형변환 : **`String()`** 함수 이용

#### 문자열 → 숫자

- 숫자, 문자 +이외의 사칙연산시 숫자가 우선되어 문자를 숫자로 변환
- 강제 형변환
    - **`Number()`** : 숫자로 형변환. 변환불가한 문자가 있는 경우, NaN을 리턴
    - **`parseInt()`** : 정수로 형변환. 변환불가한 문자전까지 변환후 정수 리턴
    - **`parseFloat()`** : 실수로 형변환. 변환불가한 문자전까지 변환후 실수 리턴
- **`paseInt()`**함수는 인자가 2개로 문자열, radix(해당진수)를 선택할 수 있음

```jsx
console.log(
	Number(true),
	Number(false)
)
//결과
1, 0
--> "123ㅁㅇㄴ" 숫자와 문자가 섞여있으면 NaN 주의
Number(null) //0 -> 사용자로부터 취소버튼을 누르면 null로 날아옴
Number(undefined) //NaN
```

#### 대입연산시 ||

- a || b -> a가 존재하면 a를 사용, a가 존재하지 않으면 b를 사용.
- 둘 다 존재하지 않으면 object타입의 null을 반환

```jsx
<div id="exist"></div>
<div id="existOrNot"></div>
function test1(){
  const elem = document.querySelector('#existOrNot') || document.querySelector('#exist');
  console.log(typeof elem, elem);
}
```

#### 짧은 조건문

- a && b -> a가 true로 평가될때 b를 실행하라.
- a || b -> a가 false로 평가될때 b를 실행하라.
- 대입문은 괄호로 감싸서 처리할 것.
- return문은 우항에 사용불가

```jsx
function test2(){
    const num = Number(prompt("정수를 입력하세요"));
    // 홀후일때만 "축하합니다." alert처리
    // if(num % 2 != 0) alert("축하합니다."); -> 원래는 이렇게 if문을 사용함
    num % 2 != 0 && alert("축하합니다."); -> 짧은 조건문은 이렇게 가능
		num % 2 == 0 || alert("축하합니다");
										대입문이 온다면 (우선순위때문에 감싸줘야함)
}
```

#### && || 코드예제

```jsx
<script>
        var input = prompt("input number");
        var number = Number(input);
 
        (number % 2 == 0) && alert("짝수입니다.");
        (number % 2 == 0) || alert("홀수입니다.");
</script>
```

### for반복처리

- `for문`
- `for in문` : 요소의 속성 **Enumerable(나열하다)이 true인 속성값**을 사용

```jsx
function test12(){
        const arr = ['a','b','c'];
        // for in문 : index를 변수에 담아 처리
        for(let index in arr){
            console.log(index, arr[index]);
        }
    }
//
0 a
1 b
2 c
```

- `for of문` : **[Symbol.Iterator]이 구현된 객체대상**

```jsx
function test12(){
    const arr = ['a','b','c'];

    // for of문 : 실제요소를 변수에 담아 처리
    for(let ch of arr){
        console.log(ch);
    }
}
//
a
b
c
```

- `forEach메소드` : **콜백함수를 통해 모든 요소별로 호출**
    - for문으로 요소 확인하는것과 비슷

```jsx
function test12(){
    const arr = ['a','b','c'];

    // forEach : 매요소마다 호출될 콜백함수 
    // (ch:요소, index:인덱스)
    arr.forEach(function(ch, index){
        console.log(ch, index);
    })
}
//
a 0
b 1
c 2
```
