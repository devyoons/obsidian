# 학습: 프로젝트 제목, 개발 배경, 구현목표 설정

## 세부 내용

팀명, 프로젝트 제목, 개발배경, 구현목표 등 회의

팀명 : 감각적인조

프로젝트 제목 :  Sensual University

개발 배경(목적, 사유)

1. 학사관리사이트 UI가 엉망이고 복잡하다. (이해하기 어렵다, 불친절하다.)
2. 크롬에서 열리지 않는다.
3. 제대로 정리된 학교 사이트를 구축해보고 싶다.

구현 목표

로그인(개인정보수정), 공지사항,질문게시판, 채팅기능, 수강신청, 테마 변경,장바구니,성적관리

기존 벤치마킹 사이트 기능 :  로그인(개인정보수정), 수강신청, 성적관리, 장바구니

벤치마킹 사이트 대비 차별점 

- 테마 기능(어두운 화면) : 밝은화면을 꺼려하는 사람들을 위한 기능
- 채팅 기능 : 신입생이 처음 사용하거나 복학생들이 사용하기 어렵거나 불편할 때 도움을 줄 수 있도록 채팅 기능 사용
- 공지사항 및 자유게시판 : 학사관리에는 없고 학교사이트에 개별로 있어서  왔다갔다 번거로움이 없도록 하나의 사이트로 합침
