# 학습: 0304

## 세부 내용

- **시작화면 메뉴**
    
    **<서울 맛집 리뷰 프로그램>**
    
    회원가입
    
    로그인
    
    리뷰쓰러가기, 리뷰 둘러보기, 내가 쓴 리뷰 확인
    
    프로그램 종료
    
- **회원가입 및 로그인**
    
    **로그인 창**
    
    아이디/비번 입력, 객체 불러오기해서 아이디와 비번 비교해서 동일한 게 있을 시 이름 + ‘님 반갑습니다. 
    
    아이디 혹은 비밀번호가 틀렸을시에 로그인에 실패하였습니다. 프로그램을 종료합니다 출력
    
    **회원가입 창**
    
    회원가입(이름, 전화번호, 아이디, 비번)
    Collection(list/set/map)으로 관리하면서 동일한 아이디 있을 시 ‘사용 불가능한 아이디입니다.’  
    비번은 8~12자리로 등록(특수문자 1개이상 포함)
    ’회원가입이 완료되었습니다.’
    객체 파일로 저장 후 로그인 창으로 리턴
    
- **리뷰쓰기**
    
    지역, 가게명, 내용, 별점, 아이디 //// 추천수는 외부 사용자 입력 값을 받아서 추천수에 따라 값이 표출되어야 하기때문에 ... 일단은 빼고 작업하고 추가 할시 진행할게요 
    
    1. 리뷰쓰기 선택시 진입
    2. 리뷰쓰기 진입 후, 지역 입력받음
    3. 상세 리뷰 내용 입력받음
        - 가게이름
        - 별점 (num 0~5 / 다시 입력하세요)
        - 한줄평 공백포함 25자 이하 (String / 초과 시 다시 입력하세요)
    4. 입력받은 한줄평 한번 뿌려주고, 확인받기 (이 내용이 맞나요?)
    5. Y/N에서
    5-1. Y시, 입력받은 내용 리뷰 배열에 저장
    5-2. N시, 2번으로 다시 돌아감 break;
    6. 2번에서 선택한 지역명, 가게이름, 별점, 한줄평, ID를 리뷰 배열에 push
    7. 맨 처음 메인으로
- **리뷰 둘러보기**
    
    **진행 사항**
    
    **메뉴 둘러보기 → 지역 선택 → 정렬 선택 → 해당 지역 맛집 리스트 출력**
    
    서울 4~6개 지역 선정하여 해당 지역 별로 리뷰 확인할 수 있도록 , 별점은 숫자 입력 시 숫자만큼 문자☆로 변환해주어 리턴.
    
    Review 클래스 필드 지역, 가게명, 한줄평, 별점 중에 지역은 사용자 입력이 아닌 문자열 배열로 직접 관리. 4~6개
    리뷰 둘러보기 선택 시, 저장된 Review 객체 정보 list로 불러오고, 지역과 정렬 선택.
    정렬은 별점순, 추천순이 있고, 추가적으로는 리뷰가 많이 달린 순 고려
    
    > 출력 내용 : [가게명 (추천 갯수)] - 한줄평 (별점 ☆☆☆☆)
