**단축키 리스트**

`Ctrl + Shift + 숫자(1~9)` : 블록 종류 변경

`ESC` : 블록 1개 선택

`Shift + 방향키`⬆️⬇️ : 여러 블록 선택

`Ctrl(cmd) + Enter` : 할 일 완료

`Shift + Enter` : 줄바꿈

`Tab` : 들여쓰기

`Shift + Tab` : 내어쓰기
