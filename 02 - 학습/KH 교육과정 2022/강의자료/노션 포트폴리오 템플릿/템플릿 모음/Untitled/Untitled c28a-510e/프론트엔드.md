# 학습: 프론트엔드

## 세부 내용

**React**

Container Components에서 데이터를 처리하고 Presentation Components에서 데이터를 출력하는 방식 사용하였습니다. 중복되는 상태를 한번에 Container에서 처리하여 재사용성을 높였습니다.

**Styled-components** 

CSS를 Javascript Component에 바로 적용할 수 있고, props 전달을 통한 가변적 스타일링에도 용이하여 재사용성을 높이기 위해 사용하였습니다.

**Zustand**

전역 상태 관리 문제를 간결하게 해결할 수 있고 Flux 패턴을 따르는 Zustand 라이브러리를 사용하였습니다.

**RestAPI (Axios)**

[‣](https://app.notion.com/p/d20f73e0197c4f38b576bc508b05982a) 

백엔드(Spring)와 HTTP 통신을 위해 REST 원칙에 따라 API를 설계 및 구현하였습니다. 라이브러리로는 Axios를 활용했습니다.
