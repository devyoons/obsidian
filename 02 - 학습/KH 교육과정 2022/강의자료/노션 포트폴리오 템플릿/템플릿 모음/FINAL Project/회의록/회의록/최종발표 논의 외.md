- 체험 시간은 None
- 발표 순서 : PPT 발표 → 시연 → 코드 리뷰

## 역할분담

#### 공통

- 각자 맡은 기능 발표 준비
- 시연 시 언급해줬으면 좋겠는 부분 준협님께 정리해서 드리기
- 프로젝트 소감 슬랙 PPT 란에 올리기

#### 발표

- 준협 : 자율

#### PPT

- 주영 : 자율

#### 자료조사

- 도경 : 만든 UI 캡쳐, 회의록, 와이어프레임
- 성훈 : ERD, 요구사항
- 승훈 : 기능 써머리
