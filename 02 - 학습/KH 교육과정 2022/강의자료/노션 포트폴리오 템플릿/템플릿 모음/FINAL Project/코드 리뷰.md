# 학습: 코드 리뷰

## 세부 내용

### 커밋(PR) 관련

- 커밋 메세지
    - 변경된 내용
    - 공식적인 요구 사항을 참조하여 변경이 필요한 이유
    - 변화의 직간접적인 결과
- 참조 사이트
    - [https://beomseok95.tistory.com/328](https://beomseok95.tistory.com/328)
    - [https://github.com/woowacourse/java-racingcar/pull/123/commits](https://github.com/woowacourse/java-racingcar/pull/123/commits)
    - [https://github.com/kkongkeozzang/SELL-LUV/commits/master?after=50779061d0272b0d92932988dafe7e78b56faacc+69&branch=master](https://github.com/kkongkeozzang/SELL-LUV/commits/master?after=50779061d0272b0d92932988dafe7e78b56faacc+69&branch=master)
    

```java
feat : 새로운 기능에 대한 커밋
fix : 버그 수정에 대한 커밋
build : 빌드 관련 파일 수정에 대한 커밋
chore : 그 외 자잘한 수정에 대한 커밋
ci : CI관련 설정 수정에 대한 커밋
docs : 문서 수정에 대한 커밋
style : 코드 스타일 혹은 포맷 등에 관한 커밋
refactor :  코드 리팩토링에 대한 커밋
test : 테스트 코드 수정에 대한 커밋
```
