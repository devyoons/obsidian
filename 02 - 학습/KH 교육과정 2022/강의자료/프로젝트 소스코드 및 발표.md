## 간단 사용 설명서

※ 사용하기 전, com.pizza.mail 패키지의 SendMail 클래스에 아래 해당되는 부분에 자신의 GMail 계정 및 Google SMTP 설정을 통해 패스워드를 발급 받은 후 입력해주세요 !

SMTP 패스워드 발급 : 구글 설정 - 보안 - 앱 비밀번호

![[02 - 학습/KH 교육과정 2022/강의자료/첨부/1.png]]

- Main Menu
    - 주문 → Pizza Menu
    - 프로그램 종료 → return
    - 콘솔 그림 추가 예정
- Pizza Menu
    - 메뉴 선택
        
        └ pizza Set → 메뉴 선택 → Pizza Menu
        
        └ pizza → 메뉴 선택 → topping (5개 제한) → 토핑 선택 → Pizza Menu
        
        └ side → 메뉴 선택 → Pizza Menu
        
        └ drink → 메뉴 선택 → Pizza Menu
        
        └ sauce → 메뉴 선택 → Pizza Menu
        
    - 주문 → Order Menu
- Order Menu
    - print(장바구니 카테고리 순으로 정렬)
    - 메뉴 추가 → Pizza Menu
    - 메뉴 삭제
    - 결제하기 → Payment Menu
- Payment Menu
    - 포장 → Packing (할인 적용)
    - 배달 → Deliver (배달비 추가)
    - 장바구니 확인 → Order Menu
- Packing
    - 할인 적용 후 Order
- Deliver
    - 배달비 적용 후 Order
- Order
    - 주문 내역 메일로 전송
- Mail
