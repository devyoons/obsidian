# 학습: OvenApp & 시퀀스 다이어그램

## 세부 내용

- OvenApp 최종본 도출
- 시퀀스 다이어그램 시작

## OvenApp

링크 다 연결해주세용

사이드바 : TOP 버튼
비회원 : 로그인/회원가입
게시판 메인
후기 게시판 : 글 작성 버튼
후기 게시판 상세 : 여행 친구 게시판 상세 참고
플래너 게시판 상세 : 좋아요, 플래너 담기, 수정하기, 삭제하기
여행 친구 게시판 : 글 작성
여행 친구 게시판 상세 : 채팅
내 플래너 : 공유 취소 버튼 삭제
공유된 플래너 : 플래너 추가하기 삭제
로그인 회원가입 : 기존에 있는 걸로

## 시퀀스 다이어그램

전인찬 : 게시판 (플래너, 여행친구, 후기), 관광정보페이지
안태현 : 마이페이지
최윤서 : 회원가입 (API, 사이트)
이경석 : 플래너
김용민 : 채팅 (채팅방)
