# 학습: OvenApp틀 설계 및 역할 분담

## 세부 내용

## OvenApp

용민 : 플래너 공유, 여행친구 구하기
인찬 : 검색, 관광 정보 상세 페이지
경석 : 플래너, 지도 API
윤서 : 로그인/회원가입, 메인페이지
민지 : 게시판(베스트 후기, 후기), FAQ페이지, 관광 정보 후기글 작성 등
태현 : 마이페이지

---

## 역할 분담

OvenApp : 권민지 (피그마로 넘어갈 수 있음)
ERD : 김용민
유스케이스 : 안태현
요구사항 정의서 및 프로젝트 일정 및 단위업무지정서 : 전인찬
PPT 제작 : 최윤서
영상 편집 : 이경석

---

## 앞으로의 계획

OvenApp -> 유스케이스 -> 요구사항 정의서 및 프로젝트 일정 및 단위업무지정서 -> ERD -> 시퀀스 다이어그램 -> PPT순으로 진행할 예정

OvenApp : 각자 파트를 나눠 디자인 및 전체적인 기초 틀 설계 진행 후 한명이 맡음

ERD : 각자 담당한 부분의 필요한 데이터 및 대략적인 테이블 설계 후 한명이 맡음

유스케이스 : 전체적인 틀을 같이 만든 후 한명이 맡음

요구사항 정의서 및 프로젝트 일정 및 단위업무지정서 : 전체적인 틀을 같이 만든 후 한명이 맡음

시퀀스 다이어그램 : 각자 맡은 부분제작. 기본적인 기능은 쳐내고 중요 기능 위주로 제작

PPT 제작 : 개발배경 및 구현 목표 설정, 각자 맡은 부분 제작 후 한명이 맡음
