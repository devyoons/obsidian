# 학습: 주제에 대한 구체적 테마 설정

## 세부 내용

## 주제

여행 사이트

1. 구체적으로 어떤 여행 사이트를 구축할건지 테마를 확실하게 정하기
1.1. ex) 국내? 해외?
1.2. ex) 국내 여행 일정 사이트라는 틀에서 태그를 통해 배낭, 차박, 캠핑 등등으로 구분하여 정보를 알려주는 사이트
1.3. ex) 해외 여행 일정 사이트라는 틀에서 여행지 및 비행기 정보등을 이용하여 일정을 알 수 있는 사이트
2. 정한 주제 및 테마를 바탕으로 API 조사 및 벤치마킹 사이트 조사

---

여행 일정 사이트

- 1순위 : 플래너 만들기 (일정 및 지도 API 이용)
- 2순위 : 후기 게시판 (본인의 플래너 공유)
- 3순위:- 커뮤니티 개념 (본인의 플래너를 공유하는 같이 여행할 사람 / 배낭, 차박, 캠핑 필터로 태그 게시판 및 채팅)
