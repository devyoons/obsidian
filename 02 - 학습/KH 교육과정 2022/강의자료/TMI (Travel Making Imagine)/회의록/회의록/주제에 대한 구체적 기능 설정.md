# 학습: 주제에 대한 구체적 기능 설정

## 세부 내용

## 기능

[ 로그인 ]

- 소셜 로그인 추가(카카오톡,네이버,구글)
- 아이디/비밀번호 찾기

[ 회원가입 ]
[ 마이페이지 ]

- 회원 정보 수정
- 회원 탈퇴

[플래너]

- 플래서 작성
- 플래너 조회 및 수정, 삭제

[ 지도 API ]

- 카카오지도API 이용
- 지도에 여행 공유 장소 표시

[게시판]

- 베스트 후기(여행지 홍보 게시판, 관광지 소개 게시판) , 후기, 공지사항 등
- 후기

[ 관광 정보 후기글 작성 ]

- 게시글 작성 (작성/수정/삭제)

[ FAQ 페이지 ]

- 1:1 질문하기 (작성/수정/삭제)
- 1:1 질문 댓글

[다른 플래너 구경하기]

- 플래너 공유하기
- 플래너 담기

[검색]

[ 관광 정보 상세페이지 ]

- 관광 공공데이터 정보 표시
- 한줄평 댓글 작성
- 액티비티 추천

[여행친구 구하기]

- 모집글 올리기
- 댓글, 대댓글
- 채팅

## 숙제

🤮OvenApp 설계 (18일 월요일까지)
용민 : 플래너 공유, 여행친구 구하기
인찬 : 검색, 관광 정보 상세 페이지
경석 : 플래너, 지도 API
윤서 : 로그인/회원가입, 메인페이지
민지 : 게시판(베스트 후기, 후기), FAQ페이지, 관광 정보 후기글 작성 등
태현 : 마이페이지
