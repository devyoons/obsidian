#### 2. 프로젝트 및 할 일 관리 사용방법

![[02 - 학습/KH 교육과정 2022/강의자료/첨부/7ebecdbd_Untitled.png]]

1. 팀원끼리 다같이 해야하는 일인데 잊을 것 같은걸 자유롭게 작성!
2. 할 일 목록은 날짜를 설정하지 않은 내용이 노출되는 것 관리가 따로 되지 않는 데이터임.

1. 프로젝트에 대분류로 나누는 회원가입, 게시판, 채팅 등을 추가할 때 편함 
2. 새로 만들기를 통해 만들 수 있음.
    - <u>회원가입을 예로 들자면</u> 새로만들기 진행 후 제목에 “회원가입”을 작성한다.
    - 진행상황을 비어있음을 누르면 목록 중 “시작전”선택한다.
    - “TASK” 회원가입 기능 하위에 있는 기능들을 부가적으로 나눈거임. 해당하는 기능을 전부 추가해준다.
    - PROJECT TEMPLATE을 눌러주면 완료된 기능과 완료되지 않은 기능을 체크박스로 관리할 수 있게 됀다.
