# 학습: 프로젝트 일정

## 세부 내용

기능 우선순위

1. 회원가입 (1 Day)
2. 로그인 / 로그아웃 (1 Day)
3. 판매 상품 등록 페이지 (2-3 Day)
4. 메인페이지 (2-3 Day)
5. 판매 글 상세보기 (1-2 Day)
6. 예약 및 채팅 기능 (2~3 Day)
7. 마이페이지 (내 상점 조회) (1 Day)
8. 관리자 페이지 (1 Day)
9. 신고하기 기능 (1 Day)
10. 상품 조회 카테고리, 지역별, 찜 상품 보기 (2 Day)
11. 구매 페이지 (2 Day)

기능 나누기

김정헌 - 판매 상품 등록, 글 상세보기

김경한 - 마이페이지 (내 상점 관리)

김동률 - 메인페이지

정서영 - 회원가입, 로그인

안태현 - 관리자 페이지
