# 학습: 기능 분석

## 세부 내용

- 마이페이지에서 내 동네 설정 -> 추천 할 때 동네 설정 가능
- 상품 문의 시 배송 문의 등의 카테고리가 필요할 것 같음
- 새 상품 보기
- 구매자 센터
- 상품 문의 시 비 공개 설정

로그인 / 회원가입 / 로그아웃 / 회원탈퇴

회원가입

1. 동네 설정
2. 계좌 인증
3. 닉네임
4. 관심 카테고리 설정

판매하기(상품등록)

1. 이미지 등록 (대표 이미지, 나머지 사진)
2. 새상품, 중고 선택
3. 타이틀, 내용
4. 가격
5. 거래지역 (구, 동) 5개 설정, 지역 설정 안함
6. 카테고리 설정
7. 가격 제안 불가 / 가능 버튼

구매하기

1. 제목, 내용
2. 가격
3. 카테고리 설정
4. 거래 지역, 방식

메인페이지

1. 검색 (카테고리, 지역)
2. 상품 추천(한줄) (로그인 x – 무작위?, 로그인 o – 설정 지역)
3. 판매하기, 구매하기
4. 중고, 새상품 토글 버튼 (새 상품만 보기)

내상점관리

1. 예약 중
2. 거래완료
3. 찜하기
4. 상품 문의 보기

관리자

신고 내역 확인 (상품, 상점)

상품 삭제

배너 수정

카테고리

Kream의 중고 버전

신발, 의류, 가방, 지갑, 프리미엄
