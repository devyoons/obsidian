### 게시판 목록 조회

1. 개요 

게시판 목록을 조회하는 유스케이스이다.

사용자는 페이지바를 사용할 수 있다.

1. 관계

개시자 : 사용자

사전 조건 : 사용자는 시스템에 접속하여 게시판 목록 조회 기능을 실행한다.

사후 조건 : 조회한 게시판의 목록이 나타난다.

1. 기본 흐름

게시판 목록 조회 기능 수행을 통해 조회한 게시판의 목록이 나타나며, 비회원과 회원 모

두 게시판 목록 조회가 가능하다.

### 공지사항(공지사항 상세조회 추가?) << …… ?

1. 개요

공지사항을 클릭하면 볼 수 있는 유스케이스이다. 사용자는 공지사항 목록을 조회할 수 있으며 관리자는 공지사항을 조회, 관리할 수 있다.

1. 관계

개시자 : 사용자, 관리자

사전 조건 : 사용자는 시스템에 접속하여 공지사항 조회 기능을 실행하고 관리자는 로그인 후 실행한다.

사후 조건 : 사용자가 조회한 공지사항의 목록이 나타나며 게시글 상세 조회도 가능하다. 관리자는 추가로 등록 및 수정, 삭제 기능이 화면에 출력 된다.

1. 기본 흐름
    1. 공지사항 조회 기능 수행을 통해 조회한 공지사항의 목록이 나타난다.
    2. 목록이 나타난 후 게시글을 클릭하면 상세 조회가 가능하다.
    3. 관리자가 공지사항 게시판을 클릭할 시 등록, 수정, 삭제 버튼이 화면에 추가로 출력되어 조회 및 게시판 관리가 가능하다.

### 게시글 상세 조회

1. 개요

게시글을 클릭해서 조회할 수 있는 유스케이스이다. 

1. 관계

개시자 : 사용자(회원)

사전 조건 : 사용자는 로그인이 되어있어야 하며, 게시판 목록 조회 유스케이스가 수행된 

상태에서 게시글 상세 조회 기능을 실행한다.

사후 조건 : 조회한 게시글이 화면에 출력된다.

1. 기본 흐름
    1. 게시판 목록 조회 기능을 통해 게시글의 제목 및 작성자 등이 보여지게 된다.
    2. 화면에 나타난 게시판 목록 중에서 조회하고자 하는 게시글을 선택해서 게시글

         상세 조회 화면으로 이동할 수 있다.

2. 예외 흐름

로그인하지 않은 사용자(비회원)가 게시글 상세 조회를 클릭한 경우

- 로그인 후 조회 가능하다는 경고창을 띄어준다.

    관리자가 샐러브리티(식단관리 쇼핑몰)에서 회원을 관리할 수 있는 유스케이스이다. 회원가입을 통해 회원목록에 등록된 회원을 관리할 수 있다.

    1. 개시자 : 관리자
    2. 지원자 : 
    3. 사전 조건 : 관리자 계정으로 시스템에 접속하여 관리자 페이지에 접근한다.
    4. 사후 조건 : 회원들의 목록이 나타난다.

    1. 회원 조회 기능 수행을 통해 전체 회원 목록이 보여지게 된다.

▫️ **상품관리**

1. 개요

    관리자가 샐러브리티에서 상품을 관리할 수 있는 유스케이스이다. 상품 목록에 등록된 상품들을 조회하고 관리하거나 새로 상품을 등록할 수 있다.

2. 관계
    1. 개시자 : 관리자
    2. 지원자 : 
    3. 사전 조건 : 관리자 계정으로 시스템에 접속하여 관리자 페이지에 접근한다.
    4. 사후 조건 : 상품 목록이 나타난다.

3. 기본흐름
    1. 상품 조회 기능 수행을 통해 전체 상품 목록이 보여지게 된다.
    2. 화면에 나타난 상품 목록들 중에서 조회하고자 하는 상품을 선택해서 상품의 상세 정보 화면으로 이동할 수 있다. *(상품상세조회)*
    3. 상품상세조회 화면에서 상품 정보를 수정할 수 있다. *(상품정보수정)*
    4. 상품상세조회 화면에서 등록된 상품을 삭제할 수 있다. *(상품삭제)*
    5. 기본흐름 b로 돌아간다.

4. 대안흐름
    1. 키워드(상품등록번호, 상품명 등)로 검색하는 경우
        1. 관리자가 입력한 키워드가 포함된 상품 목록들이 조회된다.
        2. 화면에 나타난 상품 목록들 중에서 조회하고자 하는 상품을 선택해서 상품의 상세 정보 화면으로 이동할 수 있다. *(상품상세조회)*
        3. 상품상세조회 화면에서 상품 정보를 수정할 수 있다. *(상품정보수정)*
        4. 상품상세조회 화면에서 등록된 상품을 삭제할 수 있다. *(상품삭제)*
        5. 기본흐름 b로 돌아간다.

5. 예외 흐름
    1. 관리자 계정으로 접근하지 않았을 경우
        1. 관리자 외 접근이 불가능하다는 경고창을 발생시킨다.
        2. 메인페이지로 돌아간다.

3. 기본흐름
    1. 비회원이 회원가입을 신청한다.
    2. 회원으로 가입하기 위해 필요한 정보(이름, 아이디, 비밀번호, 주소, 주민등록번호, 이메일, 전화번호)를 입력한다.
    3. 유효성검사를 통과하면 가입이 완료된다.
4. 대안흐름
5. 예외흐름
E1. 아이디가 중복된 경우
1) 아이디는 중복이 허용되지 않기 때문에, 시스템은 이미 등록된 아이디라는 알림창을 띄운다.
E2. 아이디를 입력하지 않고 중복 확인을 누른 경우
1) 시스템은 아이디를 입력하라는 알림창을 띄운다.
E3. 이메일이 중복된 경우
1) 아이디는 중복이 허용되지 않기 때문에, 시스템은 이미 등록된 아이디라는 알림창을 띄운다.
E4. 이메일을 입력하지 않고 중복 확인을 누른 경우
1) 시스템은 아이디를 입력하라는 알림창을 띄운다.
E5. 전화번호가 중복된 경우
1) 이미 등록된 전화번호라는 알림창을 띄운다.

### 로그인

1. 개요
    - 인터넷 쇼핑몰에 로그인을 수행하는 유스케이스이다. 이용자는 사이트의 서비스를 이용하기 위해 로그인을 하고 관리자는 사이트의 관리를 위해 로그인을 해야 한다.
2. 관계
    - 공통사용자
    - 사전조건 : 사용자가 시스템에 접속하여 로그인 기능을 실행한다.
    - 사후조건 : 로그인되고, 메인페이지가 실행되고, 관리자일 경우 관리자페이지가 실행된다.
3. 시나리오
    1. 공통사용자가 아이디와 비밀번호를 입력하고 로그인을 수행한다.
    2. 입력된 아이디와 비밀번호가 존재하는 경우 해당 페이지를 출력하게 된다.
4. 대안흐름
A1. 로그인한 사용자가 고객인 경우
1) 메인화면이 출력된다.
A2. 로그인한 사용자가 관리자인 경우
1) 관리자 화면이 출력된다.
5. 예외흐름
E1. 아이디를 입력하지 않은 경우
1) 아이디를 입력하라는 알림창을 띄운다.
E2. 비밀번호를 입력하지 않은 경우
1) 비밀번호를 입력하라는 알림창을 띄운다.
E3. 사용자가 존재하지 않는 경우
1) 아이디와 비밀번호를 확인하라는 알림창을 띄운다.
