# 학습: cron

## 세부 내용

- 1분마다
    
    ```java
    0 */1 * * * ?
    ```
    

| 위치 | 값 | 뜻 |
| --- | --- | --- |
| 초 | 0 | 매 분의 0초에 실행 |
| 분 | */1 | “매 1분마다” |
| 시 | * | “모든 시간에” |
| 일(일) | * | “매일” |
| 월 | * | “매월” |
| 요일 | ? | “특정 요일 지정 안 함 (충돌 방지)” |
