# 학습: 자바 ORM 표준 JPA 프로그래밍 - 기본편

## 세부 내용

---

---

#### JPA ? -Java Persistence API

- 과거에는 객체를 데이터베이스에 저장하려면 복잡한 JDBC API와 SQL을 한땀한땀 직접 작성했었음
- MyBatis , JDBC Template SQL MAPPER가 등장하면서 개발코드는 많이 줄었지 개발자가 SQL은 직접 작성해야했다.
- JPA를 사용하면 SQL조차도 작성할 필요가 없다. jpa가 적절한 sql을 생성하고 데이터베이스에서 실행해서 객체를 저장거나 불러오게된다.

#### 목표 - 객체와 테이블 설계 매핑

- 객체와 테이블을 제대로 설계하고 매핑하는 방법
- 기본 키와 외래 키 매핑
- 1:N, N:1, 1:1, N:M 매핑
- 실무 노하우 + 성능까지 고려
- 어떠한 복잡한 시스템도 JPA로 설계 가능

#### 목표 - JPA 내부 동작 방식 이해

- JPA의 내부 동작 방식을 이해하지 못하고 사용
- JPA 내부 동작 방식을 그림과 코드로 자세히 설명
- JPA가 어떤 SQL을 만들어 내는지 이해
- JPA가 언제 SQL을 실행하는지 이해
