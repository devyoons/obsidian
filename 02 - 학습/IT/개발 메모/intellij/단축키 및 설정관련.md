#### 1. 단축키 설정하기

- file → settings → keymap 검색 → Editor actions 검색을 통해 원하는 단축키 설정

#### 2. 단축키 바로 검색해보기

- ctrl + shfit + a

#### 3. 전체 검색하기

- shift + shift 두번 연속으로 치면 검색창이 나옴

#### 4. 상단 프로젝트 디렉토리 단축키로 이동하기 (jump to navigation bar)

![[02 - 학습/IT/개발 메모/intellij/첨부/efe7275d_Untitled.png]]

- alt + home → 방향키로 이동가능

![[02 - 학습/IT/개발 메모/intellij/첨부/fe7c1c23_Untitled.png]]

- alt + left, right

#### 6. 다른 클래스 파일 내용 빠르게 확인하기

- project 창에서 class 원하는 파일 클릭 후 space bar를 누른상태로 방향키로 이동가능
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/bc846b97_Untitled.png]]
    

#### 7. column selection mode 여러줄 수정

- alt + shift + insert 혹은 ctrl + shift + a 로 column 검색 후 off 를 on으로 변경하면 사용할 수 있다.
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/5410f62b_Untitled.png]]
    

#### 8. switcher 다른 창이나 열려있는 파일로 이동

- ctrl + tab (ctrl 키를 누른채로 tab 또는 shift + tab으로 위아래로 이동)
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/fc27c167_Untitled.png]]
    

#### 9. 최근에 읽거나 편집한 파일들의 목록 보기 (Recent Files/Recent Locations)

- ctrl + E / ctrl + shift + E
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/4044ded6_Untitled.png]]
    
- 둘러싸고 있는 창 단축키도 확인할 수 있음 (project창 없어졌을 때)
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/06b0dbce_Untitled.png]]
    

#### 10. 한줄/여러 줄 주석(토글)

- ctrl + / , ctrl + shift + /

#### 11. 원하는 단어 코드검색 find / replace

- ctrl + F / ctrl + R ( 대체할 단어로 변경할 수 있음)
- 내려갈 땐 enter , 올라갈 땐 shift + enter

#### 12. Declaration / usage 선언부/사용된 곳으로 이동

- ctrl + B (원래 창으로 돌아갈 땐 ctrl + alt + 방향키(← , →))
- 타입정의로 바로 가고 싶을 때 ctrl + shift + B

#### 13. 단어 드래그 한줄 드래그

- 확대 : 커서 이동 → ctrl + w  (단어 → 한줄 → 메소드 ..)
- 축소 : ctrl + shift + w

#### 14. 행 이동 / 문장 이동

- alt + shift + up / down 한줄 이동
- ctrl + shift + up / down 문장 전체 이동

#### 15. 행 복사 / 삭제

- ctrl + D  / ctrl + Y

#### 16. 코드 들여쓰기 정리

- ctrl + alt + i
    
    ![[02 - 학습/IT/개발 메모/intellij/첨부/df0cc94a_Untitled.png]]
    

#### 17. 괄호 정리

Refomat Code 

- ctrl + alt + L

#### 18. 문장 자동 완성

- ctrl + shift + enter : 문장 중간에서 단축키 입력시 세미콜론으로 완성시켜줌.
- 한번 더 누르면 다음 문장으로 커서이동

#### 19. 변수 + soutv : ex.soutv

```java
ex.soutv 입력시
-> 자동완성
System.out.println("ex = " + ex);
```
