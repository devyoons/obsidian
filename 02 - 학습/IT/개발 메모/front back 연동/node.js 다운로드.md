# 학습: node.js 다운로드

## 세부 내용

1. 아래 url로 이동

[Node.js — Run JavaScript Everywhere](https://nodejs.org/en)

1. Download 화면에서 Package Manager가 아닌, Prebuilt installer를 클릭
    
    ![[02 - 학습/IT/개발 메모/front back 연동/첨부/5b480af1_image.png]]
    

1. LTS 버전이 명시된걸로 설정하여 Download 버튼 클릭한다.
2. 노드를 설치하는 동안 다른 옵션은 선택하지 않아도된다.  순서대로 [next] 클릭하고 [install]을 선택하면 node.js 가 설치된다.

![[02 - 학습/IT/개발 메모/front back 연동/첨부/a25a8569_image.png]]

1. 터미널에서 노드 버전을 확인한다. (`window` + `r` : cmd 검색)

```c
node --version
```
