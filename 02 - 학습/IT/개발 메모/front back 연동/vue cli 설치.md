## 세부 내용

1. 아래 url로 이동

    ![[02 - 학습/IT/개발 메모/front back 연동/첨부/ffc429b6_image.png]]
    

1. 스크롤 하단으로 내려가서 installation 클릭

![[02 - 학습/IT/개발 메모/front back 연동/첨부/a1d34d8e_image.png]]

1. `npm install -g @vue/cli` 복사 후 powershell 실행 (window + r)

![[02 - 학습/IT/개발 메모/front back 연동/첨부/2b422de1_image.png]]
