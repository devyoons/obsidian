# 학습: 프로젝트 생성 - 프론트엔드

## 세부 내용

1. 프로젝트를 생성할 디렉토리를 먼저 생성 후 해당 경로를 복사한다.
    
    ![[02 - 학습/IT/개발 메모/front back 연동/첨부/9d95ace8_image.png]]
    
2. window + r : powershell 입력
3. 복사한 디렉토리로 `cd` 명령어로 이동한다.
    
    ![[02 - 학습/IT/개발 메모/front back 연동/첨부/aa9bd5f8_image.png]]
    

1. 명령어를 입력하여 vue 프로젝트를 생성한다.
    
    ```powershell
    vue create fronted
    ```
    
    - [ERROR] 이 시스템에서 스크립트를 실행할 수 없으므로..
        - window 검색창에서 powersehll 검색 후 오른쪽 마우스 클릭 + 관리자 권한으로 실행을 클릭한다.
            
            ![[02 - 학습/IT/개발 메모/front back 연동/첨부/eedcf511_image.png]]
            
        - 아래 명령어를 붙여넣어서 입력한다.
        
        ```powershell
        Set-ExecutionPolicy RemoteSigned
        ```
        
        - 실행 규칙 변경을 `[A] 모두 예`로 입력후 Enter를 친다.
        - 그런 뒤 해당 powershell을 꺼주고 기존 에러났던 powershell로 이동한다.
2. 선택하는 내용이 나오는데 Default Vue3로 두고 Enter를 입력한다.

![[02 - 학습/IT/개발 메모/front back 연동/첨부/b2473647_image.png]]

1. 완료 후에 안내에 따라 실행시켜본다.
    
    ```powershell
    $ cd frontend
    $ npm run serve
    ```
    
2. `Local`에 해당하는 주소를 복사하여 window+r 에 해당 url을 입력하여 Enter를 입력한다.
