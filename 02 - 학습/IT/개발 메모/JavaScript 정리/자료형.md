# 학습: 자료형

## 세부 내용

- **Dynamic Typing**
    
    자바처럼 변수 선언시 자료형을 함께 명시하지 않고, 대입되는 값에 따라 변수의 타입이 결정된다.
    
    <aside>
    💡 변수 선언시 자료형이 아닌 `let`, `const` 키워드를 사용한다.
    
    - `let` 변수 선언시
    - `const` 상수 선언시 (초기화 필수)
    </aside>
    
    <aside>
    💡 `var` 키워드는 더이상 사용하지 않도록 한다.
    
    </aside>
    
    <aside>
    🙂 typeof 연산자는 값의 자료형을 확인하는 연산자이며, 함수 형식으로도 사용할수 있다.
    
    - `typeof 변수/값`
    - `typeof(변수/값)`
    </aside>
    
    ```jsx
    // 변수 선언 키워드 let(변수) / const(상수)
    let a; // 자료형이 아직 지정되지 않음
    console.log(typeof a, a); // undefined undefined
    
    // 값대입 : 값을 통해 자료형 지정 Dynamic Typing
    a = true;
    console.log(typeof a, a); // boolean true
    
    // const 상수는 반드시 초기화해야하면, 이후 값대입할 수 없다.
    // const s; // 'const' declarations must be initialized.
    // s = 'heyhey';
    const str = "Helloworld";
    // s = "Byebyeworld"; // Uncaught TypeError: Assignment to constant variable.
    console.log(typeof s, s); // string Helloworld
    ```
    
- `string`
    
    홑따옴표나 쌍따옴표로 감싸서 문자열을 표현한다.
    
    ```jsx
    // string 문자열 '' ""
    const str = 'abc';
    console.log(typeof str, str); // string abc
    
    const text = "안녕";
    console.log(typeof text, text); // string 안녕
    ```
    
- `number`
    
    정수, 실수를 구분하지 않고, 모두 number  타입이다.
    
    ```jsx
    const num = 123;
    console.log(typeof num, num); // number 123
    
    const n = 45.67;
    console.log(typeof n, n); // number 45.67
    
    // 정수/실수를 구분하지 않으므로 나누기 연산결과가 실수 일수 있다.
    console.log(10 / 3); // 3.3333333333333335 
    ```
    
- `boolean`
    
    true/false 논리값을 제어한다.
    
    ```jsx
    const bool = false;
    console.log(typeof bool, bool); // boolean false
    
    let flag = 5 < 3;
    flag = !flag;
    console.log(typeof flag, flag); // boolean true
    ```
    
- `object`
    
    기본 literal로 선언 `{}`
    
    날짜객체 `new Date()`
    
    배열 `[1, 2, 3]`
    
    ```jsx
    const obj = {
      name : '홍길동',
      n : 123.456,
      married : true,
      hobby : ['축구', '농구'],
      foo : function(){
        console.log('obj.fooooooooooooooooooooo');
      },
      friend : {
        name : '고길동'
      }
    };
    console.log(typeof obj, obj);
    console.log(obj.hobby); // ['축구', '농구']
    console.log(obj.foo); // function(){ console.log('obj.fooooooooooooooooooooo'); }
    console.log(obj.friend); // { name : '고길동' }
    
    const today = new Date();
    console.log(typeof today, today); // object Wed Apr 13 2022 10:46:31 GMT+0900 (한국 표준시)
    
    const arr = [1, 2, 3];
    console.log(typeof arr, arr);
    console.log(arr[0], arr[1], arr[2]);
    ```
    
- `function`
    
    ```jsx
    function foo(){
      console.log('fooooooooooooooooooooooooooooooooooo');
    }
    console.log(typeof foo, foo); // function function foo(){console.log('fooooooooooooooooooooooooooooooooooo');}
    foo(); // 함수 호출
    ```
    
- `undefined`
    
    변수에 값을 지정하지 않은 상태를 가리키는 타입이자 값이다.
    
    ```jsx
    let h;
    console.log(typeof h, h); // undefined undefined
    
    let m = 123;
    m = undefined; // 값 제거
    console.log(typeof m, m); // undefined undefined
    ```
    
- 원시타입 | 참조타입
    
    자바스크립트의 자료형은 다음과 같이 분류할 수 있다
    
    - 원시타입
        
        `call by value` 불변성
        
        - `string`
        - `number`
        - `boolean`
        - `null`
            - `object`타입
        - `undefined`
        - `bigint`
            - `number` 보다 큰 범위, 정밀한 수를 다루는 타입
        - `symbol`
            - 변경불가하고, 이름의 충돌 위험이 없는 유일한 객체의 프로퍼티 키(property key)를 만들기 위해 사용한다.
        - 원시래퍼타입
            
            <aside>
            🙂 원시타입을 객체처럼 속성, 메소드를 사용할 수 있게 해주는 타입
            
            원시 타입을 객체처럼 사용하는 순간, 자바스크립트 내부에서 사용하는 데이터의 인스턴스를 만들어 사용한다. `Auto-boxing`
            만들어진 객체는 코드를 실행 후 바로 다음 줄에서 해제된다.
            
            </aside>
            
            - `String`
                - Basics
                    
                    ```jsx
                    let s = "helloworld";
                    s.abc = '가나다'; // new String(s).abc = '가나다'와 동일. 오류발생 안함.
                    console.log(s.abc); // undefined 원시wrapper객체는 메모리 해제됨.
                    ```
                    
            - `Number`
            - `Boolean`
            - `Symbol`
    - 참조타입
        
        `call by reference`
