# 학습: 정규표현식

## 세부 내용

<aside>
💡 특정규칙을 가진 문자열 집합에 대한 표현식. 
유효성검사, 검색, 문자열대체등에 유용하며, 언어독립적이므로 여느 프로그래밍언어에서도 활용할수 있다.
간결하게 복잡한 조건을 검사 할 수 있으나 문법자체가 복잡하므로 학습비용이 비교적 높다.

</aside>

- 정규표현식 객체 생성
    
    ```jsx
    <button id="btn1">정규표현식객체</button>
    <script>
    /**
     * 정규표현식 객체 생성
     */
    btn1.onclick = () => {
      // 숫자포함여부 검사용 정규표현식
    	// gi는 flag문자로써 정규표현식의 옵션이다.
      const regexp1 = /[0-9]/gi;
      const regexp2 = new RegExp(/[0-9]/gi);
      const regexp3 = new RegExp("[0-9]", "gi");
    
      console.dir(regexp1);
      console.dir(regexp2);
      console.dir(regexp3);
    </script>
    ```
    
- 주요메소드
    - RegExp
        - `RegExp.prototype.test`
            
            `RegExp.prototype.test(string):boolean`  해당 문자열이 정규식에 부합하면 true반환, 아니면 false반환
            
        - `RegExp.prototype.exec`
            
            매칭된 결과를 배열로 반환
            
    - String
        - `String.prototype.search`
            
            `String.prototype.search(RegExp):number`
            
            정규식과 일치하는 문자열의 인덱스를 반환
            
        - `String.prototype.match`
            
            g flag추가시 정규식에 일치하는 문자열을 배열로 반환
            
        - `String.prototype.split`
            
            정규식에 일치하는 구분자로 분할후 문자열배열 반환
            
        - `String.prototype.replace`
            
            `String.prototype.replace(RegExp, newString):string`
            
            정규식에 일치하는 문자열을 새 문자열로 치환한 후 전체 문자열 반환.
            
- 대체문자
    
    ```jsx
    <button id="btn2">대체문자</button>
    <div class="area" id="area2"></div>
    <script>
    
    /**
     * 대체문자
     * - String#replace시 사용
     * - $& 매칭된 문자열
     * - $` 매칭 이전 문자열
     * - $' 매칭 이후 문자열
     */
     btn2.addEventListener('click', (e) => {
      const str = "javascript jquery ajax css sass";
      const regexp = /as/;
      area2.innerHTML = `${str.replace(regexp, '<mark>$&</mark>')}<br/>`;
      area2.innerHTML += `${str.replace(regexp, '<mark>$`</mark>')}<br/>`;
      area2.innerHTML += `${str.replace(regexp, "<mark>$'</mark>")}<br/>`;
      area2.innerHTML += `${str.replace(regexp, (matched) => `<mark>${matched}</mark>`)}<br/>`;
    });
    </script>
    ```

- flag `g` `i` `m`
    
    ```jsx
    <button id="btn3">flag</button>
    <div id="area3" class="area"></div>
    <script>
    const SUBSTITUTE = '<mark>$&</mark>';
    /**
     * flag문자 - 정규표현식 옵션
     * - g global 전역비교수행. g가 없으면 처음 매칭된 1건만 처리.
     * - i ignore 대소문자 구분하지 않고 처리
     * - m multiline 여러줄인 경우 행단위 비교 수행
     */
    btn3.onclick = () => {
      const str = 'Javascript jQuery Ajax sass';
      area3.innerHTML = `${str.replace(/a/, SUBSTITUTE)}<br>`;
      area3.innerHTML += `${str.replace(/a/g, SUBSTITUTE)}<br>`;
      area3.innerHTML += `${str.replace(/a/gi, SUBSTITUTE)}<br>`;
      area3.innerHTML += `${str.replace(new RegExp("a", "gi"), SUBSTITUTE)}<br>`;
    };
    </script>
    ```

- `.`
    
    ```jsx
    <button id="btn5">.</button>
    <script>
    /**
     * . 임의의 한글자
     * - 문자, 특수문자 공백 문자 하나를 가리킴

      console.log("a b", regexp.test("a b")); // true

      console.log("inner", regexp2.test("inner")); // false
      console.log("holidayin", regexp2.test("holidayin")); // false
    };
    </script>
    ```

- 단축문자 `\d` `\w` `\s` `\D` `\W` `\S`
    
    ```jsx
    <button id="btn7">단축문자</button>
    <div class="area" id="area7"></div>
    <script>
    /**
     * 단축문자
     * 
     * \d digit 숫자 한글자
     * \w word 문자(영문자/숫자/_) 한글자 (한글/공백 포함되지 않음)
     * \s whitespace 공백/개행/탭문자 한글자
     * \b boundary 경계 공백을 기준으로 단어구분
     * 
     * \D [^\d] 숫자가 아닌 한글자
     * \W [^\w] 문자가 아닌 한글자
     * \S [^\s] 공백/개행/탭문자 아닌 한글자
     * \B [^\b] 경계아닌 한글자
     */
    btn7.onclick = () => {
      // const str = "A1 B2 c3 d_4 e:5` ffGG77--__--	\t\t가\n나\n다";
      const str = `A1 B2 c3 d_4 e:5 fG12345 -@!@#$% 
    안녕      잘가
    水`;
      area7.innerHTML = `${str.replace(/\d/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/\w/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/\s/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/\D/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/\W/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/\S/g, SUBSTITUTE)}<br><br>`;
    
      // [] 표현식으로 변환
      // 0~9 5제외 [01234^56789] X [012346789] O
      area7.innerHTML += `${str.replace(/[0-9]/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/[0-9A-Za-z_]/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/[ \n\t]/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/[^0-9]/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/[^0-9A-Za-z_]/g, SUBSTITUTE)}<br>`;
      area7.innerHTML += `${str.replace(/[^ \n\t]/g, SUBSTITUTE)}<br>`;
    };
    </script>
    ```

- Escaping

- 수량자
    - `*` `+` `?`
        - `a*` a가 0개 이상
        - `a+` a가 1개 이상
        - `a?` a가 0, 1개
        
        ```jsx
        <button id="btn10">수량자 * + ?</button>
        <div class="area" id="area10"></div>
        <script>
        /**
         * 수량자 Quantifier
         * - a* a가 0개 이상
         * - a+ a가 1개 이상
         * - a? a가 0, 1개
         */
        btn10.onclick = () => {
          const str = "aabc abc bc";
          area10.innerHTML = `${str.replace(/a*b/g, SUBSTITUTE)}<br/>`;
          area10.innerHTML += `${str.replace(/a+b/g, SUBSTITUTE)}<br/>`;
          area10.innerHTML += `${str.replace(/a?b/g, SUBSTITUTE)}<br/>`;
        
          // @실습문제 
          // a로 시작하고, z로 끝나는 문자열 검사
          const regexp = /^a.*z$/;
          console.log(regexp.test("abcdefz")); // true
          console.log(regexp.test("a*z")); // true
          console.log(regexp.test("az")); // true
          console.log(regexp.test("abc")); // false
          console.log(regexp.test("xyz")); // false
          console.log(regexp.test("안a하b이c녕z")); // false
          console.log("-----------------------")
        
          // 영문자만으로 이루어진 문자열 검사
          const regexp2 = /^[A-Za-z]+$/;
          console.log(regexp2.test("abcde"));
          console.log(regexp2.test("a"));
          console.log(regexp2.test(""));
          console.log(regexp2.test("123"));
          console.log(regexp2.test("abc123"));
        };
        </script>
        ```
        
    - `{start, end}`
        - `a{2,5}` a가 2개이상 5개이하
        - `a{2,}` a가 2개이상
        - `a{3}` a가 3개
        - `~~a{,5}~~` a가 5개이하 → 이 문법은 지원하지 않는다.
        
        ```jsx
        <button id="btn11">수량자 {}</button>
        <div class="area" id="area10"></div>
        <script>
        /**
         * 수량자
         * - a{2,5} a가 2개이상 5개이하
         * - a{2,} a가 2개이상
         * - a{3} a가 3개
         * 
         * a{,5} a가 5개이하 - 이 문법은 지원하지 않는다.
         */
        btn11.onclick = () => {
          const str = "aa aba abba abbba";
          area10.innerHTML = `${str.replace(/ab{0,}a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab*a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab{1,}a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab+a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab{0,1}a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab?a/g, SUBSTITUTE)}<br>`;
          area10.innerHTML += `${str.replace(/ab{1}a/g, SUBSTITUTE)}<br>`;
        
          // 4자리 숫자로 이루어진 비밀번호 검사
          const regexp1 = /^\d{4}$/;
          console.log("1234", regexp1.test("1234")); // true
          console.log("123456", regexp1.test("123456")); // false
          console.log("abcd", regexp1.test("abcd")); // false
          console.log("12", regexp1.test("12")); // false
          console.log("가나다라", regexp1.test("가나다라")); // false
          console.log("----------------------------------")
          // 숫자로 시작하고 영문자가 3개이상 나오고, .로 끝나는 문자열 검사
          const regexp2 = /^\d[a-zA-Z]{3,}\.$/;
          console.log("9abcdefg.", regexp2.test("9abcdefg.")); // true
          console.log("9abc.", regexp2.test("9abc.")); // true
          console.log("100", regexp2.test("100")); // false
          console.log("1가나다.", regexp2.test("1가나다.")); // false
          console.log("123abc가나다.", regexp2.test("123abc가나다.")); // false
        };
        </script>
        ```
        
    - 게으른 수량자
        
        정규식에서 수량자는 기본적으로 greedy 작동한다.
        
        - `a*` 매칭문자열 a가 0개이상, 1개, 2개, ...인 경우 최대한 큰 수량을 매칭
        - `a+` 매칭문자열 a가 1개이상, 2개, 3개, ...인 경우 최대한 큰 수량을 매칭
        - `a?` 매칭문자열 a가 0, 1개인 경우 0개아닌 1개를 선택
        
        반면 게으른 수량자는 최소 수량으로 매칭을 선택한다.
        
        - `a*?` 매칭문자열 a가 0개이상, 1개, 2개, ...인 경우 최소 수량을 매칭
        - `a+?` 매칭문자열 a가 1개이상, 2개, 3개, ...인 경우 최소 수량을 매칭
        - `a??` 매칭문자열 a가 0, 1개인 경우 0개 선택
        
        ```jsx
        <button id="btn12">게으른 수량자 ?</button>
        <div class="area" id="area12"></div>
        <script>
        /**
         * - 정규식에서 수량자는 기본적으로 greedy 작동한다.
         * a* a가 0개이상, 1개, 2개, ... 최대한 큰 수량을 매칭
         * a+ a가 1개이상, 2개, 3개, ... 최대한 큰 수량을 매칭
         * a? a가 0, 1개 0개아닌 1개를 선택
         * 
         * 게으른 수량자 ?
         * - 최소수량을 매칭
         * a*? a가 0개
         * a+? a가 1개
         * a?? a가 0개
         * 
         */
        btn12.onclick = () => {
          const str = "internationalization";
          
          area12.innerHTML = `${str.replace(/i\w*n/g, SUBSTITUTE)}<br>`;
          area12.innerHTML += `${str.replace(/i\w+n/g, SUBSTITUTE)}<br>`;
          area12.innerHTML += `${str.replace(/i\w?n/g, SUBSTITUTE)}<br><br>`;
        
          area12.innerHTML += `${str.replace(/i\w*?n/g, SUBSTITUTE)}<br>`;
          area12.innerHTML += `${str.replace(/i\w+?n/g, SUBSTITUTE)}<br>`;
          area12.innerHTML += `${str.replace(/i\w??n/g, SUBSTITUTE)}<br>`;
        };
        </script>
        ```
        
- 그룹핑과 역참조
    - `() ()` 그룹1 그룹2
    - `\1 \2` 그룹값을 참조
    - `$1 $2` replace시에는 $숫자로 참조
    
    ```jsx
    <button id="btn13">grouping | back-reference</button>
    <div class="area" id="area13"></div>
    <script>
    /**
     * grouping | back-reference
     * - () () 그룹1 그룹2
     * - \1 \2 그룹값을 참조
     * - $1 $2 replace시에는 $숫자로 참조
     */
    btn13.onclick = () => {
      const str = "hello123hello456";
      area13.innerHTML = `${str.replace(/hello(\d+)/g, '안녕$1')}<br>`;
    ```

- Look Around
    
    ```jsx
    <button id="btn14">Look Around</button>
    <div class="area" id="area14"></div>
    <script>
    /**
     * Look Around
     * - 검사만 실시하고, 최종결과에는 포함되지 않는다.
     * 
     * 1. Look Ahead
     *  - a(?=b) b가 뒤따르는 a를 조회
     *  - a(?!b) b가 뒤따르지 않는 a를 조회
     * 
     * 2. Look behind
     *  - (?<=b)a 앞에 b가 존재하는 a를 조회
     *  - (?<!b)a 앞에 b가 존재하지 않는 a를 조회
     * 
     */
    btn12.onclick = () => {
      const str1 = 'hello world hello Tom hello Jane';
      area14.innerHTML = `${str1.replace(/hello(?= world)/g, SUBSTITUTE)}<br>`;
      area14.innerHTML += `${str1.replace(/hello(?! world)/g, SUBSTITUTE)}<br>`;
      
      const str2 = 'hello world lotte world t world';
      area14.innerHTML += `${str2.replace(/(?<=hello )world/g, SUBSTITUTE)}<br>`;
      area14.innerHTML += `${str2.replace(/(?<!hello )world/g, SUBSTITUTE)}<br>`;
      
    };
    </script>
    ```
