# 학습: 변수 유효범위

## 세부 내용

- `전역변수` 블럭 밖에 선언된 변수로 블럭 안쪽이나, 함수안에서 사용가능하다.
- `지역변수` 블럭 안쪽에 선언된 변수로 블럭 안쪽에서만 사용이 가능하다.

C/C++ 언어들은 기본적으로 block을 기준으로 전역과 지역을 나누는 block scope를 지원하다.

자바스크립트에서는 `let`, `const`를 사용해 변수를 선언할때 block scope를 가진다.

legacy코드에서 사용되었던 `var`는  이와 달리 function기준으로만 전역/지역을 나누는 함수 scop를 지원해 개발자들의 원성을 샀고, 이제는 let과 const로 대체되었다.

그 외에도 var는 <u>중복선언이 가능</u>하다거나 <u>전역에 var키워드로 작성한 변수가 window전역객체의 속성으로 등록</u>되어 기존 속성들을 덮어쓸수도 있는 위험한 상황도 있으므로 사용하지 말아야 한다.

- let | const
    
```jsx
<button onclick="test1();">let | const</button>
<script>
// 전역공간
const a = '안녕'; // 전역변수

function test1(){
  console.log(a); // 안녕

  const b = '잘가'; // 지역변수
  console.log(b); // 잘가
}
// 전역에서 지역변수에 접근할 수 없다.
// console.log(b); // Uncaught ReferenceError: b is not defined

// 증감변수 i도 for블럭안에 선언된 지역변수로 밖에서 접근할 수 없다.
for(let i = 0; i < 10; i++){
  let k = i;
}
// console.log(i); // Uncaught ReferenceError: i is not defined
// console.log(k); // Uncaught ReferenceError: k is not defined
</script>
```

- var 🤬
    
```jsx
<button onclick="test2();">var</button>
<script>
// function scope 함수스코프
// 함수블럭외에 다른 블럭은 무시
// var키워드는 변수를 중복선언해도 오류가 나지 않는다. :O
// 전역된 선언된 var키워드는 window전역객체의 속성으로 등록된다.  :(

for(var i = 0; i < 10; i++){

}
console.log(i); // 10 

function test2(){
  var m = 99;
  console.log(m); // 99

  // if블럭은 함수블럭이 아니므로 안밖을 구분하지 않는다.
  if(true) {
    var m = 80;
  }
  
  console.log(m); // 80
}
// 함수블럭안의 지역변수는 밖에서 접근할 수 없다.
// console.log(m); // Uncaught ReferenceError: m is not defined
</script>
```
