# 학습: 상속

## 세부 내용

- prototype
    
    [프로토타입과 프로토타입 상속](https://ko.javascript.info/prototypes)
    
    자식 생성자함수 & 프로토타입처리
    
    1. 부모생성자함수 호출 - `부모생성자.apply(자식객체)`
    2. 자식.prototype으로 부모.prototype 지정 `Object.create(부모.prototype)`
    3. 새로 생성된 부모.prototype객체에 생성자함수 재지정
    
    ```jsx
    /**
     * prototype을 통한 상속구현
     */
    const test1 = () => {
      const books = [
    		// new Book('매트릭스', 35000, .15),
        // new Book('오라클 완전정복', 30000, .2),
        // new Book('네오클래식', 15000),
        new Novel('매트릭스', 35000, .15, '연애'),
        new Novel('오라클 완전정복', 30000, .2, 'SF'),
        new Novel('네오클래식', 15000, undefined, '심리')
      ];
      books.forEach((book) => console.log(book));
    };
    
    // 부모 생성자 함수
    function Book(title, price, discountRate = .05){
      this.title = title;
      this.price = price;
      this.discountRate = discountRate;
    }
    Book.prototype.getSalePrice = function(){
      return this.price - (this.price * this.discountRate);
    }
    Book.prototype.toString = function(){
      return `제목 : ${this.title}, 판매가 : ${this.getSalePrice()}원(정가 : ${this.price}원)`;
    }
    
    // 자식 생성자함수
    // 1. 부모생성자함수 호출 - 부모생성자.apply(자식객체)
    // 2. 자식.prototype으로 - 부모타입객체 지정 (Object.create)
    // 3. 2번에서 생성된 자식.prototype객체에 constructor 속성지정
    function Novel(title, price, discountRate, type){
      // 1. 부모생성자함수 호출 - 부모생성자.apply(자식객체)
      Book.apply(this, [title, price, discountRate]);
      this.type = type;
    }
    // 2. 자식.prototype으로 - 부모타입객체 지정 (Object.create)
    //   - Object.create 전달한 객체를 부모로 하는 자식객체를 반환
    //   - (생성자함수를 호출하지 않아 속성이 추가되지 않는다.) 
    Novel.prototype = Object.create(Book.prototype);
    
    // 3. 2번에서 생성된 자식.prototype객체에 constructor 속성지정
    Novel.prototype.constructor = Novel; // Book -> Novel
    ```
    
    - call | apply | bind
        
        ```jsx
        /**
         * this binding과 관련한 함수
         * 
         * this를 binding해서 호출
         * - call(this객체, arg1, arg2, ...) - 함수의 매개인자를 나열
         * - apply(this객체, [arg1, arg2, ...]) - 함수의 매개인자를 배열로 전달
         * 
         * this가 binding된 함수리턴
         * - bind(this객체)
         */
        const test2 = () => {
          const foo = function(a, b){
            console.log(this, this.id, a, b);
          };
          foo(10, 20); // window undefined 10 20
        
          const obj = {
            id : 'qwerty1234'
          };
          foo.call(obj, 10, 20); // {id: 'qwerty1234'} 'qwerty1234' 10 20
          foo.apply(obj, [10, 20]); // {id: 'qwerty1234'} 'qwerty1234' 10 20
        
          const fooooooo = foo.bind(obj);
          fooooooo(10, 20); // {id: 'qwerty1234'} 'qwerty1234' 10 20
        };
        ```
        
    - Object.create
        
        <aside>
        💡 `자식생성자함수.prototype = Object.create(부모생성자함수.prototype)` 가 필요한 이유는 <u>부모타입의 객체</u>를 만들어 prototype chain에 추가하기 위해서이다.
        
        Book객체(Book.prototype의 자식객체)를 만들어 Novel.prototype으로 지정하면,  `Novel객체 → Novel.prototype(Object.create으로 생성) → Book.prototype → Object.prototype` prototype chain으로 만들수 있다.
        
        </aside>
        
        ```jsx
        /**
         * Object.create(객체)
         * - 생성자 호출없이 해당객체의 자식객체를 생성하는 메소드
         */
        const test3 = () => {
          // 1. new Room() 객체 - Room.prototype의 자식객체 생성. 생성자함수 호출(속성추가)
          const room1 = new Room(1);
          console.log(room1);
        
          // 2. Object.create(Room.prototype) - Room.prototype의 자식객체 생성. 생성자함수 호출안함(속성없음)
          const room2 = Object.create(Room.prototype);
          console.log(room2);
        
          console.log(room1.__proto__ === Room.prototype); // true
          console.log(room2.__proto__ === Room.prototype); // true
        };
        
        function Room (no){
          this.no = no;
        }
        ```

        ```jsx
        function Comic(title, price, discountRate, finished) {
          Book.call(this, title, price, discountRate);
          this.finished = finished;
        }
        
        Comic.prototype = Object.create(Book.prototype); // new 생성자함수호출 없이 Book객체 생성
        
        Comic.prototype.constructor = Comic;
        
        // super.toString()은 사용할 수 없다.
        Comic.prototype.toString = function(){
          return `[${this.finished ? '완결' : '연재중'}] ${Book.prototype.toString.call(this)}`;
        }
        ```
        
- class  ES6
    
    <aside>
    💡 class 문법은 생성자함수의 Syntactic Sugar 라고 한다.
    
    - <u>Syntactic sugar란</u> 문법적 기능은 그대로인데 그것을 읽는 사람이 직관적으로 쉽게 코드를 읽을 수 있게 만든다는 것.
    
    `class Person {}` 문법 구조가 하는일.
    
    - 생성자함수 작성,  상속관계를 문법적으로 쉽게 작성할 수 있다.
    - Person 라는 이름을 가진 생성자 함수를 만든다. 함수 본문은 생성자 메서드 constructor에서 가져오며, 생성자 메서드가 없으면 본문이 비워진 채로 함수 생성.
    - new 연산자를 통해 생성자함수를 호출하면 constructor가 호출된다.
    - 클래스내에 선언된 메소드(메소드단축문법)는 prototype에 작성이 된다.
    - 클래스내에 선언한 속성은 현재객체의 속성이 된다.
    - static키워드를 사용하면 생성자함수의 속성으로 등록할 수 있다
    </aside>
    
    [클래스](https://ko.javascript.info/classes)
    
    ```jsx
    class Person {
      // Person 생성자함수 속성으로 작성
      static x = 100;
      static y = function(){
        console.log('yyyyyyyyyyyyyyyyyyyyyyy');
      }
    
      // 생성자함수 : new Person() 호출될 함수
      constructor(name, phone){
        this.name = name;
        this.phone = phone;
      }
    
    	// 현재객체 속성으로 등록 (this없이)
    	married = false;
    
      // Person.prototype에 작성 : 메소드단축문법
      sayHi(){
        console.log(`안녕하세요, ${this.name}입니다.`);
      }
    
      // 현재객체에 기록 (비추)
      callMe = function(){
        console.log(`제 번호는 ${this.phone}입니다. 전화주세요~`);
      };
    
    }
    
    /**
     * extends Person이 대신하는 것
     * - Dev.prototype = Object.create(Person.prototype);
     * - Dev.prototype.constructor = Dev;
     * 
     * super(name, phone)이 대신하는 것
     * - Person.call(this, name, phone);
     */
    class Dev extends Person {
      constructor(name, phone, lang){
        super(name, phone); // 부모생성자 호출
        this.lang = lang;
      }
    
      /**
       * Override
       */
      sayHi(){
        super.sayHi(); // 부모 sayHi호출!
        console.log(`저는 ${this.lang}개발자 입니다.`);
      }
    
    }
    ```
    
    ```jsx
    /**
     * 클래스 상속

    const test4 = () => {
    ```

    <aside>
    💡 class문법  심화
    
    - class와 생성자함수는 대부분 같지만, 내부속성 `[[FunctionKind]]:"classConstructor"` 이 다르다.
    - class는 new 연산자로만 호출해야 한다.
    - 메소드는 `[Enumerable]`속성이 `false`라서 열거될 수 없다. for..in문 순회대상에세 제외된다.
    - class안은 항상 `use strict` 모드이다
    </aside>
