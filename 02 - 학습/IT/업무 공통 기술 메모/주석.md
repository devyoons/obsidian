### 메소드

#### 1. 화면조회

- 해당 화면에 명칭을 작성하고 설명으로는 “화면조회” 문구를 넣어주세요.

![[02 - 학습/IT/업무 공통 기술 메모/첨부/f3b5156b_Untitled.png]]

```java
/**
 * 공통코드 현황 관리
 * 
 * <p>화면조회</p>
 */
@GetMapping(path = "/codeView")
public ModelAndView codeView() {
    ModelAndView mav = new ModelAndView();
    mav.setViewName("views/biz/adm/code/codeView");

    return mav;
}
```

#### 2. 데이터 조회

- 해당 메소드가 하는 작업단위 명칭을 적고 `@param` 엔 어떤 값이 넘어오는지 작성해주세요.
- `@return` 은 `데이터타입 ModelAndView` 로 통일합니다.

![[02 - 학습/IT/업무 공통 기술 메모/첨부/784310a6_Untitled.png]]

```java
/**
 * 그룹 코드 조회
 *
 * @param codeVo 그룹 코드, 그룹명, 사용여부
 * @return List<CodeVo> ModelAndView
 */
@RequestMapping("/selectCodeList")
    public ModelAndView selectCodeList(@ModelAttribute CodeVo codeVo) {
        ModelAndView mav = new ModelAndView();
        mav.setViewName("views/biz/adm/code/codeView :: #resultTopAreaDiv");

        List<CodeVo> codeList;
        codeList = codeService.selectCodeList(codeVo);

        mav.addObject("comCdList", codeList);

        return mav;
    }
```

#### 3. 메소드 jsonView

- 위 데이터조회와 동일한 구조로 가져가며 `JSON type`에 대한 설명을 추가해주세요.

![[02 - 학습/IT/업무 공통 기술 메모/첨부/3b572a66_Untitled.png]]

```java
/**
 * 그룹 코드 1건 상세 조회
 *
 * @param codeDetailVo 공통 그룹 코드
 * @return ModelAndView (JSON type - CodeDetailVo)
 */
@RequestMapping("selectCodeDetail.json")
public ModelAndView selectCodeDetail(@ModelAttribute CodeDetailVo codeDetailVo) {
    ModelAndView mav = new ModelAndView("jsonView");

    CodeDetailVo codeDetail;
    codeDetail = codeService.selectCodeDetail(codeDetailVo);

    mav.addObject("codeDetail", codeDetail);

    return mav;
}
```

### 매퍼

- `<select><insert>`..등 태그 위에 한글로 설명 작성
- 태그 내부 첫줄은 id 값으로 주석을 추가해줍니다. ( 좌, 우 한칸씩 띄어쓰기)

```xml
...다른 쿼리내용

<!-- 그룹 코드 1건 상세 조회 -->
<select id="selectCodeDetail" parameterType="net.csms.biz.adm.code.vo.CodeDetailVo" resultType="net.csms.biz.adm.code.vo.CodeDetailVo">
    /* selectCodeDetail */

    SELECT CMMN_GROUP_CODE          
         , GROUP_NAME               
         , USE_YN                   
    FROM T_CMMN_GROUP_CODE_M1
    WHERE CMMN_GROUP_CODE = UPPER(#{cmmnGroupCode})
</select>
```
