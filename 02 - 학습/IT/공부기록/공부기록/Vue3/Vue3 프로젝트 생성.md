# 학습: Vue3 프로젝트 생성

## 세부 내용

1. 생성할 디렉토리를 만든다.

![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/6cb334f3_image.png]]

1. cmd 를 연다 (`window + R`)
    
    ![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/81b04cd0_image.png]]
    

1. 생성한 디렉토리 경로를 복사한다.
    
    ![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/e322ec0a_image.png]]
    

1. cmd에서 생성할 디렉토리로 이동한 뒤에 create해준다.
    
    ![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/e377d0f1_image.png]]
    
```bash
cd C:\project\study\2024_12_toy_project
vue create frontend
```

2. vue3 default 를 선택한다.
    - Vue 프로젝트를 어떻게 구성할 건지 preset(프리셋 : 사전 설정)합니다.
    - 키보드의 화살 키로 위/아래로 이동할 수 있습니다.
    - Vue 프로젝트를 기본 구성으로 된 Vue 2 또는 Vue 3 버전을 선택하거나 직접 기능을 선택할 수 있습니다.
    
    ![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/d6c973b9_image.png]]
    
    ![[02 - 학습/IT/공부기록/공부기록/Vue3/첨부/256475fc_image.png]]

1. intellij를 열고 `menu → file → open`  생성한 frontend 프로젝트를 열어준다. 
2. `Alt + F12` 터미널을 열어서 `npm run serve` 로 아까와 같이 웹사이트가 잘 열리는지 확인해준다.
