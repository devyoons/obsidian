# 학습: 정보처리기사 정리

## 세부 내용

| 번호 | 이름 | 한 줄 요약 | 외우는 팁 키워드 |
| --- | --- | --- | --- |
| 802.1 | **Bridging / Management** | 네트워크 연결 및 관리 표준 | 🔗 다리(Bridge), 관리 |
| 802.2 | **LLC (Logical Link Control)** | 이더넷의 상위 계층 제어 | 🧠 논리적 연결 |
| 802.3 | **Ethernet** | 유선 LAN, 우리가 잘 아는 이더넷 | 🔌 LAN의 대표, 이더넷 |
| 802.4 | **Token Bus (폐기됨)** | 버스 기반 토큰 링 방식 | 🚌 토큰+버스 (역사 속으로) |
| 802.5 | **Token Ring (IBM)** | 링 기반의 네트워크 | 💍 토큰+링 |
| 802.6 | **MAN (폐기됨)** | 도시 규모의 네트워크 표준 | 🏙 도시 (Metro) |
| 802.7~11 | 기타 전문가 그룹 (중간은 생략) |  |  |
| 802.11 | **Wi-Fi** | 무선 LAN 표준 | 📶 무선의 대명사 Wi-Fi |
| 802.15 | **WPAN (블루투스 등)** | 근거리 무선 통신 (블루투스 등) | 🤝 친구끼리 연결 (근거리) |
| 802.16 | **WiMAX** | 광역 무선 인터넷 | 🌍 넓은 거리, 와이맥스 |
| 802.17 | **Resilient Packet Ring (RPR)** | 광역 네트워크용 링 기반 기술 | 🔁 복원 가능한 링 |
| 802.20 | **Mobile Broadband Wireless** | 고속 모바일 무선 인터넷 | 🚗 고속 무선 인터넷 |
| 802.21 | **Media Independent Handover** | 다양한 네트워크 간 핸드오버 지원 | 🧳 이동 중 끊김 없는 전환 |
| 802.22 | **Wireless Regional Area Network (WRAN)** | TV 대역을 활용한 무선 브로드밴드 | 📺 TV 주파수 이용 |

802.1은 연결관리,
802.2는 논리제어지.

802.3 이더넷 선은,
802.5 링 구조야.

802.11 무선 Wi-Fi,
15는 블루투스 근거리!

16은 와이맥스 넓게 뻗고,
20은 고속 모바일이야.

21은 끊김 없는 이동,
22는 TV 대역 쓴대~

- **802.3**: 유선 LAN (이더넷)
- **802.11**: 무선 LAN (Wi-Fi)
- **802.15**: 블루투스 (WPAN)
- **802.16**: WiMAX (광역)
- **802.20**: 모바일 광대역
- **802.22**: TV 주파수 이용

### ✨ 주요 제어 문자 의미 + 쉽게 외우는 법

| 문자 | 이름 (약자 의미) | ASCII | 설명 | 외우는 포인트 |
| --- | --- | --- | --- | --- |
| **ACK** | Acknowledge | 0x06 | "응답 OK!" 성공 응답 | 👍 OK신호 |
| **NAK** | Negative Acknowledge | 0x15 | "응답 FAIL!" 오류 응답 | ❌ 실패 응답 |
| **SYN** | Synchronous Idle | 0x16 | 동기 맞추기용 채우기 문자 | 🔄 동기 맞춤 |
| **SOH** | Start of Header | 0x01 | 헤더(제목부) 시작 알림 | 📑 헤더 시작 |
| **STX** | Start of Text | 0x02 | 본문 텍스트 시작 | 📝 본문 시작 |
| **ETX** | End of Text | 0x03 | 본문 텍스트 끝 | 🔚 본문 끝 |
| **EOT** | End of Transmission | 0x04 | 전송 종료 (회선 닫음) | 📴 전송 종료 |
| **ENQ** | Enquiry | 0x05 | "나 들리니?" 상태 요청 | ❓상태 물어봄 |
| **DLE** | Data Link Escape | 0x10 | 제어 문자 삽입 예외처리 | 🛡 특수 예외 |

SOH 시작하고 STX 본문 써~
ETX 텍스트 끝내고 EOT로 닫아~

ENQ로 묻고 ACK 받으면 OK!
NAK 오면 재전송 Go~

SYN은 동기 맞추고~
DLE는 예외 처리야~!
