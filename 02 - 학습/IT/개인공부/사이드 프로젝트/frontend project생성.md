# 학습: frontend project생성

## 세부 내용

1. cmder에서 생성할 프로젝트 경로로 이동해준다.

`cd {프로젝트 경로}`

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/583c0400_Untitled.png]]

1. 해당 경로에서 `vue create frontend` 입력
2. 맨 위에 있는걸로 선택 후 `enter` → 설치 진행

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/947b6358_Untitled.png]]

1. 설치 완료후 안내해주는 명령어를 입력
    1. `cd frontend`
    2. `npm run serve`

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/30e6cdb0_Untitled.png]]

1. 위 local 주소를 복사 후 `win` + `R` 에 입력후 확인을 누른다.

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/75ccb861_Untitled.png]]

1. 브라우저에서 바로 띄워주며 웹페이지가 정상작동하는걸 알 수 있다.

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/7ce1d10c_Untitled.png]]

1. 인텔리제이에서 프로젝트를 열어주고 인텔리제이 터미널에서 실행해본다.

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/ae4dffd6_Untitled.png]]

1. backend 프로젝트와 포트가 겹치기 때문에 frontend 포트를 3000번으로 변경해준다.

![[02 - 학습/IT/개인공부/사이드 프로젝트/첨부/7259fc62_Untitled.png]]
