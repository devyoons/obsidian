# 03. 프롬프트 잘 쓰기

## 학습 목표

- 좋은 작업 지시의 네 요소(목표, 맥락, 제약, 확인 방법)를 넣어 쓴다.
- Claude가 스스로 결과를 검증할 수 있게 확인 방법을 준다.
- 모호한 요청을 구체적인 요청으로 바꿀 수 있다.

## 설명

### Claude가 못 보는 것을 알려 주기

Claude는 폴더 안의 파일은 읽을 수 있지만, **내 머릿속 의도, 회의 내용, 화면 상태, 팀 규칙**은 모릅니다. 공식 모범 사례도 "Claude가 볼 수 없는 것을 말해 주라"를 첫째로 꼽습니다.

### 네 요소

| 요소    | 질문           | 예                                 |
| ----- | ------------ | --------------------------------- |
| 목표    | 무엇이 되어야 끝인가? | "로그인 실패 시 오류 문구가 보이게"             |
| 맥락    | 어디를, 왜?      | "`src/auth/login.ts`, 사용자 문의가 많음" |
| 제약    | 하지 말 것, 지킬 것 | "API 응답 형식은 바꾸지 마"                |
| 확인 방법 | 어떻게 맞았는지 아나? | "`npm test` 통과, 화면 캡처로 확인"        |

### 확인 방법이 가장 중요

테스트, 예상 출력, 스크린샷처럼 **Claude가 직접 돌려 볼 수 있는 확인 수단**을 주면 결과 품질이 크게 올라갑니다. 확인 수단이 없으면 Claude는 "됐을 것"이라고 추측합니다.

### 나쁜 예 → 좋은 예

```text
나쁨: 로그인 고쳐 줘.
```

```text
좋음: 비밀번호를 틀리면 화면에 아무 문구가 안 나와. src/auth/login.ts의 오류 처리를 고쳐서
"이메일 또는 비밀번호가 틀렸습니다"가 보이게 해 줘. API 응답 형식은 바꾸지 마.
고친 뒤 이 상황을 재현하는 테스트를 하나 추가하고 npm test가 통과하는지 확인해 줘.
```

### 그 밖의 요령

- **먼저 묻게 하기**: "시작하기 전에 모르는 점이 있으면 질문부터 해 줘."
- **조사와 구현 나누기**: "아직 코드는 고치지 말고 원인 후보만 정리해 줘."
- **예시 주기**: 원하는 출력 형식을 한 줄이라도 보여 주면 정확해집니다.
- **어려운 문제는 `ultrathink`**: 프롬프트에 `ultrathink`를 넣으면 그 차례에 더 깊게 생각합니다. `think`, `think hard`는 특별한 키워드가 아니라 그냥 글자입니다. 평소 생각 깊이는 `/effort`(low, medium, high, xhigh, max, auto)로 정합니다.
- **한 세션엔 한 가지 일**: 관련 없는 작업 사이에는 `/clear`(11단계).

## 실습 과제

### 실습 1. 프롬프트 고쳐 쓰기

아래 모호한 요청 세 개를 네 요소를 넣어 다시 써 보세요. 그다음 Claude에게 평가를 받습니다.

```text
1) 이 코드 좀 빠르게 해 줘
2) 보고서 정리해 줘
3) 테스트 짜 줘
```

```text
내가 쓴 프롬프트 세 개야. 목표·맥락·제약·확인 방법 기준으로 빠진 게 뭔지 짚어 주고 고친 안을 줘.
(여기에 내가 쓴 프롬프트 붙여넣기)
```

### 실습 2. 질문 먼저 받기

```text
practice 폴더에 할 일 관리 CLI 프로그램을 만들고 싶어. 만들기 전에 결정이 필요한 것들을 질문으로 먼저 물어봐 줘.
```

답을 주고, Claude가 질문을 반영해 계획을 세우는지 봅니다.

### 실습 3. 확인 방법을 준 요청

```text
practice 폴더에 두 수를 더하는 add 함수를 원하는 언어로 만들고, 테스트도 만들어 실행한 결과를 보여 줘.
테스트가 실패하면 통과할 때까지 고쳐.
```

## 확인 체크리스트

- 네 요소(목표, 맥락, 제약, 확인 방법)를 외워서 말할 수 있다.
- 모호한 요청 세 개를 구체적으로 고쳐 썼다.
- Claude에게 질문을 먼저 받는 방식으로 작업해 봤다.
- 테스트처럼 Claude가 직접 돌릴 확인 수단을 주고 결과를 받았다.
- `ultrathink`와 `/effort`의 쓰임을 안다.
