# 06. 개발 워크플로 — 새 기능, 버그 수정, 리뷰, 테스트

## 학습 목표

- 작업 종류(새 기능, 버그, 리뷰, 테스트)마다 맞는 진행 순서를 쓴다.
- 데스크톱 앱의 diff 보기와 브라우저 미리보기로 결과를 눈으로 확인한다.
- Claude가 스스로 검증하게 만드는 습관을 들인다.

## 설명

### 공통 흐름: 조사 → 계획 → 구현 → 확인

1. **조사**: 관련 코드를 먼저 읽게 합니다. "아직 고치지 마"를 붙입니다.
2. **계획**: 큰 작업은 계획 모드(05단계).
3. **구현**: 작은 단위로. 단계마다 테스트를 돌리게 합니다.
4. **확인**: 테스트, 린트, 화면 확인. 내가 diff를 읽고 승인합니다.

### 작업 종류별 요령

| 작업 | 요령 | 프롬프트 뼈대 |
|---|---|---|
| 새 기능 | 테스트를 먼저 쓰게 하면(TDD) 범위가 분명해짐 | "먼저 실패하는 테스트를 쓰고, 그다음 구현해 통과시켜" |
| 버그 수정 | 재현부터. 오류 메시지·로그를 그대로 붙여넣기 | "이 오류를 재현하는 테스트를 먼저 만들고 원인을 찾아 고쳐" |
| 코드 리뷰 | 관점을 정해 주기(정확성, 보안, 성능) | "이 diff를 정확성과 보안 관점에서 리뷰해. 심각한 것부터" |
| 테스트 보강 | 경계값·실패 경로를 콕 집기 | "빈 입력, 아주 큰 입력, 네트워크 실패 경우의 테스트를 추가해" |
| 낯선 코드 파악 | 질문으로 시작 | "이 저장소의 구조와 요청이 처리되는 흐름을 설명해 줘" |

### 리뷰 도구

- `/security-review`: 현재 변경 사항의 보안 문제를 점검합니다.
- 일반 리뷰는 위 프롬프트처럼 직접 요청하거나, GitHub에서 `@claude`를 부릅니다(07, 12단계).

### 데스크톱 앱에서 결과 확인

- **diff 보기**: Changes 카드의 줄 수(`+12 -1`)나 제목 줄의 Changes를 누릅니다. 줄에 의견을 달아 `Ctrl+Enter`로 보내면 Claude가 반영합니다.
- **브라우저 미리보기**: `Ctrl+Shift+B`로 브라우저 창을 엽니다. 개발 서버 설정은 `.claude/launch.json`에 둡니다. 변경 뒤 자동 확인(Auto-verify)이 기본으로 켜져 있습니다.

## 실습 과제

할 일 API 프로젝트(04단계)에서 진행합니다. 웹 화면이 있는 내 프로젝트가 있다면 그것도 좋습니다.

### 실습 1. 낯선 코드 파악

```text
이 프로젝트 구조를 설명하고, GET /todos 요청이 들어와서 응답이 나갈 때까지 거치는 파일을 순서대로 알려 줘.
```

### 실습 2. 새 기능(TDD)

```text
할 일에 우선순위(priority: low|medium|high)를 추가하려고 해.
먼저 실패하는 테스트를 작성해서 실패하는 걸 보여 주고, 그다음 구현해서 통과시켜 줘.
잘못된 우선순위 값은 400을 돌려줘야 해.
```

### 실습 3. 버그 수정

일부러 버그를 심습니다.

```text
할 일 목록을 반환하는 코드에 정렬 버그를 하나 몰래 넣어 줘. 어디에 넣었는지는 말하지 마.
```

`/clear`로 새로 시작한 뒤:

```text
GET /todos 결과 순서가 이상해. 원인을 찾아서, 재현 테스트부터 만들고 고쳐 줘.
```

### 실습 4. 리뷰

```text
지금까지 바뀐 내용을 정확성, 보안, 테스트 누락 관점에서 리뷰해 줘. 심각한 것부터, 파일:줄 형식으로.
```

```text
/security-review
```

### 실습 5. 화면 확인(데스크톱 앱, 웹 프로젝트가 있을 때)

```text
개발 서버를 띄울 수 있게 .claude/launch.json을 만들고, 미리보기에서 메인 페이지가 뜨는지 확인해 줘.
```

## 확인 체크리스트

- 조사 → 계획 → 구현 → 확인 순서로 기능을 하나 만들었다.
- 실패하는 테스트를 먼저 보고 구현해 통과시켰다.
- 버그를 재현 테스트로 잡고 고쳤다.
- 관점을 지정한 리뷰와 `/security-review`를 돌려 봤다.
- diff에 의견을 달아 Claude에게 반영시켰다(데스크톱 앱).
- (선택) 브라우저 미리보기로 화면을 확인했다.
