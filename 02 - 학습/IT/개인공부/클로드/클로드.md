# 개발자를 위한 Claude 활용 학습지

Claude 데스크톱 앱(Code 탭)과 터미널용 Claude Code CLI를 함께 익히는 단계별 학습지입니다. 웹·앱 개발과 보고서·문서 작업을 모두 다룹니다.

- 대상: Windows에서 개발하는 사람
- 형식: 단계마다 **학습 목표 → 설명 → 실습 과제 → 확인 체크리스트**
- 사실 확인: 명령과 기능 이름은 2026-11-12에 공식 문서(code.claude.com/docs, support.claude.com)로 확인했습니다. Claude Code는 자주 바뀌니, 각 문서 맨 아래 출처 링크로 최신 내용을 다시 보세요.

## 준비물

- Pro, Max, Ultra, Team, Enterprise 구독 또는 Console(API) 계정(무료 플랜은 Claude Code를 쓸 수 없음)
- Windows 10 1809 이상, Git for Windows(권장), Node.js(실습용 예제 프로젝트에 씀)
- 실습 폴더: 볼트 밖 `C:\work\study\ai\클로드\practice`를 씁니다(node_modules 같은 실습 파일이 볼트에 섞이지 않게).

## 한 장 요약(자주 쓰는 것)

| 하고 싶은 일 | CLI | 데스크톱 앱 |
|---|---|---|
| 시작 | `claude` | Code 탭 > 폴더 선택 |
| 이어서 하기 | `claude -c`, `claude --resume` | 왼쪽 세션 목록 |
| 멈추기 / 되돌리기 | `Esc` / `Esc Esc`, `/rewind` | 정지 버튼 / `/rewind` |
| 권한 모드 바꾸기 | `Shift+Tab` | 모드 선택기 |
| 계획부터 | `/plan 설명` | 모드 선택기에서 Plan |
| 컨텍스트 정리 | `/clear`, `/compact` | 같음 |
| 사용량 | `/usage` | 같음 |
| 변경 확인 | `!git diff` | Changes 카드 |
