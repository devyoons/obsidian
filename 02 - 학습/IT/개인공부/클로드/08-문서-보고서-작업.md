# 08. 문서·보고서 작업 — docx, pptx, xlsx, pdf, 정리·요약

## 학습 목표

- Claude Code에 문서 스킬을 설치해 Word, PowerPoint, Excel, PDF 파일을 만들고 고친다.
- 채팅(claude.ai)의 파일 만들기 기능과 Claude Code 방식의 차이를 안다.
- 여러 자료를 모아 요약·정리하는 프롬프트를 쓴다.

## 설명

### 두 가지 길

| | claude.ai 채팅(파일 만들기 + 스킬) | Claude Code + 문서 스킬 |
|---|---|---|
| 준비 | 설정 > Capabilities에서 코드 실행·파일 만들기를 켜고, Customize > Skills에서 스킬 확인 | `anthropics/skills` 마켓플레이스에서 `document-skills` 플러그인 설치 |
| 파일 위치 | 채팅에 올리고 내려받음 | 내 폴더에 바로 저장 |
| 좋은 경우 | 한두 개 빠르게 | 폴더 안 자료 여러 개를 읽어 반복 생성, 스크립트화 |

- 도움말 문서는 이 기능을 claude.ai, Cowork, Claude Code에서 쓸 수 있다고 적고 있습니다. 데스크톱 앱 채팅에서의 지원 여부는 문서에 따로 없으니 직접 확인하세요.
- Team·Enterprise는 조직 관리자가 조직 설정 > Plugins & skills에서 허용해야 할 수 있습니다.

### Claude Code에 문서 스킬 설치

세션 안에서:

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```

`/plugin install`은 바로 설치하지 않고 범위(user, project, local)를 고르는 창을 엽니다. 저장소에는 docx, pptx, xlsx, pdf 스킬이 들어 있습니다(Apache 2.0). 저장소 README는 이 스킬들을 시연·교육용이라고 밝히고 있으니, 중요한 문서는 결과를 꼭 열어 확인하세요.

### 정리·요약 프롬프트 요령

- **독자와 목적**을 먼저: "팀장에게 보고할 1쪽 요약"
- **형식** 지정: 목차, 표, 글자 수, 슬라이드 장수
- **원본 근거** 요구: "숫자마다 어느 파일 몇 쪽에서 왔는지 표시해"
- **두 번에 나누기**: 먼저 개요를 받고 승인한 뒤 본문을 씁니다.

## 실습 과제

`practice\docs` 폴더를 만들고 자료 두세 개(회의록 텍스트, 엑셀, PDF 등)를 넣습니다. 없으면 만들어 달라고 합니다.

```text
practice\docs에 가상의 "3분기 웹 서비스 운영 현황" 자료를 만들어 줘: 월별 방문자·오류 건수 xlsx 하나, 회의록 md 하나.
```

### 실습 1. 요약

```text
practice\docs의 자료를 모두 읽고, 팀장 보고용으로 "3분기 운영 요약"을 1쪽 분량으로 정리해 줘.
결론 3줄 → 주요 수치 표 → 문제와 다음 할 일 순서로. 숫자마다 출처 파일을 괄호로 달아.
```

### 실습 2. Word 보고서

```text
위 요약을 report-q3.docx로 만들어 줘. 제목, 목차, 표 포함. 글꼴은 맑은 고딕.
```

### 실습 3. PowerPoint

```text
같은 내용으로 발표용 5장짜리 report-q3.pptx를 만들어 줘. 한 장에 메시지 하나, 수치는 차트로.
```

### 실습 4. Excel

```text
방문자·오류 xlsx에 월별 오류율(오류/방문자) 열과 합계 행을 수식으로 추가하고, 오류율이 1%를 넘는 달은 빨간색으로 표시해 줘.
```

### 실습 5. PDF

```text
report-q3.docx를 PDF로 바꾸고, 그 PDF에서 표만 뽑아 table.csv로 저장해 줘.
```

### 실습 6. 채팅 방식과 비교(선택)

claude.ai에서 같은 xlsx를 올리고 실습 4를 시켜 봅니다. 결과 품질과 편의성을 비교해 한 줄로 적습니다.

## 확인 체크리스트

- [ ] `document-skills` 플러그인을 설치했다.
- [ ] 여러 파일을 읽어 출처가 달린 요약을 받았다.
- [ ] docx, pptx, xlsx, pdf를 각각 하나 이상 만들거나 고쳤다.
- [ ] 결과 파일을 직접 열어 깨진 곳이 없는지 확인했다.
- [ ] 채팅 방식과 Claude Code 방식 중 언제 무엇을 쓸지 안다.
