# 11. 컨텍스트 관리와 비용 아끼기

## 학습 목표

- 컨텍스트 창이 무엇이고 왜 차면 품질이 떨어지는지 안다.
- `/clear`, `/compact`, `/context`로 컨텍스트를 관리한다.
- 모델·생각 깊이·작업 방식을 조절해 사용량을 줄인다.

## 설명

### 컨텍스트 창

Claude가 한 번에 기억하는 대화·파일 내용의 양입니다. 차오를수록 앞의 내용을 놓치기 쉽고, 매 차례 처리할 양이 늘어 사용량도 늡니다. 한계에 가까워지면 **자동 압축(auto-compact)**이 대화를 요약합니다.

### 관리 도구

| 도구 | 쓰는 때 |
|---|---|
| `/clear` | 관련 없는 새 작업을 시작할 때. 가장 확실한 절약 |
| `/compact 지시` | 같은 작업을 이어 가지만 기록이 길 때. 예: `/compact API 변경 내용과 남은 할 일 위주로` |
| `/context` | 무엇이 컨텍스트를 차지하는지 볼 때 |
| 서브에이전트 | 큰 탐색·조사를 본 대화 밖에서 할 때(10단계) |
| CLAUDE.md 다이어트 | 매 세션 읽히므로 짧게(200줄 이하) |

CLAUDE.md에 "Compact instructions" 섹션을 두면 압축 때 무엇을 남길지 정할 수 있습니다.

### 사용량 보기

- `/usage`: 세션 비용, 플랜 한도, 항목별 내역, 캐시 통계(`/cost`는 별칭). 구독자는 사용량 막대로, API 사용자는 비용으로 봅니다.

### 비용을 아끼는 습관

1. **작업마다 `/clear`**: 지난 작업 기록을 계속 끌고 다니지 않기.
2. **모델 고르기**(`/model`): 쉬운 일은 `sonnet`이나 `haiku`, 어려운 설계는 `opus`. `opusplan`은 계획만 Opus, 실행은 Sonnet.
3. **생각 깊이 조절**(`/effort`): 단순 작업엔 `low`나 `medium`.
4. **구체적인 프롬프트**: 파일 경로를 짚어 주면 Claude가 헤매며 읽는 양이 줄어듭니다(03단계).
5. **서브에이전트에 싼 모델**: 탐색용 에이전트 앞머리에 `model: haiku`.
6. **프롬프트 캐싱**: 같은 CLAUDE.md·파일을 반복해 쓰면 자동 캐싱의 덕을 봅니다. 세션을 잘게 쪼개 자주 새로 열기보다, 한 작업은 한 세션에서 이어 가는 편이 캐시에 유리합니다.

## 실습 과제

### 실습 1. 컨텍스트 들여다보기

긴 작업을 하던 세션에서:

```text
/context
```

가장 많이 차지하는 항목이 무엇인지 적습니다.

### 실습 2. 압축과 비우기

```text
/compact 지금까지 정한 설계 결정과 남은 할 일만 남겨
```

다시 `/context`로 줄어든 양을 봅니다. 이어서 관련 없는 질문을 하기 전에:

```text
/clear
```

### 실습 3. 모델·생각 깊이 비교

같은 간단한 요청을 두 설정으로 해 봅니다.

```text
/model
```

```text
/effort low
```

```text
practice 폴더의 md 파일 목록과 각 파일 첫 줄을 표로 보여 줘.
```

`/usage`로 차이를 확인하고, 어떤 설정으로도 충분했는지 적습니다.

### 실습 4. 내 절약 규칙 만들기

```text
~/.claude/CLAUDE.md를 열어 지금 몇 줄인지 알려 주고, 매 세션 읽힐 필요가 없는 내용을 골라 줘.
```

골라진 내용은 스킬이나 별도 문서로 옮깁니다.

## 확인 체크리스트

- `/context`로 컨텍스트 사용 내역을 읽을 수 있다.
- `/clear`와 `/compact`를 언제 쓰는지 구분한다.
- `/usage`로 사용량을 확인했다.
- 모델·effort를 바꿔 같은 작업을 비교했다.
- 비용 아끼는 습관 여섯 가지 중 세 가지 이상을 실제로 쓰고 있다.
