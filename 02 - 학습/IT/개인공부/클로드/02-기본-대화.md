# 02. 기본 대화 — 세션 다루기와 단축키

## 학습 목표

- 세션을 열고, 끊고, 이어서 하고, 되돌릴 수 있다.
- `@` 파일 참조, `!` 셸 모드, 이미지 붙여넣기를 쓸 수 있다.
- CLI의 주요 실행 방식(`claude`, `claude "질문"`, `claude -p`, `-c`, `-r`)을 구분한다.

## 설명

### 세션이란

한 대화가 하나의 세션입니다. 세션마다 작업 폴더와 대화 기록이 따로 있습니다. 데스크톱 앱에서는 왼쪽 목록에 세션이 쌓이고, 여러 세션을 동시에 돌릴 수 있습니다.

### CLI 실행 방식

| 명령 | 하는 일 |
|---|---|
| `claude` | 대화형 세션 시작 |
| `claude "질문"` | 첫 프롬프트를 넣고 세션 시작 |
| `claude -p "질문"` | 답만 출력하고 끝냄(비대화형, 스크립트용) |
| `cat 파일 \| claude -p "질문"` | 파이프로 입력을 넘김 |
| `claude -c` | 이 폴더의 가장 최근 대화를 이어서 |
| `claude -r "이름 또는 ID" "질문"` | 특정 세션을 골라 이어서 |
| `claude --resume` | 세션 고르는 목록을 띄움(세션 안에서는 `/resume`) |
| `claude -n 이름` | 세션에 이름을 붙여 시작 |

### 꼭 외울 키

| 키 | 동작 |
|---|---|
| `Esc` | 지금 하는 일을 멈춤(방향을 바로잡을 때) |
| `Esc` `Esc` | 입력창이 비어 있으면 되돌리기(rewind) 메뉴, 글이 있으면 입력 지움 |
| `Ctrl+C` | 실행 중인 작업 중단. 아무것도 안 돌 때 두 번 누르면 종료 |
| `Shift+Tab` | 권한 모드 바꾸기(05단계) |
| `Shift+Enter` / `Ctrl+J` | 줄바꿈(Windows Terminal은 Shift+Enter 가능, Ctrl+J는 어디서나) |
| `Alt+V` | 이미지 붙여넣기(Windows·WSL) |
| `Alt+T` | 확장 사고(thinking) 켜고 끄기(Windows) |
| `@` | 파일 경로 자동 완성. 파일을 대화에 붙임 |
| `!` (맨 앞) | 셸 모드. 명령 결과가 대화에 들어감 |

데스크톱 앱에서는 입력창 옆 메뉴와 버튼으로 같은 일을 합니다.

## 실습 과제

`practice` 폴더에서 진행합니다.

### 실습 1. 파일 참조와 셸 모드

```text
@hello.md 내용을 영어로 번역해서 hello.en.md로 저장해 줘.
```

이어서 셸 모드로 결과를 직접 확인합니다(맨 앞 `!`).

```text
!dir
```

### 실습 2. 중간에 멈추고 방향 바꾸기

```text
1부터 100까지 각 숫자를 설명하는 numbers.md를 만들어 줘.
```

쓰기 시작하면 `Esc`로 멈춘 뒤 다시 지시합니다.

```text
아니, 1부터 10까지만, 표 형식으로.
```

### 실습 3. 되돌리기

입력창이 빈 상태에서 `Esc`를 두 번 눌러 되돌리기 메뉴를 열고, numbers.md를 만들기 전 시점으로 돌아갑니다. `/rewind`를 입력해도 됩니다.

### 실습 4. 이어서 하기

세션을 끝내고(`Ctrl+C` 두 번) 다시 이어 봅니다.

```powershell
claude -c
```

```text
방금 무슨 작업을 했는지 한 줄로 요약해 줘.
```

### 실습 5. 비대화형 실행

```powershell
claude -p "hello.md 파일 내용을 한 문장으로 요약해"
```

## 확인 체크리스트

- [ ] `@`로 파일을 붙여 질문했다.
- [ ] `!`로 셸 명령 결과를 대화에 넣었다.
- [ ] `Esc`로 작업을 멈추고 새로 지시했다.
- [ ] 되돌리기(`Esc Esc` 또는 `/rewind`)로 이전 시점에 돌아갔다.
- [ ] `claude -c`로 지난 대화를 이어 갔다.
- [ ] `claude -p`로 답만 받아 봤다.
