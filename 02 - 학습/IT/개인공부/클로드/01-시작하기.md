# 01. 시작하기 — 설치와 로그인

> 이 문서의 명령과 경로는 2026-11-12에 공식 문서로 확인했습니다. 버전이 바뀌면 달라질 수 있으니, 막히면 맨 아래 출처부터 다시 보세요.

## 학습 목표

- Windows에 **Claude 데스크톱 앱**을 설치하고 **Code 탭**에서 첫 세션을 연다.
- 터미널용 **Claude Code CLI**를 설치하고 로그인한다.
- 두 방식의 차이를 알고 상황에 맞게 고른다.

## 설명

### 두 가지 사용 방식

| 구분 | 데스크톱 앱(Code 탭) | Claude Code CLI |
|---|---|---|
| 형태 | 창으로 쓰는 앱 | 터미널에서 `claude` 명령 |
| 강점 | 변경 사항(diff) 보기, 브라우저 미리보기, 여러 세션 나란히 띄우기, 클라우드 세션 | 스크립트·자동화(`claude -p`), 어떤 터미널·IDE에서나 사용 |
| 실행 환경 | Local, Cloud, SSH, WSL | 내 PC(또는 WSL) |
| 추천 | 처음 시작, 화면으로 결과 확인 | 반복 작업, CI, 터미널이 편한 사람 |

둘은 같은 엔진을 씁니다. CLAUDE.md, 스킬, 설정 파일(`~/.claude/…`)도 함께 씁니다.

### 쓸 수 있는 계정

- Pro, Max, Ultra, Team, Enterprise 구독이나 Console(API) 계정이 필요합니다.
- **무료(Free) claude.ai 플랜으로는 Claude Code를 쓸 수 없습니다.**

### Windows 요구 사항

- Windows 10 1809 이상 또는 Windows Server 2019 이상.
- **Git for Windows**는 필수는 아니지만 권장합니다. Git이 있으면 Claude가 Bash 도구를 쓰고, 없으면 PowerShell 도구를 씁니다. Git Bash를 못 찾으면 settings.json의 `env`에 `CLAUDE_CODE_GIT_BASH_PATH`를 넣습니다.
- WSL(WSL 2 권장)에서도 쓸 수 있습니다. 이때는 WSL 안에서 Linux 설치 방법을 씁니다.

## 실습 과제

### 실습 1. 데스크톱 앱 설치

1. https://claude.com/download 에서 Windows용 설치 파일을 받습니다. x64와 ARM64 중 내 PC에 맞는 쪽을 고릅니다.
2. 설치한 뒤 로그인합니다.
3. 위쪽 탭에서 **Code**를 누릅니다.
4. 연습용 폴더를 하나 만들어 고릅니다. 예: `C:\work\study\ai\클로드\practice`
5. 첫 프롬프트를 입력합니다.

```text
이 폴더에 무엇이 있는지 알려 주고, hello.md 파일을 만들어 "안녕, Claude"라고 적어 줘.
```

6. 파일을 고치기 전에 허락을 묻는 창이 뜨면 내용을 확인하고 허용합니다.
7. **Changes** 카드의 줄 수(예: `+1 -0`)를 눌러 변경 내용(diff)을 봅니다.

### 실습 2. CLI 설치(셋 중 하나)

PowerShell(권장, 자동 업데이트):

```powershell
irm https://claude.ai/install.ps1 | iex
```

CMD:

```bat
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

WinGet(자동 업데이트 없음, `winget upgrade Anthropic.ClaudeCode`로 올림):

```powershell
winget install Anthropic.ClaudeCode
```

> npm 설치(`npm install -g @anthropic-ai/claude-code`)도 아직 지원하지만 Node.js 22 이상이 필요합니다. 특별한 이유가 없으면 위의 네이티브 설치를 쓰세요.

### 실습 3. 설치 확인과 로그인

새 터미널을 열고 차례로 실행합니다.

```powershell
claude --version
claude doctor
```

`claude doctor`는 세션을 열지 않고 설치 상태만 점검합니다. 이상이 없으면 로그인합니다.

```powershell
cd C:\work\study\ai\클로드\practice
claude
```

처음 실행하면 브라우저가 열리며 로그인을 요청합니다. 다른 계정으로 바꿀 때는 세션 안에서 `/login`을 입력합니다.

### 실습 4. 업데이트

```powershell
claude update
```

## 확인 체크리스트

- [ ] 데스크톱 앱의 Code 탭에서 폴더를 골라 파일을 하나 만들었다.
- [ ] Changes 카드에서 diff를 열어 봤다.
- [ ] `claude --version`이 버전 번호를 출력한다.
- [ ] `claude doctor`에 오류가 없다.
- [ ] 터미널에서 `claude`로 로그인한 뒤 프롬프트가 뜬다.
- [ ] 데스크톱 앱과 CLI 중 어떤 상황에 무엇을 쓸지 한 줄로 설명할 수 있다.
