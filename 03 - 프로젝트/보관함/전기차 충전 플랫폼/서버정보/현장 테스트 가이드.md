### 1️⃣ WSS 충전기 연동

#### 1. 관리자 웹에서 테스트할 충전기 등록

- 필요한 정보
    - 제조사, 모델명, 충전기 유형(ex. 급속100kW, 완속11kW), 커넥트 유형
    - Authorization Key
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/3d5fbb03_image.png]]
    

#### 2. 연결할 충전기 설정하기

1. 빨간박스 부분을 터치하여 설정에 들어갑니다.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/4c7d39c6_image.png]]
    

1. 설정에 들어갈 비밀번호를 누른다.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/c6f432b8_image.png]]
    
    현재 저희쪽 비밀번호는 “6956”이고 이 번호가 아니라면 이지차저측에 요청하셔야합니다.
    

1.  네트워크설정에서 첫번째 URL은 WS로 설정, 두번째는 WSS로 설정한다.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/9732e493_image.png]]
    
    기계마다 설정하는 방법이 다를것으로 판단되어 현장에서 확인 후 진행해주시면 될 것 같습니다.
    

1. 충전기 설정에서 아래 내용으로 설정합니다. 
    
    ![SID : 999996
    CID : 07](../../../../attachments/88327f80-b904-4842-9b76-a87e681cb55a/image.png)

#### 3. 충전기 부팅하기

- 충전기 오른쪽 옆면에 레버를 돌려 부팅해주세요.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/9fd3f1b1_image.png]]
    

- 부팅을 해주시면 제가 로그를 확인할 예정입니다.
    - 아래는 현재 ws에 해당하는 충전기 headers에 담긴 내용이며, wss는 여기에 
    `authorization` 값이 들어와야합니다.

```bash
rawMessage ====================================== SecurityBefore HandShake start
headers : [upgrade:"websocket", connection:"upgrade", 
x-real-ip:"112.218.73.204", x-forwarded-for:"112.218.73.204", 
host:"cp.any-ev.com", sec-websocket-protocol:"ocpp1.6",
sec-websocket-key:"MDIwMjMwMzI3MzkwMDAwMA==", sec-websocket-version:"13"]
```

### 2️⃣ 충전 테스트

1. 테스트 이전에 커넥터를 연결할 기계의 상태를 동일하게 맞춰주세요.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/1ef5bc13_image.png]]
    
    빨간색 표시를  `9B`로 맞춰주세요.
    
    ![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/98fa3094_image.png]]
    
2. 같이 보내드린 테스트 가이드 문서를 참고하여 진행합니다.
    1. `A-1 비회원`  첫번째 테스트 진행
    2. `A-2 일반회원` → `미구독 충전 진행` → `카드 결제`  두번째 테스트 진행
        - 테스트 서버이기 때문에 결제는 이루어지고 오후 11시 혹은 11시 30분에 카드결제 취소됩니다.
        - 충전소는 가이드와 동일하게 저희가 등록한 `이지차저_테스트충전소1` 에서 진행하도록합니다.

1. 카드 결제를 완료하고 나면 충전기에서 “커넥터를 연결해주세요” 라는 멘트가 나옵니다. 
이때 커넥터를 아래 이미지와 같이 연결해주세요. 
    
    ** 커넥터 연결 후 아래 빨간 스위치를 `6C`로 돌려주면 온풍기가 돌아가면서 충전기 시작되었다는 안내멘트가 나옵니다.
    

![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/5f6119fe_image.png]]

![[03 - 프로젝트/보관함/전기차 충전 플랫폼/서버정보/첨부/69f9cf09_image.png]]

- 충전시작후 대략 3분 30초 이후(MeterValue를 받기 위함)  `충전중지` 버튼을 누릅니다.
    - 회원 : 앱에서 충전중단
    - 비회원 : 충전기에서 충전중단

### 3️⃣ 커넥터 연결 지연시 결제취소 테스트

1. 위 충전테스트 로직과 동일하게 결제까지 진행한 후 커넥터를 연결하지 않습니다.
2. 1분 지연뒤 자동으로 결제취소가되며 충전 취소가 되었는지 확인합니다.
