# 업무: Redis CLI 접근

## 내용

---

최종 변경 : 2023.07.24

---

#### Redis CLI 접근 : 로컬

```bash
redis-cli
```

---

#### Redis CLI 접근 : 원격

```bash
redis-cli -h IP주소 -p 포트 -a 비밀번호
```

---

#### Redis CLI 접근시 database 설정

```bash
redis-cli -n 데이터베이스번호
```

n 옵션을 통해 데이터베이스번호 명시가능, 이때 db번호는 0번부터 시작
