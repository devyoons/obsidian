# 업무: 스냅샷

## 내용

---

최종 변경 : 2023.07.27

---

#### 레디스 스냅샷

인메모리에 저장된 레디스 서버 데이터를 영구저장하기 위한 작업으로 특정 시점 기준으로 변경된 내역들을 저장하게 된다. (시점 백업)

---

#### 스냅샷 설정

- redis conf 파일 접속
    
```bash
sudo vi /etc/redis/redis.conf
```


- save 파라미터 설정 : 스냅샷 주기
    
```bash
save 초단위시간 KEY변경수
```


특정 초 시간 동안 설정한 수 만큼 KEY 변경이 발생하면 스냅샷

![[03 - 프로젝트/보관함/전기차 충전 플랫폼/업무문서/EV 개발환경·Redis·OCPP 메모/레디스/첨부/c365ad40_1.png]]

- 스냅샷 실패시 레디스 쓰기 요청 거부 설정
    
```bash
stop-wrotes-on-bgsave-error yes
```


- 스냅샷 압축 여부
    
```bash
rdbcompression yes
```


- rdb 파일 마지막에 CRC64 checksum 기록 여부 (순환 중복 검사)
    
```bash
rdbchecksum yes
```


- 스냅샷 파일명 설정
    
```bash
dbfilename dump.rdb
```


- 스냅샷 파일 사용 후 제거 여부
    
```bash
rdb-del-sync-files no
```


- 스냅샷 저장 위치
    
```bash
dir /var/lib/redis
```
