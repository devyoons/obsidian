#### Redis

레디스는 “key” - “value” 구조의 비정형 데이터를 저장하는 오픈 소스 DBMS이다. 캐시 저장소로 많이 사용되며 인메모리 구조를 사용하기 때문에 레디스 서버를 재시작하면 모든 데이터가 소멸된다.
