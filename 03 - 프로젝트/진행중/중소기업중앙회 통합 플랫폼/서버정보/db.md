# 서버: db

## 내용

파일경로: 사업단 내부 DB공유

모델변경내용
- 개발하다가 변경된 내용을 해당 문서에 올릴 예정
모델변경요청
- 변경이 필요한 부분은 양식에 맞춰 작성해서 이름_날짜 파일명으로 전달하면 수정해주심

엑셀 테이플 매핑 정의서 -> 테이블 정의서 -> 공통코드 id

- 시퀀스, 코드id

달력
- 현재는 휴일만 들어가있음

파일
- 파일원천유형코드
- 첨부파일참조ID

제휴사
- 제휴사에서 제공해주는 api 정보
- 시스템 연계 제휴사 기본,상세 테이블 확인

공통_관리자업무기본
- 관리자 업무처리한다면, 해당 담당자에게 알림을 주기 위한 테이블임
- 보완이 될 예정이며 이해만 하고 넘어가도됨

통합회원기본
- 노란회원가입여부 : 기간계에서 바로 호출해서 확인하는걸로 사용할것같음
- 로그인 안한 사람들 X,

회원탈퇴
- 회원 탈퇴회원기본 : 개인정보 일정기간 지나면 삭제해야할텐데 해당 부분 이력으로 쌓을 테이블이 필요하지않은가?
- 업무에서 협의 필요

게시판
- 조회수 카운트 어떻게 할건지
- 현재는 클릭수와 조회로그 카운트로 두가지 방법으로 되어있음
- 조회로그를 카운트하는걸로 결정됨

객실
- 제휴사 -> 보유객실 -> 일괄등록 -> 객실기본 으로 처리됨

sql 작성 기준

- 문서 참고하면될듯
