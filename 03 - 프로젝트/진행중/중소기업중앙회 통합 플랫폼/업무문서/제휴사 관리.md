# 업무: 제휴사 관리

## 내용

---

---

#### 제휴사 관리 메뉴 구조도

1. 제휴업체 입점 관리 (최윤서)
    - 입점 신청
        - 입점 신청 목록
        - 입점 신청 상세 (조회, 수정[상태변경포함])
        - 입점 신청 등록
    - 제휴 계정 관리
        - 제휴 계정 목록
        - 제휴 계정 상세 (조회, 수정)
        - 제휴 계정 등록
2. 제휴업체 정보 관리 (최윤서)
    - 제휴업체 관리
        - 제휴업체 목록
        - 제휴업체 상세 (조회,수정)
    - 제휴시설 관리
        - 제휴시설 목록
        - 제휴시설 상세 (조회, 수정)
        - 제휴시설 등록
    - 객실 유형 관리
        - 객실 유형 목록 (일괄 엑셀 다운로드[팝업])
        - 객실 유형 상세 (조회, 수정)
        - 객실 유형 등록
    - 제휴업체 문의내역
        - 제휴업체 문의내역 목록
        - 제휴업체 문의내역 상세 (답변상태에 따른 조회, 수정)
3. 제휴업체 콘텐츠 관리 (최윤서)
    - 제휴사 등록 콘텐츠 검수 목록
    - 제휴사 등록 콘텐츠 검수 상세 (조회, 수정)
4. 제휴업체 실적 관리 (정우진)
    - 제휴업체 연계 실적 자료
        - 제휴업체 연계 실적 자료 목록
    - 제휴업체 실적
        - 제휴업체 실적 목록
        - 제휴업체 실적 상셰 (조회화면 예시 없음. 확인필요)
        - 제휴업체 실적 등록
        - 제휴업체 실적 엑셀 업로드
    - 실적관리 대상항목
        - 제휴업체 실적 대상 항목 목록
        - 제휴업체 실적 대상항목 상세 (조회, 수정)
        - 제휴업체 실적 대상항목 등록
    - 평가기준 설정 (제휴사 평가관리)
        - 제휴업체 평가기준 목록
        - 제휴업체 평가기준 상세 (조회, 수정[레이어팝업])
        - 제휴업체 평가기준 등록
    - 평가결과 (제휴사 평가관리)
        - 제휴업체 평가결과 목록
    - 제휴사 시설 예약 현황
        - 제휴사 시설 예약 현황 목록
    - 제휴사 월별 이용 통계
    - 제휴사 할인쿠폰 사용량
    - 제휴사 이벤트 참여자 수
    - 제휴 실적 통계
5. 제휴업체 활동 로그
    - 제휴업체 로그인 이력 목록
        - 제휴업체 로그인 이력 상세
    - 제휴업체 이용 로그 목록 (엑셀 다운로드)

#### 제휴업체 입점 관리 & 제휴 계정 관리

| **단계** | **주요 활동** | **비고** |
| --- | --- | --- |
| **신청** | 사업자 번호 검증 → 업체/담당자 정보 등록 | 제휴업체 포탈 |
| **심사** | 목록 조회 → 서류/정보 검토 → 승인/반려 결정 | 서비스실 |
| **등록** | DB 저장 → 외부 API 연계 호출 | 업무 시스템 |
| **완료** | 알림톡(Kakao) 발송 | 업체 통보 |

| **구분** | **주요 액티비티** | **관련 시스템/부서** | **비고** |
| --- | --- | --- | --- |
| **계정 관리** | ID 검증 → 정보 등록 → 승인 요청 → API 연계 | 포탈, 서비스실, 중앙회 | 알림톡 발송 포함 |
| **정보 수정** | 대상 조회 → 정보 변경 확인 → DB 수정 → API 연계 | 포탈, 서비스실, 중앙회 | 수정/삭제 API 연계 |
