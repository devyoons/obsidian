    - 첫출근일자 추가 필요
    - 승인할때도 첫출근일자를 지정하도록 해야할 것 같음 - 모바일

    - 위험성평가 또한 동일하게
    - 웹한글기안기에 적용할 수 있게

    - 뷰어만 HTML로 변환한다는거고 웹한글기안기는 살려둠
    - 서버부하가 많은 것 같아서 패스됌

    - 시스템 공지
        - 관리자 대시보드 생기면 그때 진행
    - 사업장 공지 → 안전 수칙, 지켜야할 거 → 주체는 현장관리자가 뿌리는거고 오늘의 브리핑
        - 현장관리자들이 보내는거
        - 작업일보 파일을 올리면 해당 내용을 분석해서 핵심 키워드로 조심해야할거 5줄~10줄 요약
            - 우리가 올려줄 수 있음
            - ai 로 만듬
    - 전체 사업장 중대재해 알림
        - 공종구분
        - 중대재해알림
        - 구분 : 중대재해알림, 오늘의 한줄 안전공지(작업일보 보고 ai 요약해서 진행)
            - 사람이 올리는 것
            - 발송주체는 우리.
            - 범위체크 필요해보임
    - 위 공지를 다시 볼 수 있는 메뉴가 필요함
        - 리스트만 보이게 하기 위함
- 안전챗
    - 이미지 → 파일서버에 있음
    - 정책 필요함 → 어느 시점이 지나면 톡이 사라지게될건지 논의 필요

- 메뉴개편
    - 안전교육 참석
        - 금일 교육이 없는 경우에는 작업중지 조치에 대상없음과 동일하게 비활성화 표시
        - 금일 교육이 있는 경우에는 교육한 인원만 카운팅
    - 출근 총 빼기, TBM참석, 개인점검은 출근한 total을 사용한다.
    - 금일 미활동 내역
        - 사실상 현재 보여져야할게 없음
        - 정확한 내용을 보고 싶으면 작업일보를 올려주세요. 라는 문구가 있고
            - 파일을 넣어서 제대로된 데이터를 볼 수 있도록 포인트 쓰게 유도
    - 안전문서사용설정
