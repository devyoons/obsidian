# 11 용어 정리

| 용어                | 뜻                     | 2.0에서 비슷한 것                |
| ----------------- | --------------------- | -------------------------- |
| SPA               | HTML 하나, 화면 전환은 JS    | —                          |
| 컴포넌트              | 화면 조각 함수              | `th:fragment`              |
| JSX / `.tsx`      | JS 안의 HTML 문법         | Thymeleaf 템플릿              |
| props             | 부모가 넘기는 값             | fragment 파라미터              |
| state             | 화면이 기억하는 값, 바뀌면 다시 그림 | —                          |
| Hook (`use…`)     | 상태·동작을 쓰는 함수          | —                          |
| React Router      | 주소 → 화면 연결            | `@GetMapping` + view 이름    |
| TanStack Query    | 서버 데이터 조회·캐시·갱신       | Controller가 Model에 담기      |
| queryKey          | 캐시된 데이터 이름표           | —                          |
| invalidateQueries | 데이터 낡음 표시 → 재조회       | 페이지 다시 요청                  |
| Zustand           | 화면 공용 상태 저장소          | —                          |
| Node.js           | JS 실행기(개발 도구용)        | JDK                        |
| pnpm              | 라이브러리 관리              | Gradle                     |
| package.json      | 의존성·명령 목록             | `build.gradle`             |
| Vite              | 개발 서버 + 빌드            | Gradle `bootRun` · `build` |
| 프록시               | 같은 주소로 받아 API 서버로 전달  | —                          |
| CORS              | 다른 주소 호출을 막는 브라우저 규칙  | —                          |
| `dist/`           | 빌드 결과(정적 파일)          | `build/libs/*.jar`         |
| nginx             | 운영에서 정적 파일 + API 전달   | —                          |
| 웹뷰                | 앱 안의 브라우저             | 동일                         |
