# 02 서버가 왜 따로 뜨나

## 결론

- React 화면은 결국 정적 파일(HTML·JS·CSS)
	- 누군가 이 파일을 브라우저에 내려줘야 함
- 개발 중: Vite 개발 서버가 내려줌 (`pnpm dev`, 5173)
- 운영: nginx가 내려줌 (빌드된 `dist/`)
- 백엔드(Spring Boot)는 API만 담당
	- 그래서 "화면 서버"와 "API 서버"가 따로 뜸

## 개발 서버(Vite)가 하는 일

- `web/` 에서 `pnpm dev` → `vite` 실행
	- `package.json` 의 `"dev": "vite"`
- 주소: `http://localhost:5173`
	- `vite.config.ts` 의 `port: 5173`, `strictPort: true` (포트 고정)
- 하는 일
	- `.tsx`·`.ts` 를 브라우저가 읽는 JS로 바로 변환해서 줌
	- 파일 저장하면 화면이 즉시 바뀜 (새로고침 없이)
	- `/api` 요청을 백엔드로 전달 (프록시)

## 프록시: 왜 필요한가

- 브라우저 보안 규칙
	- 화면 주소(`localhost:5173`)와 다른 주소로 API를 부르면 막힘 (CORS)
	- 쿠키도 다른 주소로는 잘 안 붙음
- 해결
	- 화면은 같은 주소의 `/api/...` 를 부름
		- `.env.development` 의 `VITE_API_BASE_URL=/api`
	- Vite가 이 요청을 받아 백엔드로 대신 전달
	- 브라우저 입장에서는 같은 주소라 안 막힘

## 프록시 대상 (`vite.config.ts`, `.env.development`)

- 대상이 두 곳
	- `BACK_PROXY_TARGET=http://192.168.0.73:8107`
		- 새 API 서버 `back/`
		- 정해진 경로만 이쪽으로
			- 예: `/api/organization/(site|team|network)/`, `/api/incident/contact/`, `/api/session/(auth|role|...)/`, `/api/common/file/` 등
			- 전체 목록은 `vite.config.ts` 첫 번째 정규식
	- `API_PROXY_TARGET=https://dev.safetytalk.co.kr`
		- 기존 API `safety-back`
		- 위 경로에 안 걸린 나머지 `/api` 전부
- 즉, 화면 코드는 서버가 어디인지 모름
	- 경로만 보고 Vite가 나눠 보냄

## 실행 명령 읽기

```bash
VITE_API_MODE=live BACK_PROXY_TARGET=http://localhost:8080 pnpm dev
```

- `BACK_PROXY_TARGET=http://localhost:8080`
	- `back/` 경로를 내 PC에서 띄운 백엔드(8080)로 보냄
	- 나머지는 그대로 `dev.safetytalk.co.kr`
- `VITE_API_MODE=live`
	- 현재 `web/` 코드(`.ts`·`.tsx`·`.mjs`·`.env*`)에서 이 값을 읽는 곳 없음 (2026-11-09 확인)
	- 지금은 넣어도 동작 차이 없음

## 운영(배포)에서는

- `pnpm build` → `dist/` 폴더에 정적 파일 생성
- `Dockerfile`
	- 빌드 후 nginx 이미지에 `dist/` 복사
- `deploy/nginx.conf.template`
	- `/` : `dist/` 파일 응답, 없는 주소는 `index.html` (`try_files $uri /index.html`)
		- 주소 판단은 React Router가 함
	- `back/` 경로 → `BACK_UPSTREAM`
	- 나머지 `/api/` → `API_UPSTREAM` (safety-back)
	- `/connection/` → `SOCKET_UPSTREAM` (실시간 연결)
- 이미지 기본값 (dev)
	- `API_UPSTREAM=http://192.168.0.97:8089`
	- `BACK_UPSTREAM=http://192.168.0.73:8107`
	- `SOCKET_UPSTREAM=http://192.168.0.97:8090`
- 개발 때 Vite 프록시가 하던 일을 운영에서는 nginx가 함

## 그림으로

```
[개발]
브라우저 ─ localhost:5173 ─ Vite
                              ├─ 화면 파일(.tsx 변환)
                              ├─ /api/(back 경로) → back (BACK_PROXY_TARGET)
                              └─ /api/그 외       → safety-back (API_PROXY_TARGET)

[운영]
브라우저 ─ web 도메인 ─ nginx
                         ├─ 화면 파일(dist)
                         ├─ /api/(back 경로) → BACK_UPSTREAM
                         ├─ /api/그 외       → API_UPSTREAM
                         └─ /connection/     → SOCKET_UPSTREAM
```
