# 10 앱 웹뷰와 네이티브 브릿지

## 구조

- 앱(Android·iOS) 안의 웹뷰가 웹 화면을 띄움
	- 화면은 PC 웹과 같은 React 코드
- 앱만 할 수 있는 기능은 웹 → 앱으로 요청
	- 푸시 토큰, QR 스캔, 채팅 열기
- 저장소의 `mobile/` 에 `android`, `ios`, `rn` 폴더

## 프로젝트에서 보기: `src/shared/native/bridge.ts`

- 네이티브 기능은 이 파일로만 부름 (`AGENTS.md`)
- 앱인지 판단

```ts
export function nativePlatform(): NativePlatform | null {
  if (typeof window === 'undefined') return null
  if (window.AndroidInterface) return 'android'
  return window.webkit?.messageHandlers ? 'ios' : null
}
```

- Android: 앱이 `window.AndroidInterface` 를 넣어 줌
- iOS: `window.webkit.messageHandlers` 로 메시지 보냄
- 결과는 앱이 `window.fcmToken` · `window.qrScan` 함수를 호출해서 돌려줌
	- `waitForReply` 가 이 함수를 잠깐 걸어 두고 결과를 기다림

## 기능별 (`AGENTS.md`)

| 기능 | 앱 | 앱이 아닐 때 |
|---|---|---|
| 채팅 열기 | `openChatRoom` · `openChat` 로 RN 채팅 | 근로자 메시지 화면 |
| 푸시 토큰 | `getFcmToken` → `workforce/user/updatePushToken` 저장 | 저장 안 함 |
| QR 스캔 | `startQrScan` | 브라우저 카메라(`getUserMedia` + `jsqr`) |
