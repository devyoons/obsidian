# 09 화면 하나 따라가기 - 연결된 회사

- `AGENTS.md` 가 새 화면 기준으로 지정한 화면
	- `src/features/site/CompaniesPage.tsx`
	- `src/features/site/queries.ts`

## 전체 흐름

1. 주소 `/site/companies`
	- `router.tsx` 의 `/:group/:sub?` → `AdminLayout`
	- 그 전에 `RequireSession` 이 로그인 확인
2. 화면 고르기
	- `AdminLayout` 이 `SCREENS['companies']` → `CompaniesPage`
	- 제목 줄 단추는 `CompaniesActions` ("+ 회사 초대")
3. 현재 현장
	- `useCurrentSite()` → `site.id`
4. 조회
	- `useQuery(siteCompaniesQuery(siteId))`
	- `backPost('/organization/network/selectNetworkList', { schPobId: siteId })`
5. 호출 경로
	- 브라우저: `POST /api/organization/network/selectNetworkList`
	- 개발: Vite 프록시 → `BACK_PROXY_TARGET`
	- 운영: nginx → `BACK_UPSTREAM`
6. 백엔드
	- `back/.../organization/network/controller/PobNtwrRestController.java`
	- `@RequestMapping("/api/organization/network")` + `@PostMapping("/selectNetworkList")`
	- → `PobNtwrService` → `PobNtwrMapper`
7. 응답
	- `ApiResponse` 의 `data` → `toSiteNetwork` 로 화면용 변환
8. 그리기
	- 로딩 → `LoadingState`
	- 오류 → `Notice`
	- 0건 → `EmptyState` "연결된 회사가 없습니다."
	- 있으면 `CompanyNode` 를 재귀로 그림 (하위 회사 `children`)
9. 회사 누르면
	- `openDrawer(() => <CompanyDrawer … />)` 로 서랍 열림
	- 서랍 안 "다시 요청"·"연결 끊기" → `useMutation`
	- 성공하면 `invalidateQueries` 로 목록 재조회

## 2.0 방식으로 바꿔 보면

| 단계 | 2.0 | 2.5 |
|---|---|---|
| 주소 받기 | Controller `@GetMapping` | React Router |
| 로그인 확인 | 서버 필터 | `RequireSession` (+ 서버도 확인) |
| 데이터 조회 | Controller → Service → Mapper | 화면 `useQuery` → API → Service → Mapper |
| 화면 만들기 | Thymeleaf 템플릿 | `CompaniesPage` 컴포넌트 |
| 저장 후 갱신 | 페이지 다시 요청 | `invalidateQueries` 로 목록만 재조회 |

## 직접 해 보기

- `pnpm dev` 띄우고 `http://localhost:5173/site/companies`
- 브라우저 개발자도구(F12) → Network 탭
	- `selectNetworkList` 요청·응답 JSON 확인
- `CompaniesPage.tsx` 의 "연결된 회사가 없습니다." 문구 바꿔 보기
	- 저장하면 새로고침 없이 바로 반영
	- 확인 후 되돌리기
