### 기기설명

- 제트팬
    - 터널 안의 먼지나, 이산화탄소, 화재 시 연기를 빼낼 때 사용한다.
- 축류팬(1,2,3)
    - 장터널인 경우 축류팬이 들어갈수도있다 수직갱에 위치한다.
- 진입차단 설비(1,2)
    - 터널 안에 화재나 교통사고 시 터널 안으로 진입 할 수 없도록 차단막을 내려주는 설비 터널의 진행 방향 입구에 위치한다
- 피난연결통로 차단문
    - 터널 시점 방향과 종점 방향의 중간에 위치하는 통로이다.
- 수동소화기
    - 터널 안에 위치하는 수동 소화기이다. 소화기를 꺼내게 되면 포인트가 올라온다
- 부하개폐기(LBS)
    - 판넬 제일 초단에 위치하는 설비이다
- ATS
    - 한전에서 전기가 들어오는지 발전기에서 전기가 들어오는지 알려주는 설비다
- 누전경보기
    - 혹시 전기가 땅으로 누전 되지는 않는지 알려주는 설비이다
- 발전기 (GEN, GCP)
    - 발전기의 종류는 GEN, GCP가 있다.
- UPS
    - 한전에서도 전기가 안들어오고 발전기에서도 전기가 안들어오는 상황에 왔을때 UPS가 돌아가면서 전기를 공급해준다.
- 조명제어기
    - 조명이 고압등이나 나트륨등? 등으로 설치되어있다 전류소모가 많다
- 디밍제어기(부가장치)
    - LED등으로 전류소모가 적다 터널입구부분 디밍등은 밝고 터널안으로 들어갈수록 어두워진다 (C 맑음,CR 흐림,NE 상시,MN 일출,N 심야)
- VDS
    - 차량속도를 알려주는 설비
- LCS
    - 차선에대한 정보를 알려주는 설비
- VMS
    - 터널의 입구부분과 터널내에 설치 되어있는 설비이다. 도로교통전광판이다
- 환기운영
    - 터널내의 이산화탄소나 먼지등이 많을때 터널내의 공기를 깨끗하게 만들어주는 운영설비이다.
    - 환기운영을 자동으로 해놓으면 VICO가 이산화탄소값을 측정하여 이산화탄소값이 높으면 제트팬이 돌아가면서 이산화탄소값을 내려준다.
- 화재운영(1, 2)
    - 터널내에 화재시그널이 올라왔을때 화재운영을 돌리게되면 제트팬이 40초마다 1번씩 돌아간다 전속배연운전을 선택하면 제트팬이 무한정으로 돌아간다
- 환기, 전력 제어 권한 부여
    - 지사에서 제어를 할 것인지, 관리동에서 제어할것인지를 알려주고 제어할수있게 해준다.
- 계측기 운영(1, 2)
    - 임계풍속 상한, 하한값을 조정할수있고 단계별로 VI,CO,NO값을 조정할수있다. 임계풍속이 낮으면 제트팬이 돌아가고 임계풍속이 높으면 역방향으로 돌아가야하는데 안 돌아가는 것으로 알고있다.
- VDS 디밍제어
    - 외부밝기(디밍제어기값) * 교통속도/교통량(%) * 보수율 값으로 LED등의 밝기를 조절해주는 설비이다
- 화재돌발
    - 화재돌발 원클릭버튼을 누르게 되면 LCS VMS 고압,LED등 진입차단설비 JF 비상방송을 작동시켜준다

### DO, DI, AO, AI, AI32

- DO(Digital Output) – 제어를 담당하는 포인트들을 말한다 (1bit)
- DI(Digital Input) – 상태를 표현해주는 포인트들을 말한다 (1bit)
- AO(Analog Output) – 제어를 담당하는 포인트들을 말한다 정수를표현하기 위해 16bit를 사용한다
- AI(Analog Input) – 값을 읽기위한 포인트들을 말한다 정수를표현하기 위해 16bit를 사용한다
- AI32, AO32 – 실수를 표현하기 위해 32비트를 사용하는 포인트들이다 (32bit)

### 터널 계통도 JSP(HTML) 구조

- 📌**코드 복붙**
    
```
<!-- 본문 시작 -->
<div id="contentWrap">

    <!-- 상단 항목 시작 -->
    <div class="top-control clear">
        <div class="option-control02 clear mgLspace">

        </div>

        <!-- 터널 시작 -->
        <div class="tunnel-area">
            <div class="tunnel">

            </div>
        </div>
        <!-- 하단 항목 -->
        <div class="bottom-control clear">

        </div>
    </div>
</div>
```
