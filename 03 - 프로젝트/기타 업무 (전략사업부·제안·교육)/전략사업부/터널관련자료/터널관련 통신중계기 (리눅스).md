#### 📌 리눅스 주요 단축키

`tail` : 마지막 10줄을 출력

- -f : 실시간으로 조회 (Log 확인시 주로 사용)
- tail [옵션][파일명]
- tail filename.txt
- tail -f filename.txt
    - **f :** tail을 종료하지 않고 파일의 업데이트 내용을 실시간으로 계속 출력한다.
    - **n (라인 수) :** 파일의 마지막줄부터 지정한 라인수까지의 내용을 출력한다.
    - **c (바이트 수) :** 파일의 마지막부터 지정한 바이트만큼의 내용을 출력한다.
    - **q :** 파일의 헤더와 상단의 파일 이름을 출력하지 않고 내용만 출력한다.
    - **v :** 출력하기전에 파일의 헤더와 이름 먼저 출력한 후 파일의 내용을 출력한다.

`pwd(print working directory)` : 현재 디렉토리 경로 확인

`ll` : 폴더에 리스트 상세보기 (권한까지 보는 것 | 세로로 리스트 보여줌)

- `ls -l` → `ll`

`ls(list)` :  가로로 리스트 보여줌

- `ls -a` : all 숨겨진 파일까지 모두 보여줌

`cd(change directory)` :  디렉토리 이동

`ctrl+c` : 명령어 중단

`| (Pipe)` : 명령의 결과를 다음 명령의 입력으로 넘긴다.

`grep` : 파일에 포함된 특정 단어를 검색

- i : 대소문자 구분 안함
- n : 라인 번호 출력
- v : 검색어가 없는 Line 보여달라
- c : 라인의 개수 출력

`cat / more` : 텍스트 파일 출력 (짧은 내용 cat, 내용이 많으면 more)

#### 📌 리눅스 ps명령어

`ps` : 현재 실행중인 프로세스의 목록을 보는 명령어

- -e : 실행중인 모든 프로세스의 정보를 출력
- -f : 프로세스에 대한 자세한 정보를 출력 (PPID확인가능)
- -u [사용자이름] : 특정 사용자에 대한 모든 프로세스의 정보를 출력
- -p pid : pid로 지정한 프로세스의 정보를 출력
- u : 프로세스 소유자의 이름, CPU 사용량, 메모리 사용량 등 상세정보출력
- a : 터미널에서 실행한 프로세스의 정보를 출력
- x : 실행 중인 모든 프로세스의 정보를 출력

#### 🌱 터널중계기 미수용터널 반영시

---

<aside>
💡 WDT : 관리하는 프로세스
hitms : 터널중계서버 계정

</aside>

1. NGS 로그인 후 secureCRT 실행 → 작업할 지사선택
2.  DB 업데이트 (ver 0으로 변경해주는 작업)
    1. config 디렉토리로 이동
    2. 파일 리스트 확인해서 HOST.cnf 파일여부 확인 `ll` or `ls -al`
    3. `config HOST.cfg` → DB_VER : 0 으로 바꿔주기
        - `x` : 누르면 지우기
        - `shift` + `r` : 바꾸기
        - `i` : 끼워넣기
        - `q!` : 저장안하기
        - esc 커서 나가기
        - `wq` : 저장하기
3. 프로세스 kill 후 재실행 
    1. bin 디렉토리로 이동
    2. `ps -ef | grep hitms` : 프로세스 목록중 “hitms”확인
        
        <aside>
        💡 모든 프로세스 리스트 확인 : `ps -ef`
        특정 프로세스 정보 확인 : `ps -ef | grep 프로세스이름`
        
        </aside>
        
        - `ps -ef | grep hitms` : WDT 프로세스 확인하기 총5개
            - SCAN (지사번호)
            - EVENT (지사번호)
            - HOST (지사번호)
            - TTMS (지사번호)
            - WDT 15 debug
    3. `kill 프로세스번호` : 프로세스 죽이기
    : WDT 15(지사마다다름) debug 프로세스 번호를 죽이면 hitms관련 전부 kill
        - kill 후에 한번 더 확인해준다. → `ps -ef | grep hitms`
    4. `WDT 15(지사번호) debug` : 프로세스 다시 실행해주기 
        - 프로세스 재기동 후 한번 더 확인해준다. → `ps -ef | grep hitms`
    

#### ✔ 실시간 데이터보기

---

: PLC에서 데이터가 잘넘어오는지 확인하는 방법

- log 디렉토리로 이동
- 리스트 확인 후 해당 파일명 확인
- 실시간 데이터보기 → `tail -f logfile (오늘날짜.txt)`
    - 이때 `-f` 옵션은 실시간 데이터를 계속 출력해주는 옵션

#### ✔ 데이터가 안올라오면 확인하는 방법 : 중계기->PLC 방화벽 포트

---

1. **nc로 네트워크 통신 확인하는방법 : 해당 서버에 502포트가 뚫려있는지 확인**
    - `nc -v` : PLC IP PORT 확인하는 방법
        - `nc -v 000.00.000.000 502`
    - 이때 성공여부 확인! 실패시 “서버에서 해당 PLC방화벽이 안뚫려있다”는 것
        - 성공시 : **Connection** to 000.00.000.000 502 port [tcp/d-s-n] succeeded!
2. **육안으로 웹 지사관제화면에서 확인하는 방법**
PLC 색(빨간색), 
중계기(빨간색 동그라미 표기), 
통신서버(빨간색 동그라미) 등으로 구간별 확인
3. **[tb_network] 테이블에 통신상태를 확인할수있는 DB**
