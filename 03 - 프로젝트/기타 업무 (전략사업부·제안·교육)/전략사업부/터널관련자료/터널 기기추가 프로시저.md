        ```sql
        CREATE OR REPLACE PROCEDURE TER_MAIN."P_MAKE_MACHINE_DEVICE"
        (
            INPUT_TNCODE          IN VARCHAR2
           ,INPUT_MACHINECODE     IN VARCHAR2
        )
        IS
            MAXSEQ                NUMBER(10)    :=  0;
            V_MSG                 VARCHAR2(200) := '';
        
        CURSOR MY_CUR1 IS
                    SELECT COUNT(*) CNT
                      FROM T_AFMF_OPND_INSR01M1
                     WHERE 1=1

        END P_MAKE_MACHINE_POINTOPR;
        /
        ```
        
    - 데이터를 올라오게 하기 위한 프로시저
    - 마스터 테이블에서 조회해서 insert문을 만들어준다.
    - DI(Digital Input) : 상태를 표현해주는 포인트들을 말한다. (1bit)
        - POINT_STAT
    - AI (Analog Input) : 값을 읽기 위한 포인트들을 말한다. (정수를 표현하기 위해 16bit를 사용)
        - POINT_VALUE
    - DO (Digital Output) : 제어를 담당하는 포인트들을 말한다.
    - AO (Analog Input) : 값을 읽기 위한 포인트들을 말한다. (정수를 표현하기 위해 16bit를 사용)
