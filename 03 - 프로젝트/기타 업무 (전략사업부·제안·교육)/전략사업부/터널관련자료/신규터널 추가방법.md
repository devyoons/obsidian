| --- | --- |
| T_AFMF_TNRM_TUNL01P1 | 부대시설물_터널원격명세 테이블 |

### 1. T_AFMF_TNRM_TUNL01M1 [터널원격터널기본]작성, 수정해야 할 데이터

![[03 - 프로젝트/기타 업무 (전략사업부·제안·교육)/전략사업부/터널관련자료/첨부/2fb1a7be_Untitled.png]]

1. TUNL_CD = 터널코드 입니다.
    - 생성방식은 PBUS_JRSD_LCLSS_ID 와 PBUS_JRSD_MCLSS_ID 두가지와 순차적인 일련번호생성으로 만들어집니다.
    - PBUS_JRSD_LCLSS_ID 의 00000 숫자의 자리 수와
    PBUS_JRSD_MCLSS_ID 의 000 숫자의  자리 수와
    CSTR_TUNL_SQNO 의 00 숫자를 합쳐서 터널코드의 앞이 생성됩니다.
        - 예시
            - 기타 데이터가 없거나 정보가 없는 곳은 NULL로 입력하고 나중에 수정하면 됩니다.

    📌 **본부, 지사, 터널 정보**
    
    ```sql
    -- 본부, 지사, 터널 정보
    SELECT DISTINCT BBCD.INTG_DPTCD BBCODE
    , REPLACE(BBCD.KOR_DPTNM, '본부', '') BBNAME
        , JSCD.INTG_DPTCD JSCODE
        , REPLACE(REPLACE(JSCD.KOR_DPTNM, '지사', ''), '도로관리소', '') JSNAME
        , TCD.TUNL_CD TNCODE
        , REPLACE(TCD.TUNL_NM, '터널', '') TNNAME
     FROM T_AFMF_TNRM_TUNL01M1 TCD
     , (SELECT TB.*, TBC.SORT_TORD FROM V_CNKC_INTG_DPRT01C1 TB, T_AFMF_DPRT_SORT01M1 TBC WHERE TB.INTG_DPTCD = TBC.RSNT_DPTCD) BBCD
        , (SELECT TB.*, TBC.SORT_TORD FROM V_CNKC_INTG_DPRT01C1 TB, T_AFMF_DPRT_SORT01M1 TBC WHERE TB.INTG_DPTCD = TBC.RSNT_DPTCD) JSCD
    WHERE 1=1
      AND TCD.HDQR_CD  = BBCD.INTG_DPTCD
      AND TCD.MTNOF_CD = JSCD.INTG_DPTCD
      AND BBCD.INTG_DPTCD   = JSCD.IMDT_HGRN_DPTCD
      AND TNRM_TUNL_TYPE_CD = 'L' -- 터널 타입(L:장터널, M:중터널, S:단터널)  
      AND TUNL_CD IN (80513, 80514, 80516, 80517, 80521, 80523)
    ;
    ```

### 3. T_AFMF_RPTR_MPNG01M2 신규중계기매핑기본 테이블 생성하기

1. 터널코드가 생성되었다면 T_AFMF_RPTR_MPNG01M2 테이블에도 생성해서 넣어준다.
    - 같은 지사의 중계기번호 RPTR_SEQ를 맞춰서 입력해주시면 됩니다.

    SELECT * FROM T_AFMF_RPTR_MPNG01M2
    WHERE MTNOF_CD = 'N01046';

    ### 1. MRG_SQNO 순번 찾기
    
    ```sql
    SELECT * FROM T_AFMF_TNRM_TUNL01M1
    WHERE
    	MTNOF_CD IN (
    	SELECT DISTINCT MTNOF_CD FROM TER_MAIN.T_AFMF_RPTR_MPNG01M2
    	WHERE RPTR_SEQ = (
    		SELECT RPTR_SEQ FROM T_AFMF_RPTR01M2
    		WHERE MTNOF_CD = 'N01046')
    	)
    ORDER BY MRG_SQNO;
    ```
