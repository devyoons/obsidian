# 면접: 기술면접정리

## 질문 목록

- 객체 지향 프로그래밍이란 무엇인가?
    
    절차지향 프로그래밍은 오로지 컴퓨터 관점에서의 프로그래밍 패러다임이라면 객체지향은 인간이 구분할 수 있는 요소를 객체로 표현한 인간 중심적 프로그래밍 패러다임입니다. 객체 지향 프로그래밍의 대표적 특징으로 추상화 캡슐화 다형성 상속이 있습니다. 추상화는 클래스를 구현함에 있어 필요한 부분만 구현할 수 있고 캡슐화는 내부적인 데이터 흐름을 알 필요없이 사용하도록하고 은닉화를 통해 내용을 함부로 고치지 못하도록 무결성을 보장합니다. 다형성은 동일한 요청에 다른 방식으로 처리할 수 있도록 하는것이고 상속은 부모 클래스의 속성과 메소드를 자식클래스가 이어 받아 사용할 수 있습니다.
    
- OOP란?
    
    OOP는 객체지향형 프로그래밍을 의미합니다. 모든 데이터를 객체로 취급하여 프로그램에 반영한 것이며 순차적으로 프로그램이 동작하는 기존의 것들과는 다르게 객체와 객체의 상호작용을 통해 프로그램이 동작하는 것을 말합니다.
    
    OOP의 장점으로는 코드의 재사용이 가능하고 변경에 용이하며 오류 발생 가능성이 적고 안정성이 높습니다. 
    
- 자바의 특징은?
    
    자바는 네트워크상에서 쓸 수 있도록 미국의 선마이크로 시스템즈가 개발한 객체 지향 프로그래밍 언어입니다.  이식성이 좋고 메모리를 스스로 관리합니다. 은닉화로 보안성이 뛰어나며, 멀티 쓰레드를 지원합니다.  단점으로는 예외처리가 잘되어있지만 개발자가 일일이 처리를 해줘야한다는 불편함이 있고 다른 언어에 비해 작성해야 하는 코드가 긴편입니다.
    
- 스레드
    
    프로세스내에서 동시에 실행되는 독립적인 실행 단위를 말합니다.
    
    특징으로는 어플리케이션의 성능을 향상 시킬 수 있고, 구현이 쉽습니다. 단점으로 교착상태에 빠질 수 있습니다. 다중 프로그래밍 체제에서 하나 또는 그 이상의 프로세스가 수행할 수 없는 어떤 특정시간을 기다리고 있는 상태를 말합니다. 
    
- 스레드와 프로세스의 차이점
    
    운영체제에서 실행중인 하나의 프로그램을 프로세스라고 합니다. 프로세스 내에서 실행되는 각각의 일을 스레드라고 합니다. 프로세스 내에서 실행되는 세부 작업 단위로 여러개의 스레드가 하나의 프로세스를 이루게 되는 것입니다.
    
- REST API란?
    
    rest를 기반으로 만들어진 api를 의미합니다. rest는 생성, 조회, 수정, 삭제 데이터 자원을 이름으로 구분하여 해당 자원의 상태를 주고 받는 모든 것을 의미합니다. http uri를 통해 자원을 명시하고 메소드를 통해 해당 자원에 대한 CRUD Operation을 적용하는 것을 의미합니다. 
    
- MVC 패턴이 무엇인가?
    
    모델 뷰 컨트롤러의 약자로 애플리케이션을 세 가지 역할로 구분한 개발 방법론입니다. 컨트롤러에서 비즈니스 로직을 처리하면 모델을 통해 데이터를 가져오고 그 데이터를 바탕으로 뷰를 통해 시각적 표현을 제어하여 사용자에게 전달합니다. 이러한 패턴을 사용하면 사용자 인터페이스로부터 비즈니스 로직을 분리하여 애플리케이션 시각적 요소나 그 이면에서 실행되는 비즈니스 로직을 서로 영향 없이 쉽게 고칠 수 있는 애플리케이션을 만들 수 있습니다. 
    
- MVC1 MVC2 차이점
    
    MVC1은 뷰와 컨트롤러를 전부 JSP가 담당하지만, MVC2는 요청의 결과를 보여주는 뷰만 JSP가 담당하고, 컨트롤러의 역할은 서블릿이 담당합니다. 
    
- JVM이란?
    
    자바는 OS에 종속적이지 않다는 특징을 가지고 있습니다. OS에 종속받지 않고 실행되기 위해서는 OS위에서 자바를 실행시킬 무언가가 필요한데 그게 바로 JVM입니다. 
    OS에 종속 받지 않고 CPU가 자바를 인식하고 실행할 수 있게 하는 가상 컴퓨터입니다
    
- SI란?
    
    시스템 통합을 의미합니다. 기업이 필요로 하는 정보 시스템에 관한 기획과 개발, 나아가 운영에 이르기까지 모든 서비스를 제공하는 것을 말합니다. 
    
- 클래스란?
    
    객체지향프로그래밍에서 특정 객체를 생성하기 위해 변수와 메소드를 정의하는 일종의 틀입니다.
    
- 객체란?
    
    클래스에서 정의한 것을 바탕으로 실제 저장공간인 메모리에 할당된 것으로 프로그램에서 사용되는 데이터 또는 식별자에 의해 참조되는 공간을 의미합니다.
    
- 오버로딩 오버라이딩
    
    오버로딩은 같은 이름의 메소드를 여러개 정의하는것이고 오버라이딩은 상위 클래스의 메소드를 하위 클래스에서 재정의하는 것을 말합니다. 
    
- JDBC란?
    
    데이터 베이스에 접근할 수 있는 프로그래밍을 의미합니다. 
    
- JDBC 코딩단계는?
    
    드라이버 등록하고 DBMS를 연결한 후 statement를 생성 하고  sql을 전송합니다. 결과를 받고 사용한 객체를 역순으로 닫아줍니다. 
    
- JDBC에서 트랜잭션관리는 어떻게 하는지?
    
    메서드를 통해서 각각 따로 커밋과 롤백을 할 수 있게 설정합니다. 
    
- JDBC에서 트랜잭션 처리할때 setAutoCommit이란?
    
    true인 경우 비정상적으로 종료되기 전까지는 실행한 쿼리문이 모두 커밋되어 있는것이고 false인경우 코드상에서 직접 커밋이나 롤백을 해주어야만 실행한 쿼리문이 반영되도록 하는 것입니다.
    
- 서블릿과 jsp의 차이점은?
    
    서블릿은 컨테이너가 이해할 수 있게 구성된 순수 자바 코드로만 이루어진 것이고 
    
    jsp는 html 기반에 자바코드를 블록화하여 삽입한 것입니다. 
    
- get과 post의 차이점
    
    get은 주로 웹브라우저가 웹서버에 데이터를 요청할 때 사용되고, post는 웹브라우저가 웹 서버에 데이터를 전달하기 위해서 사용됩니다.
    
- 프레임워크란?
    
    Gof의 디자인 패턴으로 소트트웨어의 구체적인 부분에 해당하는 설계와 구현을 재사용이 가능하게끔 일련의 협업화된 클래스들을 제공하는 것입니다. 예시로 프레임워크는 자동차의 프레임, 즉 기본적으로 구성하고 있는 뼈대를 말하고 라이브러리는 자동차의 기능을 하는 무품을 의미합니다. 
    
    장점으로는 시간과 비용이 훨씬 절약되며 생산성이 좋아집니다. 다수의 개발자가 사용하며 수정하다보니 이미 검증된 코드라 실수하기 쉬운 부분을 커버해줍니다. 회사입장에서는 개발 담당자가 바뀌어버리면 곤란하지만 프레임워크를 사용하면 코드가 보다 체계적이어서 위험부담을 줄일 수 있습니다. 단점으로는 프레임워크에 있는 코드를 습득하고 이해하는데 오랜 시간이 걸리고 짜여진 틀에 살을 붙여나가야하니 자유롭고 유연하게 개발하는 데에는 한계가 있습니다. 
    
- **Overloading과 Overriding의 차이**
    
    오버 로딩은, 다양한 타입과 개수의 파라메터를 가진 메소드를 여러 개 생성하여, 다양한 유형의 호출에 응답하게 하는 기술입니다.
    
    오버라이딩은 상위클래스의 메소드를 하위 클래스에서 재정의하는 것을 말합니다.
    
- 세션과 쿠키의 차이점
    
    세션은 쿠키와 다르게 개인 아이디와 비밀번호와 같은 웹사이트의 데이터가 클라이언트가 아닌 서버에 저장되거나 웹브라우저 캐시에 저장되어 브라우저가 닫히거나 서버에서 삭제시 사라집니다. 즉 사용자가 머무르는 시간 또는 한 명의 사용자의 한 번의 방문을 의미하고
    
    쿠키는 사용자가 특정 웹서버에 접속할 때 생성되는 개인 아이디와 비밀번호, 방문한 사이트의 정보를 담은 임시 파일로써, 서버가 아닌 클라이언트에 텍스트 파일로 저장되어 다음에 해당 웹서버를 찾을 경우 웹서버에서는 그가 누구인지 어떤정보를 주로 찾았는지 등을 파악할 때 사용됩니다. 
    
- 접근제한자
    
    **public**
    
    - 접근 제한이 없다. (같은 프로젝트 내에 어디서든 사용 가능)
    
    **protected**
    
    - 같은 패키지 내, 다른 패키지에서 상속 받아 자손클래스에서 접근 가능
    
    **default**
    
    - 같은 패키지 내에서만 접근 가능
    
    **private**
    
    - 같은 클래스 내에서만 접근 가능
- 자바 출력문
    
    println : 안에 있는 것을 출력 후 , 줄바꿈
    
    print : 안에 있는 것을 출력 후, 줄바꿈을 하지 않음
    
    printf : 출력 포맷을 지정할 수 있음. 자동 줄바꿈이 안됨.
    
    %f 실수, %s 문자열, %c 문자 등..
