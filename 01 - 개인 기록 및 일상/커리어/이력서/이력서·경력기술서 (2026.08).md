### 2. 스마트 건설현장 관리 플랫폼 v2 — 4개 채널을 하나의 구조로 통합

2025.01 ~ 2026.01 (약 13개월) · 자사 · 플랫폼 아키텍처 설계, 백엔드 개발 및 인프라 구축

- v1에서는 서비스별로 동일 테이블을 각자 조회해 컬럼 하나만 추가돼도 전체 서비스를 일일이 찾아 수정·재배포해야 했던 구조를, 공통 데이터를 Core 모듈 매퍼로 분리하는 멀티모듈 구조(safety-com·safety-back·safety-web·safety-mng·safety-wrk)로 전환해 **컬럼 변경 시 수정 지점을 Core 모듈 한 곳으로 단일화, 불필요한 전체 재배포 제거**
- 관리자 웹·관리자 앱·근로자 앱 3가지 로그인 흐름을 `UnifiedAuthFilter` 하나로 통합해, URL 패턴과 로그인 ID 형식(휴대폰 번호 여부)으로 사용자 유형을 자동 추론하고 **JWT 발급·검증·자동 갱신·기기 바인딩 로직을 단일 지점에서 관리하는 통합 인증 구조 구현**
- 접속 경로 × 사용자 유형 × 담당 구분 × 사업장 구분 조합으로 **상위 권한이 하위 권한을 포함하는 계층적 권한 체계(RBAC) 설계**, 모바일 기기 교체 시 본인인증(NICE) 연동으로 재바인딩 처리
- 근로자 출퇴근 인증을 GPS가 아닌 **블루투스 근접 신호 기반으로 설계해 위치 스푸핑·대리 출근을 원천 차단** (관리자 기기 광고 송출 → 근로자 앱 스캔 → 매칭 시 출근 등록)
- Java/JavaScript 공통 모듈 및 하이브리드 웹앱 간 통신을 위한 공통 브릿지(Bridge) 함수 개발 (FCM, GPS, 카메라/갤러리/QR, 녹음, PDF, 블루투스 등 AOS/iOS 표준 인터페이스 정의)
- 본인인증, 알림톡(Aligo) API, 행안부 주소 API 연동 등 외부 API 기반 부가 기능 구현
- Docker 컨테이너 기반 서버 구축, Nginx/DB 세팅 및 Gitea-Jenkins 연동을 통한 CI/CD 배포 파이프라인 구축

### 자기소개서

#### 배우는 게 즐겁고, 맡은 일은 끝까지 해냅니다

백엔드 개발자로 일한 지 3년 10개월 됐습니다. SI 프로젝트 개발부터 사내 서비스 유지보수, 신규 서비스 아키텍처 설계까지 여러 역할을 거쳐왔고, 그 과정에서 입사 1년 6개월 만에 대리, 3년 7개월 만에 과장으로 진급했습니다. 처음 해보는 업무도 믿고 맡겨주셨고, 그걸 해내면서 신뢰를 쌓아온 시간이었던 것 같습니다.

주력 스택은 Java와 Spring Boot이고, Jenkins·Docker·Git·NGINX·Redis로 DevOps 환경을 구축하고 운영해봤습니다. 시스템 구조를 파악해서 안정성과 확장성을 고려해 설계하는 걸 잘하는 편이고, 담당자가 빠진 채 멈춰 있던 프로젝트를 이어받아 끝까지 마무리한 경험도 있습니다. 새로운 환경에 적응하는 속도는 자신 있고, 그 힘으로 계속 성장하고 싶습니다.

##### 직무 경험 및 자기소개

### 1. [설계가 없어도 개발은 시작해야 하니까]

프로젝트에 투입된 시점은 이미 개발을 시작해야 하는 단계였는데, 화면설계서는 AS-IS 화면을 그대로 가져와 제출용으로만 만들어져 있었고 실제 설계는 개발과 병행해서 잡아가야 하는 상황이었습니다. 기획자가 설계를 먼저 끝낸 파트부터 순서대로 나눠서 개발을 진행했고, DB도 막 나온 기본 틀이라 개발하면서 맞지 않는 부분을 확인하고 변경 요청을 해가며 구조를 잡아나갔습니다. 이런 상황에서는 원인을 따지기보다 지금 할 수 있는 부분부터 처리하면서 진행하는 편입니다.

### 2. [동료가 일하기 편한 구조를 고민하는 개발]

1인 개발부터 멀티 모듈 기반 서비스 고도화, Docker와 Jenkins로 배포 자동화하는 것까지 서비스가 돌아가는 과정을 직접 다뤄봤습니다. 맡은 기능만 구현하고 끝내기보다, 같이 일하는 동료들이 개발하기 편한 구조인지, 서비스가 안정적으로 돌아가는지를 계속 신경 쓰면서 일합니다.

### 3. [현장에서 배운 감각, 코드로 이어지다]

개발자가 되기 전엔 수영강사, 그다음엔 인테리어 디자이너로 일했습니다. 인테리어 일을 할 때는 전산응용건축제도기능사 자격증을 갖고 실측부터 도면 설계, 목공·타일·조명 위치까지 직접 조율했는데, 정확하게 설계하고 그걸 실제로 구현해내는 감각을 그때 많이 배운 것 같습니다. 지나고 보니 이 경험이 지금 백엔드 개발자로서 여러 요소가 맞물리는 시스템 구조를 설계할 때도 도움이 되고 있습니다. 장기적으로 할 수 있는 일을 고민하다 개발로 넘어왔고, 이후엔 성과로 인정받아 진급도 빠르게 할 수 있었습니다. 개발이 재미있어서 일하면서 컴퓨터공학과에 편입해 학사 학위를 땄고, 지금은 정보처리기사 필기에 합격해 올해 안에 실기까지 취득할 계획입니다.
