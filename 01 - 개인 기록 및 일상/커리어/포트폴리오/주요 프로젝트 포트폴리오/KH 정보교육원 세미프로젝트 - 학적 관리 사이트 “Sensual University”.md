### **🗞설명**

---

- 해당 프로젝트는 학적 관리 사이트를 구현한 프로젝트입니다.
- 기존 학적 사이트에서 제공되지 않는 수강신청을 할 수 있고, 다양한 게시판, 채팅 기능으로 사용자 간의 커뮤니케이션 기능을 업그레이드하여 기존 사이트의 UI와 달리 심플한 UI로 새롭게 통합구현하였습니다.

### **🙋‍♂️역할**

---

- OvenApp :  전체적인 UI 디자인
- 회원 서비스 기능
    
    : 로그인, 로그아웃, 비밀번호 찾기, 회원가입, 마이페이지, 내 정보 수정, 회원탈퇴
    

### **⚙️사용 기술**

---

- IDE : Eclipse
- 개발언어 : Java , JavaScript , HTML , CSS
- DB : Oracle Cloud
- Server : Apache Tomcat 9.0
