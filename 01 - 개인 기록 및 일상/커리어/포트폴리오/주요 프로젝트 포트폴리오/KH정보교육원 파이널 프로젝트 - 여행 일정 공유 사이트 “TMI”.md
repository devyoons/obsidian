### **🗞설명**

---

- 코로나로 인해 해외여행이 힘들어진 상황에서 국내 여행을 위주로 한 여행 일정 공유 사이트를 개발 주제로 선정하여 여행 계획을 만들어 공유하고 새로운 친구들과 국내 여행의 길잡이가 될 수 있는 사이트를 구상하여 기획, 여행 계획을 상상해서 만들어 보자에서 착안하여 Travel Making Imagine을 줄여 TMI
- 해당 프로젝트는 Spring legacy 기반으로 Java, JavaScript, HTML, CSS 언어를 사용하여 구현한 여행 일정 공유사이트입니다.
- 깃을 사용하여 협업의 효율성을 높였습니다.

### **🙋‍♂️역할**

---

- PPT : 프로젝트 기획, 기능 PPT 제작
- 회원 서비스 기능 구현
    
    : 로그인, 로그아웃, 비밀번호 찾기, 이메일 찾기, 회원가입
    
- 1대1 채팅 기능 구현 : 게시글 작성자와 1대1 채팅
- 메인페이지 : GIF 메인 이미지와 메뉴바, 전체적인 CSS작업
- 이용약관동의 페이지 : 간단한 CSS작업과 Photoshop 을 활용

### **⚙️사용 기술**

---

- IDE : Eclipse
- 개발언어 : Java , JavaScript , HTML , CSS
- DB : Oracle Cloud
- Server : Apache Tomcat 9.0
- 프로젝트 시 활용해본 대표기술
    - JSP, Servlet, JDBC, WebSocket, jQuery, Ajax, Jackson, Bootstrap, Kakao Map API, Toru API 3.0, Spring-Security, Lombok, log4j
